### Hello, Time

Time is needed in a computing device for the following reasons,
* We want to be able to use the same hardware again and again for different inputs, which means the inputs change over **time**.
* We also want to be able to store information in hardware and want the hardware to remember them, the next time we try to read the value. 
* When dealing with time in computing devices, we also need to take into consideration the speed at which our hardware can operate and adjust clock times accordingly (not too fast otherwise the system becomes unstable).
#### The Clock

In computing devices, there is always a clock, that sends alternating 1/0 signals in equal intervals of time, when the clock sends a 1 signal, it is called a **tick**, and when the clock sends a 0 signal, it is called a **tock**. 

The clock continues to give signals tick, tock, tick, tock, ... and so on. One cycle of tick-tock is considered single integer unit of time. This is considered the smallest indivisible value of time in a computing machine. It is considered that nothing happens in between the clock cycles (although not entirely true, we'll see it later).

![](Pasted%20image%2020250105094320.png)

At every time unit the input could change, and the output would change accordingly within that time unit, and then until the start of next cycle nothing will change, then input may or may not change and so on the cycle continues.

Below is the example of this.

![](Pasted%20image%2020250105094635.png)

This is how we think about time in computer, every computing device has a master clock, and all other components receive alternating signals from this clock. Inputs only change at the start of clock cycle and output follows, then until the next cycle nothing changes.

But the point to note is that before the next cycle everything stabilises, before we read the output or change the input.

>Then for next change the values of pins might need to go from 0 to 1 or vice versa and this change takes time because physically electrons need to move to bring this change.
#### Sequential Logic

In combinatorial logic, we have output at time t dependent at input at time t, but in Sequential Logic output at time t is dependent at input at time t-1.

In principal we can still read output of input at time t in that same time interval but it is best to read the output for current input at the next time interval.

Sequential Logic circuits have memory, then can remember previous inputs and we can compute output based on current input and previous inputs.

## Flip Flops

A flip flop is a basic memory element that can store one bit of information (either 0 or 1). It retains its state until it is explicitly changed by an input signal.
#### SR Latch using NOR Gate

Latch is part of the flip flop that is responsible for storing the state. SR latch means Set Reset latch, it has two inputs Set input and Reset input. It can be made using other logic gates as well, but here we will only use NOR gate to implement it's functionality.

![](Pasted%20image%2020250105123007.png)

In this two nor gates are connect to inputs S and R and outputs of other Nor gates as shown in the figure above. Below are the truth tables of Nor gate and this SR Latch.

![](Pasted%20image%2020250105170223.png)

The thing to note in Nor gate is that if any of the inputs is 1, then regardless of the other input, the output will be 0.
##### Explanation Of SR Latch

* When both the inputs are 0, then in that case the state will be whatever it was earlier, i.e. if Q was 1 before this, then $\overline Q$ will be 0, and this state will be maintained, same is the case if Q was 0.
* When S is 0 and R is 1, then Q is surely 0, and then the input of above Nor gate will be 0, 0 which will make $\overline Q$. Similarly we can reason the output for case when S is 1 and R is 0.
* The case when S is 1, R is also 1, in that case the output is unpredictable and we call it an invalid state.

From the explanation it is clear, that it not inputs are give to the latch, it will hold the previous state indefinitely, this is the basis of memory in computer systems.

## RAM (Random Access Memory)

RAM is a collection of registers, that is used to store and retrieve information. Each register in a RAM is assigned an address, starting from 0 to n-1 (if the ram has n registers).

It is called random access, because reading and writing operations on any register takes the same amount of time, i.e. it is not like reading/writing on some register is faster than others.

At a particular interval of time we can select only 1 register from the ram to interact with, then we either choose to read or write its value. Below is the diagram of RAM.

![](Pasted%20image%2020250105181910.png)

If the RAM has N Registers, then we need k = log2(N) number of bits to be able to address every register.

To read a value from a particular register in RAM we first set the address to the register's address and in the next cycle we will get that value as output.

To write a value to a register, we need to set in = value, then address = register's address and set load = 1, then in next cycle this value will be stored inside of the register.

##### Bit

Below is the hdl for a 1-Bit register.

```hdl
/**
* 1-bit register:
* If load is asserted, the register's value is set to in;
* Otherwise, the register maintains its current value:
* if (load(t)) out(t+1) = in(t), else out(t+1) = out(t)
*/

CHIP Bit {
	IN in, load;
	OUT out;
	  
	PARTS:
	Mux(a=prevIn, b=in, sel=load, out=currIn);
	DFF(in=currIn, out=out, out=prevIn);
}
```

##### PC (Program Counter)

A chain of if else can be implemented using multiplexer chip as shown below.

```HDL
/**
* A 16-bit counter.
* if reset(t): out(t+1) = 0
* else if load(t): out(t+1) = in(t)
* else if inc(t): out(t+1) = out(t) + 1
* else out(t+1) = out(t)
*/

CHIP PC {
	IN in[16], reset, load, inc;
	OUT out[16];
	
	PARTS:
	Inc16(in=prevIn, out=incOut);
	Mux16(a=prevIn, b=incOut, sel=inc, out=in1);
	Mux16(a=in1, b=in, sel=load, out=in2);
	Mux16(a=in2, b=false, sel=reset, out=inFinal);
	Register(in=inFinal, load=true, out=out, out=prevIn);
}
```
