##### Half Adders And Full Adders

Addition is a functionality that we will build inside of our hardware itself, and along with it subtraction functionality is automatically realised as x - y = x + (-y). Functionalities like multiplication and division are hard to implement in hardware and they also make the chips costly, hence we will implement them in software layer.

To implement hardware that can add, we need to first be able to add two bits, this is implemented using a chip called Half Adder. It takes in two input bits that we need to add and outputs sum and carry bits. The truth table of Half adder is shown below.

#### Negative Numbers

Normally we don't just store positive numbers, rather we also need to store negative numbers and be able to do operations on them.

Hence one of the bit among k bits must be reserved to differentiate between negative and positive numbers. One way is to reserve the left most bit (most significant bit) as sign bit, if it is 0, then the number is positive and if it is one, then it is a negative number.

If we have 3 bits, then the range of numbers we can store will look at something like this.

![[Pasted image 20250104225145.png]]

As you can see that there is a problem of two zeroes in this method, also performing operations like addition and subtraction is very difficult with this method. 

##### 2's Complement Method

The way that is used to store negative number is to store them as 2's complement of their positive counter part i.e. In a k bit system -x will be stored as 2^k - x. In this system with 3 bits, the numbers look something like this.

![[Pasted image 20250104230130.png]]

##### How to compute 2's complement

In a k bit system, to get -x we need to do 2^k - x, but 2^k cannot be represented in a k bit system.

Another way to compute 2's complement of a number is using the fact that `x + not(x) = 2^k-1` which gives `not(x)+1 = 2^k - x`. Hence to get compute 2's complement of x we first invert all bits of x (i.e. not(x)) and then add one two the result.

The biggest benefit of using 2's complement is that it automatically makes addition of positive and negative numbers correct automatically. Consider the subtraction x - y, in our system, this will be occurring as follows.

## The ALU

The Arithmetic and Logical unit is a chip present in the cpu of a computer and that can perform a bunch of arithmetic operations (Addition, multiplication, division, ...) and logical operations (And, Or, Xor, ...) on the input values.

What all operations the ALU supports depends on the person designing the ALU. The features that we decide not to put in the ALU are then needed to be implemented in the software layer.
