# Overview

Linear algebra can begin with matrices, or it can begin with linear transformations. Strang's book chose matrices. Someone else might say, "Matrices are only a special case of linear transformations," and go even further back: "The real numbers are only a special case of a field." All of these are proper parts of the branch of mathematics called *Algebra*.

How should we respond to that? A good analogy: before you study languages in general (linguistics), you need to know at least one language. Working with column vectors, matrices, linear equations, inverses, vector spaces, orthogonality, linear independence and rank is a fascinating and rewarding "first language". The variety of matrices is like a community of people with different relations and different jobs: each matrix is unique, but factorization connects it to other matrices. You are allowed to have favorites.

This chapter has three sections:

1. **8.1** The Idea of a Linear Transformation
2. **8.2** The Matrix of a Linear Transformation
3. **8.3** The Search for a Good Basis

Section 8.3 discusses good bases for vector spaces of *functions*. The most natural extension from $\mathbb{R}^n$ to infinite dimensions is called **Hilbert space**, and the length and inner product of functions $f(x)$ and $g(x)$ take a natural form:

$$
\|f\|^2 = \int |f(x)|^2 \, dx \qquad \text{and} \qquad (f,g) = \int f(x)g(x) \, dx
$$

The best bases $q_1(x), q_2(x), \dots$ are orthogonal, as always. That discussion leaves *Algebra* behind and opens the way to *Functional Analysis*.

# 8.1 The Idea of a Linear Transformation

## What Is a Transformation?

When a matrix $A$ multiplies a vector $\boldsymbol{v}$, it "transforms" $\boldsymbol{v}$ into another vector $A\boldsymbol{v}$. In goes $\boldsymbol{v}$, out comes $T(\boldsymbol{v}) = A\boldsymbol{v}$. This is the same idea as a function: in goes a number $x$, out comes $f(x)$. For a single vector (or number) we just multiply by the matrix (or evaluate the function). But the deeper goal is to see **all** vectors at once: when we multiply every $\boldsymbol{v}$ by $A$, we are transforming the whole space $\mathbf{V}$.

Now think about what a matrix does. It sends $\boldsymbol{v}$ to $A\boldsymbol{v}$ and $\boldsymbol{w}$ to $A\boldsymbol{w}$. Then we *already know* what happens to $\boldsymbol{u} = \boldsymbol{v} + \boldsymbol{w}$: there is no doubt that $A\boldsymbol{u}$ must equal $A\boldsymbol{v} + A\boldsymbol{w}$. This predictability is exactly what we want to capture in general.

> [!abstract] Definition: Transformation and Linear Transformation
> A **transformation** $T$ assigns an output $T(\boldsymbol{v})$ to each input vector $\boldsymbol{v}$ in $\mathbf{V}$. The transformation is **linear** if it meets these requirements for all $\boldsymbol{v}$ and $\boldsymbol{w}$:
>
> - (a) $T(\boldsymbol{v} + \boldsymbol{w}) = T(\boldsymbol{v}) + T(\boldsymbol{w})$
> - (b) $T(c\boldsymbol{v}) = cT(\boldsymbol{v})$ for all scalars $c$

If the input is $\boldsymbol{v} = \boldsymbol{0}$, the output must be $T(\boldsymbol{0}) = \boldsymbol{0}$ (take $c = 0$ in rule (b)). We can also combine rules (a) and (b) into a single requirement.

> [!abstract] Definition: Linearity (Combined Form)
> $$
> T(c\boldsymbol{v} + d\boldsymbol{w}) = cT(\boldsymbol{v}) + dT(\boldsymbol{w}) \quad \text{for all } \boldsymbol{v}, \boldsymbol{w} \text{ and all scalars } c, d
> $$

Matrix multiplication passes this test: $A(c\boldsymbol{v} + d\boldsymbol{w}) = cA\boldsymbol{v} + dA\boldsymbol{w}$ is true. So multiplication by a matrix is the model example of a linear transformation.

> [!summary] Summary: The Five Facts About Linear Transformations
> 1. A linear transformation $T$ takes vectors $\boldsymbol{v}$ to vectors $T(\boldsymbol{v})$, and linearity requires $T(c\boldsymbol{v} + d\boldsymbol{w}) = cT(\boldsymbol{v}) + dT(\boldsymbol{w})$. Note that $T(\boldsymbol{0}) = \boldsymbol{0}$, so $T(\boldsymbol{v}) = \boldsymbol{v} + \boldsymbol{u}_0$ is not linear.
> 2. The input vectors $\boldsymbol{v}$ and the outputs $T(\boldsymbol{v})$ can be in $\mathbb{R}^n$, or in a matrix space, or in a function space.
> 3. If $A$ is $m$ by $n$, then $T(\boldsymbol{v}) = A\boldsymbol{v}$ is linear from the input space $\mathbb{R}^n$ to the output space $\mathbb{R}^m$.
> 4. The derivative $T(f) = \dfrac{df}{dx}$ is linear. The integral $T^+(f) = \displaystyle\int_0^x f(t)\,dt$ is its pseudoinverse.
> 5. The product $ST$ of two linear transformations is still linear: $(ST)(\boldsymbol{v}) = S(T(\boldsymbol{v}))$.

## Shift Is Not Linear

A linear transformation is highly restricted. To see how restrictive, suppose $T$ adds a fixed vector $\boldsymbol{u}_0$ to every vector, so $T(\boldsymbol{v}) = \boldsymbol{v} + \boldsymbol{u}_0$ and $T(\boldsymbol{w}) = \boldsymbol{w} + \boldsymbol{u}_0$. Applying $T$ to $\boldsymbol{v} + \boldsymbol{w}$ produces $\boldsymbol{v} + \boldsymbol{w} + \boldsymbol{u}_0$, which is *not* the same as

$$
T(\boldsymbol{v}) + T(\boldsymbol{w}) = (\boldsymbol{v} + \boldsymbol{u}_0) + (\boldsymbol{w} + \boldsymbol{u}_0)
$$

The extra copy of $\boldsymbol{u}_0$ breaks rule (a). The only exception is $\boldsymbol{u}_0 = \boldsymbol{0}$, where the transformation reduces to $T(\boldsymbol{v}) = \boldsymbol{v}$. This is the **identity transformation** (nothing moves, as in multiplication by the identity matrix), which is certainly linear. In this case the input space $\mathbf{V}$ is the same as the output space $\mathbf{W}$.

> [!abstract] Definition: Affine Transformation
> The linear-plus-shift transformation $T(\boldsymbol{v}) = A\boldsymbol{v} + \boldsymbol{u}_0$ is called **affine**.

> [!note] Affine Transformations Keep Lines Straight
> Straight lines stay straight under an affine transformation, even though $T$ is not linear. Computer graphics works with affine transformations because we must be able to *shift* images.

## Recognizing Linear Transformations

> [!note] Dot Products Are Linear
> Fix a vector $\boldsymbol{a}$ and let $T(\boldsymbol{v}) = \boldsymbol{a} \cdot \boldsymbol{v}$. Dot products are linear. If $\boldsymbol{a}$ and $\boldsymbol{v}$ live in $\mathbb{R}^3$, then the input space is $\mathbf{V} = \mathbb{R}^3$ and the outputs are just numbers, so the output space is $\mathbf{W} = \mathbb{R}^1$. We are multiplying by the *row matrix* $A = \boldsymbol{a}^T$, so $T(\boldsymbol{v}) = A\boldsymbol{v}$.

You will get good at recognizing which transformations are linear. As a rule of thumb: if the output involves squares, products or lengths, such as $v_1^2$, $v_1 v_2$ or $\|\boldsymbol{v}\|$, then $T$ is **not** linear.

> [!warning] Length Is Not Linear
> The length $T(\boldsymbol{v}) = \|\boldsymbol{v}\|$ fails both requirements. Requirement (a) would read $\|\boldsymbol{v} + \boldsymbol{w}\| = \|\boldsymbol{v}\| + \|\boldsymbol{w}\|$, and requirement (b) would read $\|c\boldsymbol{v}\| = c\|\boldsymbol{v}\|$. Both are false.
> - **Not (a):** the sides of a triangle satisfy an *inequality* $\|\boldsymbol{v} + \boldsymbol{w}\| \le \|\boldsymbol{v}\| + \|\boldsymbol{w}\|$, not an equality.
> - **Not (b):** the length $\|-\boldsymbol{v}\|$ is $\|\boldsymbol{v}\|$ and not $-\|\boldsymbol{v}\|$. For negative $c$, linearity fails.

> [!warning] Projection Onto a Shifted Plane Is Not Linear
> Projecting every 3-dimensional vector $\boldsymbol{v} = (x, y, z)$ onto the horizontal plane $z = 1$ gives $T(\boldsymbol{v}) = (x, y, 1)$. This is not linear. Why not? It doesn't even transform $\boldsymbol{v} = \boldsymbol{0}$ into $T(\boldsymbol{v}) = \boldsymbol{0}$.

> [!note] Rotation Is Linear
> Let $T$ rotate every vector in the $xy$ plane by a fixed angle (say $30^\circ$). The **domain** of $T$ is the $xy$ plane (all input vectors $\boldsymbol{v}$), and the **range** of $T$ is also the $xy$ plane (all rotated vectors $T(\boldsymbol{v})$). Notice that we described $T$ without any matrix. Is rotation linear? Yes: we can rotate two vectors and add the results, and the sum of rotations $T(\boldsymbol{v}) + T(\boldsymbol{w})$ is the same as the rotation $T(\boldsymbol{v} + \boldsymbol{w})$ of the sum. **The whole plane is turning together** in this linear transformation.

## Linearity for Combinations of Many Vectors

So far linearity talks about two vectors. Does it say anything about three, or $n$ vectors? It does.

> [!theorem] Linearity Extends to $n$ Vectors
> If $T$ is linear, then
> $$
> \boldsymbol{u} = c_1\boldsymbol{v}_1 + c_2\boldsymbol{v}_2 + \cdots + c_n\boldsymbol{v}_n \quad \text{must transform to} \quad T(\boldsymbol{u}) = c_1T(\boldsymbol{v}_1) + c_2T(\boldsymbol{v}_2) + \cdots + c_nT(\boldsymbol{v}_n)
> $$

**Proof:** Start with three vectors to see the pattern. The 2-vector rule applies to the grouping $c\boldsymbol{u}$ and $d\boldsymbol{v} + e\boldsymbol{w}$:

$$
T(c\boldsymbol{u} + d\boldsymbol{v} + e\boldsymbol{w}) = T(c\boldsymbol{u}) + T(d\boldsymbol{v} + e\boldsymbol{w})
$$

Then linearity applies to *both* of those parts, giving three parts: $cT(\boldsymbol{u}) + dT(\boldsymbol{v}) + eT(\boldsymbol{w})$. For general $n$, repeat this peeling-off argument: split off one term at a time using the 2-vector rule until every term has been transformed separately. $\blacksquare$

This $n$-vector rule leads to a very important fact about linear transformations.

> [!theorem] Basis Tells All
> Suppose you know $T(\boldsymbol{v})$ for all vectors $\boldsymbol{v}_1, \dots, \boldsymbol{v}_n$ in a basis. Then you know $T(\boldsymbol{u})$ for every vector $\boldsymbol{u}$ in the space.

**Proof:** Every $\boldsymbol{u}$ in the space is a combination $\boldsymbol{u} = c_1\boldsymbol{v}_1 + \cdots + c_n\boldsymbol{v}_n$ of the basis vectors $\boldsymbol{v}_j$. By the $n$-vector rule, $T(\boldsymbol{u})$ is the *same combination* $c_1T(\boldsymbol{v}_1) + \cdots + c_nT(\boldsymbol{v}_n)$ of the known outputs $T(\boldsymbol{v}_j)$. $\blacksquare$

## Lines to Lines, Triangles to Triangles

What does linearity look like geometrically? Consider the line from $\boldsymbol{v}$ to $\boldsymbol{w}$ in the input space, and the line from $T(\boldsymbol{v})$ to $T(\boldsymbol{w})$ in the output space. Linearity tells us that every point on the input line goes onto the output line, and more than that: **equally spaced points go to equally spaced points**. For instance, the middle point $\boldsymbol{u} = \frac{1}{2}\boldsymbol{v} + \frac{1}{2}\boldsymbol{w}$ goes to the middle point $T(\boldsymbol{u}) = \frac{1}{2}T(\boldsymbol{v}) + \frac{1}{2}T(\boldsymbol{w})$.

Moving up a dimension, take three corners $\boldsymbol{v}_1, \boldsymbol{v}_2, \boldsymbol{v}_3$ with outputs $T(\boldsymbol{v}_1), T(\boldsymbol{v}_2), T(\boldsymbol{v}_3)$. The input triangle goes onto the output triangle, and equally spaced points stay equally spaced (along the edges, and then between the edges). The middle point $\boldsymbol{u} = \frac{1}{3}(\boldsymbol{v}_1 + \boldsymbol{v}_2 + \boldsymbol{v}_3)$ goes to the middle point $T(\boldsymbol{u}) = \frac{1}{3}\big(T(\boldsymbol{v}_1) + T(\boldsymbol{v}_2) + T(\boldsymbol{v}_3)\big)$.

> [!figure] Figure Placeholder: Figure 8.1 - Lines to lines and triangles to triangles. A line from $\boldsymbol{v}$ to $\boldsymbol{w}$ with equally spaced points (including the midpoint $\boldsymbol{u}$) is mapped to the line from $T(\boldsymbol{v})$ to $T(\boldsymbol{w})$ with equal spacing preserved. A triangle with corners $\boldsymbol{v}_1, \boldsymbol{v}_2, \boldsymbol{v}_3$ and its grid of equally spaced points is mapped to the triangle with corners $T(\boldsymbol{v}_1), T(\boldsymbol{v}_2), T(\boldsymbol{v}_3)$. Also $\boldsymbol{u} = \boldsymbol{0}$ goes to $T(\boldsymbol{u}) = \boldsymbol{0}$.

### Linear Transformations of a House

The book also gives a purely visual illustration. The columns of a $2$ by $12$ **house matrix** $H$ are the corners of a house drawn in the plane (the last corner connects back to the first). Multiplying $H$ by a $2$ by $2$ matrix $A$ transforms every corner, and the columns of $AH$ are the corners of a new house. Straight lines between the original corners become straight lines between the transformed corners, so the transformation from house to house is linear. Depending on $A$, the new house may be rotated, reflected, stretched, or otherwise unlivable.

> [!figure] Figure Placeholder: Figure 8.2 - Linear transformations of a house drawn by `plot2d(A*H)` for four matrices $A$: the identity (original house), a rotation matrix (house rotated by $35^\circ$), a matrix that swaps the two coordinates (house reflected across the $45^\circ$ line), and a matrix with entries $0.7$ and $0.3$ (house squeezed and skewed).

## Linear Transformations in Calculus

Linear transformations are not only about vectors in $\mathbb{R}^n$. Calculus is full of them, and here the "vectors" are functions.

### The Derivative

> [!note] The Derivative Is Linear
> The transformation $T(u) = \dfrac{du}{dx}$ takes the derivative of the input function.

How do you differentiate a quadratic $u = a + bx + cx^2$? You start with the derivatives of the basis functions $1$, $x$, $x^2$, which are $0$, $1$, $2x$. Then you use **linearity** for the derivative of any combination:

$$
\frac{du}{dx} = a\,(\text{derivative of } 1) + b\,(\text{derivative of } x) + c\,(\text{derivative of } x^2) = b + 2cx
$$

All of calculus depends on linearity. Precalculus finds a few key derivatives (for $x^n$, $\sin x$, $\cos x$ and $e^x$), and then linearity applies to all their combinations. The **chain rule** is special to calculus: it produces $\dfrac{df}{dg}\dfrac{dg}{dx}$ as the derivative of $f(g(x))$.

**Nullspace of $T(u) = du/dx$.** For the nullspace we solve $T(u) = 0$. The derivative is zero exactly when $u$ is a constant function. So the nullspace is one-dimensional, a line in function space consisting of all multiples of the special solution $u = 1$.

**Column space of $T(u) = du/dx$.** If the input space contains all quadratics $a + bx + cx^2$, the outputs (the column space) are all linear functions $b + 2cx$. The Counting Theorem ($r + (n - r) = n$) is still true in this setting:

$$
\dim(\text{column space}) + \dim(\text{nullspace}) = 2 + 1 = 3 = \dim(\text{input space})
$$

### The Matrix for $d/dx$

Can we find a matrix for $T = d/dx$? We know what $T$ does to the basis functions $v_1, v_2, v_3 = 1, x, x^2$:

$$
\frac{dv_1}{dx} = 0 \qquad \frac{dv_2}{dx} = 1 = v_1 \qquad \frac{dv_3}{dx} = 2x = 2v_2
$$

The $3$-dimensional input space $\mathbf{V}$ (quadratics) transforms to the $2$-dimensional output space $\mathbf{W}$ (linear functions). If $v_1, v_2, v_3$ were ordinary vectors, the matrix collecting these outputs would be

$$
A = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 2 \end{bmatrix} = \text{matrix form of the derivative } T = \frac{d}{dx}
$$

This matrix copies the transformation perfectly. Multiplying the coefficient vector of $u = a + bx + cx^2$ by $A$ gives

$$
A\boldsymbol{u} = \begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 2 \end{bmatrix}\begin{bmatrix} a \\ b \\ c \end{bmatrix} = \begin{bmatrix} b \\ 2c \end{bmatrix} \quad \longleftrightarrow \quad \frac{du}{dx} = b + 2cx
$$

> [!note] Every Transformation Gets a Matrix
> We will connect *every* linear transformation to a matrix. The connection from $T$ to $A$ depended on choosing an **input basis** $1, x, x^2$ and an **output basis** $1, x$.

### The Integral as the Pseudoinverse

Next come integrals, which give the pseudoinverse $T^+$ of the derivative. We cannot write $T^{-1}$ and cannot say "inverse", because the function $f = 1$ has derivative $df/dx = 0$ (the derivative has a nontrivial nullspace, so it is not invertible).

> [!note] Integration Is Also Linear
> Integration $T^+$ is linear: $\displaystyle\int_0^x (D + Ex)\,dx = Dx + \tfrac{1}{2}Ex^2$.

Here the input basis is $1, x$ and the output basis is $1, x, x^2$. So the matrix $A^+$ for $T^+$ is $3$ by $2$:

$$
A^+\boldsymbol{v} = \begin{bmatrix} 0 & 0 \\ 1 & 0 \\ 0 & \tfrac{1}{2} \end{bmatrix}\begin{bmatrix} D \\ E \end{bmatrix} = \begin{bmatrix} 0 \\ D \\ \tfrac{1}{2}E \end{bmatrix} \quad \longleftrightarrow \quad T^+(v) = Dx + \tfrac{1}{2}Ex^2
$$

The Fundamental Theorem of Calculus says that integration is the (pseudo)inverse of differentiation. For linear algebra, the matrix $A^+$ is the (pseudo)inverse of the matrix $A$:

$$
A^+A = \begin{bmatrix} 0 & 0 \\ 1 & 0 \\ 0 & \tfrac{1}{2} \end{bmatrix}\begin{bmatrix} 0 & 1 & 0 \\ 0 & 0 & 2 \end{bmatrix} = \begin{bmatrix} 0 & 0 & 0 \\ 0 & 1 & 0 \\ 0 & 0 & 1 \end{bmatrix} \qquad \text{and} \qquad AA^+ = \begin{bmatrix} 1 & 0 \\ 0 & 1 \end{bmatrix}
$$

Look at the zero in the top-left corner of $A^+A$: the derivative of a constant function is zero, and that zero sits on the diagonal of $A^+A$. Calculus wouldn't be calculus without that $1$-dimensional nullspace of $T = d/dx$.

## Products and Inverses of Transformations

> [!theorem] Product of Linear Transformations
> If $T$ and $S$ are linear, then the product $ST$, defined by $(ST)(\boldsymbol{v}) = S(T(\boldsymbol{v}))$, is also linear. In matrix language, if $T(\boldsymbol{v}) = A\boldsymbol{v}$ and $S(\boldsymbol{u}) = B\boldsymbol{u}$, then $T(S(\boldsymbol{u}))$ matches $AB\boldsymbol{u}$.

Now suppose $A$ is an **invertible** matrix. Certainly $T(\boldsymbol{v} + \boldsymbol{w}) = A\boldsymbol{v} + A\boldsymbol{w} = T(\boldsymbol{v}) + T(\boldsymbol{w})$. Another linear transformation is multiplication by $A^{-1}$. This produces the **inverse transformation** $T^{-1}$, which brings every vector $T(\boldsymbol{v})$ back to $\boldsymbol{v}$:

> [!abstract] Definition: Inverse Transformation
> $T^{-1}(T(\boldsymbol{v})) = \boldsymbol{v}$ matches the matrix multiplication $A^{-1}(A\boldsymbol{v}) = \boldsymbol{v}$.

> [!abstract] Definition: Invertible (Possibly Nonlinear) Transformation
> A nonlinear transformation $T$ is **invertible** if every $\boldsymbol{b}$ in the output space comes from *exactly one* $\boldsymbol{x}$ in the input space: $T(\boldsymbol{x}) = \boldsymbol{b}$ always has exactly one solution. When you solve $T(\boldsymbol{x}) = \boldsymbol{b}$, you are inverting $T$ to find $\boldsymbol{x}$.

## Is Every Linear Transformation a Matrix?

We are reaching an unavoidable question: **are all linear transformations from $\mathbf{V} = \mathbb{R}^n$ to $\mathbf{W} = \mathbb{R}^m$ produced by matrices?** When a linear $T$ is described as a "rotation" or "projection" or something else, is there always a matrix $A$ hiding behind $T$? Is $T(\boldsymbol{v})$ always $A\boldsymbol{v}$?

The answer is **yes**. This is an approach to linear algebra that doesn't start with matrices, but we still end up with matrices, *after we choose an input basis and an output basis*. (Section 8.2 develops this.)

## The Language of Transformations: Range and Kernel

Transformations have a language of their own. For a matrix, the column space contains all outputs $A\boldsymbol{v}$, and the nullspace contains all inputs for which $A\boldsymbol{v} = \boldsymbol{0}$. We translate those words into "range" and "kernel".

> [!abstract] Definition: Range and Kernel
> - **Range of $T$** $=$ the set of *all outputs* $T(\boldsymbol{v})$. The range corresponds to the **column space**.
> - **Kernel of $T$** $=$ the set of *all inputs* for which $T(\boldsymbol{v}) = \boldsymbol{0}$. The kernel corresponds to the **nullspace**.

The range lies in the output space $\mathbf{W}$, while the kernel lies in the input space $\mathbf{V}$. When $T$ is multiplication by a matrix, $T(\boldsymbol{v}) = A\boldsymbol{v}$, the range is the column space of $A$ and the kernel is the nullspace of $A$.

## Review of the Key Ideas

> [!summary] Summary: Key Ideas of 8.1
> 1. A transformation $T$ takes each $\boldsymbol{v}$ in the input space to $T(\boldsymbol{v})$ in the output space.
> 2. $T$ is **linear** if $T(\boldsymbol{v} + \boldsymbol{w}) = T(\boldsymbol{v}) + T(\boldsymbol{w})$ and $T(c\boldsymbol{v}) = cT(\boldsymbol{v})$: lines go to lines.
> 3. Combinations go to combinations: $T(c_1\boldsymbol{v}_1 + \cdots + c_n\boldsymbol{v}_n) = c_1T(\boldsymbol{v}_1) + \cdots + c_nT(\boldsymbol{v}_n)$.
> 4. The derivative $T$ and the integral $T^+$ are linear. So is $T(\boldsymbol{v}) = A\boldsymbol{v}$ from $\mathbb{R}^n$ to $\mathbb{R}^m$.

It is more interesting to *see* a transformation than to define it. When a $2$ by $2$ matrix $A$ multiplies all vectors in $\mathbb{R}^2$, we can watch how it acts: the eleven house vectors $\boldsymbol{v}$ are transformed into eleven vectors $A\boldsymbol{v}$, and straight lines between the $\boldsymbol{v}$'s become straight lines between the transformed vectors. Applying $A$ to a standard house produces a new house, possibly stretched or rotated or otherwise unlivable.
