# 4.1 Indefinite Integration

### Finding Antiderivatives – Indefinite Integrals

**Definition:** a function $F(x)$ is an antiderivative of a function $f(x)$ if
$$
F'(x) = f(x)
$$
for all $x$ in the domain of $f$. The set of all antiderivatives of $f$ is the **indefinite integral** of $f$ with respect to $x$, denoted by
$$
\int f(x) dx .
$$
The symbol $\int$ is an integral sign. The function $f$ is the **integrand** of the integral and $x$ is the **variable of integration**.

**Note:** From corollary 2 of the MVT we know that all functions that have the same derivative differ by a constant.
$$
\implies \quad \boxed{\int f(x) dx = F(x) + C}
$$
Hence, once we have found one antiderivative, others will simply be obtained by adding arbitrary constants.

### Indefinite integrals that we can directly obtain by differentiation

1. $\displaystyle\int x^n dx = \frac{x^{n+1}}{n+1} + C,\quad n \neq -1,\ n$ is rational
2. $\displaystyle\int \sin kx dx = -\frac{\cos kx}{k} + C$
3. $\displaystyle\int \cos kx dx = \frac{\sin kx}{k} + C$
4. $\displaystyle\int \sec^2 x dx = \tan x + C$
5. $\displaystyle\int \csc^2 x dx = -\cot x + C$
6. $\displaystyle\int \sec x \tan x dx = \sec x + C$
7. $\displaystyle\int \csc x \cot x dx = -\csc x + C$

Once we have obtained the antiderivative, verifying if it is correct is very simple, we just differentiate it to see if we get back the integrand or not.

**Example:** verify if $x\sin x + \cos x + C$ is equal to $\int f(x) dx$ where $f(x) = x\cos x$.

**Sol:**
$$
\frac{d}{dx}(x\sin x + \cos x) = x(\cos x) + \sin x,(1) - \sin x = x\cos x
$$
Hence, we have
$$
\int x\cos x dx = x\sin x + \cos x + C
$$
Later we will learn the step by step process to find antiderivatives.

### Rules of Indefinite Integration

1. **Constant Multiple Rule:** $\displaystyle\int k f(x) dx = k\int f(x) dx$
2. **Sum and Difference Rule:** $\displaystyle\int \left[f(x) \pm g(x)\right]dx = \int f(x) dx \pm \int g(x) dx$

### The Integrals of $\sin^2 x$ and $\cos^2 x$

We can find the integrals of $\sin^2 x$ and $\cos^2 x$ by using the multiple angle formula
$$
\implies \ \cos 2x = 1 - 2\sin^2 x \ \implies \ \sin^2 x = \frac{1 - \cos 2x}{2}
$$
$$
\implies \ \int \sin^2 x dx = \int \left(\frac{1 - \cos 2x}{2}\right)dx = \frac{1}{2}\int x^0 dx - \frac{1}{2}\int \cos 2x dx
$$
$$
\implies \ \boxed{\int \sin^2 x dx = \frac{x}{2} - \frac{\sin 2x}{4} + C}
$$
Similarly we can evaluate
$$
\boxed{\int \cos^2 x dx = \frac{x}{2} + \frac{\sin 2x}{4} + C}
$$

# 4.2 Differential Equations, Initial Value Problems and Mathematical Modelling

### Initial Value Problems

An equation like $\dfrac{dy}{dx} = f(x)$ that has a derivative in it is called a **differential equation**. The problem of finding a function $y$ of $x$ when we know its derivative and its value $y_0$ at a particular point $x_0$ is called an **initial value problem**. We solve such a problem in two steps, as shown below.

**Example:** Find the curve whose slope at the point $(x, y)$ is $3x^2$, if the curve is required to pass through the point $(1, -1)$.

**Sol:** given that $\dfrac{dy}{dx} = 3x^2$
$$
\implies \ \int \left(\frac{dy}{dx}\right)dx = 3\cdot\left(\frac{x^{2+1}}{2+1}\right) + C
$$
$$
\implies \ y = 3\left(\frac{x^3}{3}\right) + C = x^3 + C
$$
$$
\implies \ y(1) = -1 \ \implies \ 1^3 + C = -1 \ \implies \ C = -2
$$
$$
\implies \ \boxed{y = x^3 - 2}
$$
**Note:** for a given differential equation $\dfrac{dy}{dx} = f(x)$, finding the indefinite integral gives the **general solution** of the differential equation.
$$
\implies \ \frac{dy}{dx} = f(x) \text{ has general solution } \implies \ \int \left(\frac{dy}{dx}\right)dx = \int f(x)dx = F(x) + C
$$
Solving the general solution for an initial value problem gives a **particular solution** that passes through $(x_0, y_0)$.

>[!note]
>To solve a differential equation of the form $\dfrac{d^2y}{dx^2} = f(x)$ we need to integrate twice and to get a particular solution we would need more information than just a single point.
>$$
>\frac{d^2y}{dx^2} = f(x)\ \implies \ \int\left(\frac{d^2y}{dx^2}\right)dx = \int f(x)dx = F_1(x) + C_1
>$$
>$$
>\implies \ \text{Since } \frac{d^2y}{dx^2} = \frac{d}{dx}\left(\frac{dy}{dx}\right)\ \implies \ \boxed{\frac{dy}{dx} = F_1(x) + C_1}
>$$
>$$
>\implies \ \int\left(\frac{dy}{dx}\right)dx = \int \left(F_1(x) + C_1\right)dx = F_2(x) + C_1 x + C_2
>$$
>$$
>\implies \ \boxed{y = F_2(x) + C_1 x + C_2}
>$$

**Example:** A projectile fired from a platform 3 m above ground with an initial velocity of 160 m/s. Find the equation of height from ground as function of time assuming acceleration due to gravity is $9.8\ \text{m/s}^2$.

**Sol:** If $h$ is the height function then $\dfrac{d^2h}{dt^2} = -9.8$
$$
\implies \ \int\left(\frac{d^2h}{dt^2}\right)dt = -9.8t + C_1
$$
$$
\implies \ \frac{dh}{dt} = v = -9.8t + C_1,\quad \text{at } t = 0,\ \text{we have that } v = 160
$$
$$
\implies \ v(0) = C_1 = 160\ \implies \ \boxed{v = \frac{dh}{dt} = -9.8t + 160}
$$
$$
\implies \ \int \frac{dh}{dt} dt = -9.8\left(\frac{t^2}{2}\right) + 160t + C_2 = h
$$
$$
\implies \ \text{at } t = 0 \implies  h = 3 \implies  h(0) = C_2 = 3
$$
$$
\implies \ \boxed{h = -4.9t^2 + 160t + 3}
$$
>[!note]
>In a similar fashion we can solve any differential equation of the form $\dfrac{d^n y}{dx^n} = f(x)$.

### Sketching Solution Curves

The graph of a solution of a differential equation is called a **solution curve** (integral curve).

When we cannot find the explicit formulas for the solution curves of an equation $\dfrac{dy}{dx} = f(x)$, we may still be able to find their general shape by examining derivatives.

**Example:** Sketch the solution of the differential equation $\dfrac{dy}{dx} = \dfrac{1}{x^2 + 1}$.

**Sol:** $y' = \dfrac{1}{x^2 + 1}$, we have the following observations:

$y' > 0\ \ \forall, x \in D(y) = (-\infty, \infty)$, hence the function is increasing.

$\displaystyle\lim_{x \to \pm\infty} y' = 0$, hence the graph has horizontal asymptotes.

$y'' = \dfrac{-2x}{(x^2 + 1)^2}$, hence the curvature is up in $(-\infty, 0)$ and down in $(0, \infty)$.

From all of these observations we have the following shape of the graph.

### Mathematical Modelling

The development of a mathematical model usually takes four steps,

1. First we observe something in the real world and construct a system of mathematical variables and relationships that imitate some of its important features. We build a metaphor for what we see.
2. Next we apply existing mathematics to the variables and relationships in the model to draw conclusions about them.
3. After that we translate the mathematical conclusions to information about the system under study.
4. Finally we check the information against the observation to see if the model has any predictive value. We also investigate the possibility that the model applies to other systems.

### Computer Simulation

When we want to study a system we perform experiments under different circumstances and take observation.

But if carrying out multiple experiments is not feasible (it may be too expensive or dangerous or have too many calculations or time consuming) then we might run a series of simulated experiments on a computer.

The experiments behave like the real thing, without the disadvantages.

When the experiment has too many calculations carrying out experiments becomes impractical e.g. NASA's space flight simulation model.

# 4.3 Integration by Substitution – Running the Chain Rule Backward

### The Generalized Power Rule in Integral Form

If $u$ is a differentiable function of $x$, then from chain rule we know that
$$
\frac{d}{dx}\left(\frac{u^{n+1}}{n+1}\right) = u^n \frac{du}{dx}
$$
This means that $\dfrac{u^{n+1}}{n+1}$ is the antiderivative of $u^n \dfrac{du}{dx}$
$$
\implies \ \int \left(u^n \frac{du}{dx}\right)dx = \frac{u^{n+1}}{n+1} + C
$$
The left hand side of the previous equation is usually written in the following "differential" form.
$$
\int \left(u^n \frac{du}{dx}\right)dx = \int u^{n}\left( \frac{du}{dx}dx \right) = \int u^ndu
$$
Hence, if $u$ is a differentiable function,
$$
\int u^ndu = \frac{u^{n+1}}{n+1} + C
$$
**Example:** Evaluate $\displaystyle\int (x+2)^5 dx$.

**Sol:** we can put $x + 2 = u \implies  du = \left(\dfrac{du}{dx}\right)dx = 1\cdot dx = dx$
$$
\implies \ \int (x+2)^5dx = \int u^5du = \frac{u^{5+1}}{5+1} = \frac{(x+2)^6}{6} + C
$$
**Example:** Evaluate $\displaystyle\int \sqrt{1 + y^2}\cdot 2ydy$.

**Sol:** we can put $u = 1 + y^2 \implies  du = u' dx = 2ydy$
$$
\implies \ \int \sqrt{1 + y^2}\cdot 2ydy = \int \sqrt{u}du = \frac{u^{3/2}}{3/2} + C
$$

### Trigonometric Functions

If $u$ is a differentiable function of $x$, then $\sin u$ is also differentiable and using chain rule we get
$$
\frac{d}{dx}\sin u = \cos u\frac{du}{dx}\ \implies \ \int \left(\cos u\cdot\frac{du}{dx}\right)dx = \sin u + C
$$
$$
\implies \ \int \left(\cos u\frac{du}{dx}\right)dx = \int \cos u\left(\frac{du}{dx}\cdot dx\right) = \int \cos udu
$$
$$
\implies \ \int \cos u \text{ }du = \sin u + C
$$
In a similar way we can prove the following formulas also

1. $\displaystyle\int \sin u du = -\cos u + C$
2. $\displaystyle\int \sec^2 u du = \tan u + C$
3. $\displaystyle\int \csc^2 u du = -\cot u + C$
4. $\displaystyle\int \sec u \tan u du = \sec u + C$
5. $\displaystyle\int \csc u \cot u du = -\csc u + C$

**Example:** Evaluate $\displaystyle\int \frac{1}{\cos^2 2\theta} d\theta$.

**Sol:** $\displaystyle\int \frac{1}{\cos^2 2\theta} d\theta = \int \sec^2 2\theta d\theta$, now if we put $2\theta = u$
$$
\implies \ d\theta = \frac{1}{2} du \ \implies \ I = \int \sec^2 u\cdot\frac{1}{2} du = \frac{1}{2}\int \sec^2 u du
$$
$$
\implies \ I = \frac{1}{2}\left(\tan u + C\right) = \frac{1}{2}\tan u + \frac{C}{2} = \frac{\tan 2\theta}{2} + C'
$$
### The Substitution Method

The substitutions that we saw in previous examples were all instances of the following general rule.
$$
\int f(g(x))\cdot g'(x)dx = F(g(x)) + C,\qquad \text{where } \int f(x)dx = F(x) + C
$$
This we can prove very easily first by using substitution $u = g(x)$ & $du = g'(x)dx$
$$
\implies \ I = \int f(g(x))g'(x)dx = \int f(u)du = F(u) + C
$$
$$
\implies \ I = F(g(x)) + C
$$
To verify this we can simply differentiate RHS, i.e.
$$
\frac{d}{dx}\left[F(g(x)) + C\right] = F'(g(x))\cdot g'(x) = f(g(x))\cdot g'(x).
$$
Hence $\displaystyle\int f(g(x))\cdot g'(x) dx = F(g(x)) + C$.

**Example:** $I = \displaystyle\int \frac{2z dz}{\sqrt[3]{z^2 + 1}}$

**Sol:** $u = z^2 + 1 \implies  du = 2z dz \implies  I = \displaystyle\int u^{-1/3} du$
$$
\implies \ I = \frac{u^{2/3}}{2/3} + C = \frac{3}{2}\cdot\left(z^2 + 1\right)^{2/3} + C
$$

**Another Solution:** put $u = \sqrt[3]{z^2 + 1} \implies  u^3 = z^2 + 1$
$$
\implies \ y = u^3 = z^2 + 1 \ \implies \ dy = 3u^2 du = 2z dz
$$
$$
\implies \ I = \int \frac{3u^2 du}{u} = 3\int u du = 3\cdot\frac{u^2}{2} + C
$$
$$
\implies \ I = \frac{3}{2}\left(z^2 + 1\right)^{2/3} + C
$$
**Example:** Evaluate $\displaystyle\int \sec^2 x\cdot\tan x dx$

**Sol:** $I = \displaystyle\int \sec^2 x\cdot\tan x dx$

**Method 1:** put $\tan x = u \implies  \sec^2 x dx = du$
$$
\implies \ I = \int u du = \frac{u^2}{2} + C = \frac{\tan^2 x}{2} + C
$$
**Method 2:** put $\sec x = u \implies  \sec x \tan x dx = du$
$$
\implies \ I = \int u du = \frac{u^2}{2} + C' = \frac{\sec^2 x}{2} + C'
$$
Both the anti-derivatives must differ by a constant
$$
\implies \ \frac{\sec^2 x}{2} + C' - \frac{\tan^2 x}{2} - C = \frac{1}{2} + C' - C = \text{constant}
$$
Hence, we can solve the same integrand in multiple ways and still get the same answer.

**Example:** $\displaystyle\int \sin^5\frac{x}{3}\cos\frac{x}{3} dx$

**Sol:** $u = \sin\dfrac{x}{3} \implies  du = \cos\dfrac{x}{3}\cdot\dfrac{1}{3} dx \implies  \cos\dfrac{x}{3} dx = 3 du$
$$
\implies \ I = 3\int u^5 du = 3\cdot\frac{u^6}{6} + C = \frac{u^6}{2} + C = \frac{\sin^6(x/3)}{2} + C
$$
**Example:** $\displaystyle\int x^4\left(7 - \frac{x^5}{10}\right)^3 dx$

**Sol:** $u = 7 - \dfrac{x^5}{10} \implies  du = -\dfrac{1}{2}x^4 dx \implies  x^4 dx = -2 du$
$$
\implies \ I = -2\int u^3 du = -2\left(\frac{u^4}{4} + C\right) = -\frac{u^4}{2} + C
$$
$$
\implies \ I = -\frac{1}{2}\left(7 - \frac{x^5}{10}\right)^4 + C
$$

**Sol:** $u = \cos\dfrac{1}{\theta} \implies  du = -\sin\left(\dfrac{1}{\theta}\right)\cdot\dfrac{-1}{\theta^2} d\theta = \dfrac{1}{\theta^2}\sin\left(\dfrac{1}{\theta}\right)d\theta$

# 4.5 Riemann Sums and Definite Integral

### Algebra with Finite Sums

1. **Sum Rule:** $\displaystyle\sum_{k=1}^{n}(a_k + b_k) = \sum_{k=1}^{n}a_k + \sum_{k=1}^{n}b_k$
2. **Difference Rule:** $\displaystyle\sum_{k=1}^{n}(a_k - b_k) = \sum_{k=1}^{n}a_k - \sum_{k=1}^{n}b_k$
3. **Constant Multiple Rule:** $\displaystyle\sum_{k=1}^{n}c,a_k = c\sum_{k=1}^{n}a_k$
4. **Constant Value Rule:** $\displaystyle\sum_{k=1}^{n}c = n\cdot c$

### Sum Formulas for Positive Integers

1. $\displaystyle\sum_{k=1}^{n}k = \frac{n(n+1)}{2}$
2. $\displaystyle\sum_{k=1}^{n}k^2 = \frac{n(n+1)(2n+1)}{6}$
3. $\displaystyle\sum_{k=1}^{n}k^3 = \left(\frac{n(n+1)}{2}\right)^2$

### Riemann Sums

Let $f$ be a continuous function on the interval $[a, b]$, and $P$ be a partition of $[a, b]$ i.e.
$$
\begin{align}
P = \{ x_0, x_1, x_2, \dots, x_n \} \quad \text{where } x_0 < x_1 < \dots < x_n\ \ &\ \ x_0 = a\ \ &\ \ x_n = b.
\end{align}
$$
Hence, $P$ has $n$ disjoint sub-intervals $[x_0, x_1], [x_1, x_2], \dots, [x_{k-1}, x_k], \dots, [x_{n-1}, x_n]$.

The length of $k$-th sub-interval is $\Delta x_k = x_k - x_{k-1}$.

Let $c_k$ be any value in the $k$-th sub-interval $[x_{k-1}, x_k]$ then we have the **Riemann Sum** for $f$ on the interval $[a, b]$ as
$$
S_P = \sum_{k=1}^{n} f(c_k)\Delta x_k
$$
Geometrically this sum approximates the signed area under the curve $f$ in the interval $[a, b]$.
![](Pasted%20image%2020260925153557.png)
As the partition becomes finer and finer, the Riemann Sum's approximation for the area under the curve becomes more and more accurate.

**Norm of Partition:** the norm of a partition is the length of the longest sub-interval of the partition, it is denoted by $\lVert P \rVert$.
$$
\implies \ \lVert P \rVert = \max(x_k - x_{k-1})
$$
### Definite Integral as a Limit of Riemann Sums

>[!into] Definition
>Let $f(x)$ be a function defined on a closed interval $[a, b]$. We say that the limit of the Riemann Sums $\displaystyle\sum_{k=1}^{n} f(c_k)\Delta x_k$ on $[a, b]$ as $\lVert P \rVert \to 0$ is the number $I$ if the following condition is satisfied:
>
>Given any number $\varepsilon > 0$, there exists a corresponding number $\delta > 0$ such that for every partition $P$ of $[a, b]$
>$$
>\lVert P \rVert < \delta\ \implies \ \left|\sum_{k=1}^{n} f(c_k)\Delta x_k - I\right| < \varepsilon
>$$
>for any choice of the number $c_k$ in the sub-intervals $[x_{k-1}, x_k]$. If the limit exists, then we write
>$$
>\lim_{\lVert P \rVert \to 0}\sum_{k=1}^{n} f(c_k)\Delta x_k = I
>$$
>We call $I$ the **definite integral** of $f$ on $[a, b]$, we say that $f$ is **integrable** over $[a, b]$ and we say that the Riemann Sums of $f$ on $[a, b]$ converge to the number $I$.
>The number $I$ is denoted by $\displaystyle\int_a^b f(x) dx$
>$$
>\implies \ \boxed{\lim_{\lVert P \rVert \to 0}\sum_{k=1}^{n} f(c_k)\Delta x_k = \int_a^b f(x) dx}
>$$

>[!note]
>The amazing fact is that despite the variety of sums $\displaystyle\sum_{k=1}^{n} f(c_k)\Delta x_k$ as the partition change and the arbitrary $c_k$ change, the $\displaystyle\lim_{\lVert P \rVert \to 0}$ makes all of these converge to the same number.

>[!abstract] Theorem 1: The Existence of Definite Integrals
>All continuous functions are integrable. That is, if a function $f$ is continuous on an interval $[a, b]$ then its definite integral over $[a, b]$ exists.

**Proof:** Upper Riemann Sum is a specific variation in which we choose $c_k$ such that $f(c_k)$ is max, similarly we have Lower Riemann Sum in which $f(c_k)$ is the minimum.

Note that we are looking for absolute max & min in the interval $[x_{k-1}, x_k]$, and since $f$ is cont. on this we know that these always exist and $f$ takes these values at some point within the interval.
$$
\implies \ U(f, P) = \sum_{k=1}^{n} M_k \Delta x_k,\qquad L(f, P) = \sum_{k=1}^{n} m_k \Delta x_k
$$
where $M_k$ & $m_k$ are max and min of $k$-th sub-interval. Now, for the definite integral to exist we want the following limits to exist
$$
\lim_{\lVert P \rVert \to 0} U(f, P) = \lim_{\lVert P \rVert \to 0} L(f, P) = I
$$
$$
\implies \ \lim_{\lVert P \rVert \to 0}\left[U(f, P) - L(f, P)\right] = 0
$$
Now, a modified condition to prove existence of definite integral involving $U(f, P)$ & $L(f, P)$ is that for every $\varepsilon > 0$ there exists $\delta > 0$ such that for all $P$ with $\lVert P \rVert < \delta$
$$
\implies \ \left|U(f, P) - L(f, P)\right| < \varepsilon
$$
Now, $f$ is cont. on $[a, b]$, this means that $f$ is uniformly continuous on $[a, b]$, hence there exists $\delta > 0$ such that for all $x, y \in [a, b]$, if $|x - y| < \delta$, then $|f(x) - f(y)| < \varepsilon$

Hence, for $\varepsilon' = \dfrac{\varepsilon}{b - a}$, we can find $\delta > 0$, such that
$$
x, y \in [a, b] \quad \text{with} \quad  |x - y| < \delta \implies  |f(x) - f(y)| < \dfrac{\varepsilon}{b - a}
$$

This is called the **Heine–Cantor theorem**. Consider all partitions $P$ with $\lVert P \rVert < \delta$, this means that $x_k - x_{k-1} < \delta \implies  \Delta x_k < \delta\ \ \forall \Delta x_k \in P$.

Now let $c_k$ and $d_k$ be points where the function achieves min and max values in the $k$-th sub-interval.
$$
\implies \ |d_k - c_k| < x_k - x_{k-1} < \delta
$$
$$
\implies \ f(d_k) - f(c_k) < \frac{\varepsilon}{b - a}\ \implies \ M_k - m_k < \frac{\varepsilon}{b - a}
$$
$$
\implies \ U(f, P) - L(f, P) = \sum_{k=1}^{n}(M_k - m_k)\Delta x_k < \sum_{k=1}^{n}\left(\frac{\varepsilon}{b - a}\right)\Delta x_k
$$
$$
\implies \ U(f, P) - L(f, P) < \frac{\varepsilon}{b - a}\sum_{k=1}^{n}\Delta x_k = \frac{\varepsilon}{b - a}\cdot(b - a) = \varepsilon
$$
$$
\implies \ U(f, P) - L(f, P) < \varepsilon
$$
Hence proved that if $f$ is continuous on $[a, b]$, then the definite integral of $f = \displaystyle\int_a^b f(x) dx$ always exists.

**Note:** Geometric interpretation.

Consider the following increasing function and corresponding graphs of $U(f, P)$, $L(f, P)$ & $U(f, P) - L(f, P)$.
![](Pasted%20image%2020260925155322.png)
$U - L$ is the area of those boxes, now as we keep making the partition finer and finer, the boxes will keep getting smaller and having smaller total area, hence we can make their total area as small as we want and this means that $U$ & $L$ approach the same limit.

A box with bigger $P$, Same box with finer $P$ gives many small boxes with small total area.

>[!note] Why The Modified Condition Works
> $m_{k} \leq f(c_{k}) \leq M_{k}$ which gives us the following inequality for any given partition $P$,
> $$
> L(f,P) \leq \sum_{k=1}^{n} f(c_{k}) \Delta x_{k} \leq U(f,P)
> $$
> Now, both $L(f,P)$ and $U(f,P)$ have the same limit $I$ as $||P|| \to 0$, hence, by sandwhich theorem, we have that
> $$
> \displaystyle\lim_{\lVert P \rVert \to 0}\sum_{k=1}^{n} f(c_k)\Delta x_k
> $$
> also exists and is equal to $I$.

>[!note]
>The most important property of $f$ in this theorem is that it is continuous on $[a, b]$ which makes it bounded. Later in chapter 7 we will look at the integration of unbounded functions.

### Proof of Heine–Cantor Theorem

>[!info] Definition of Uniform Continuity
> A function is uniform continuous on an interval $I$ if for every $\varepsilon > 0$, there exists a $\delta > 0$ such that for all $x, y \in I$, if $|x - y| < \delta$, then $|f(x) - f(y)| < \varepsilon$.

>[!abstract] Theorem
> If $f$ is continuous on a closed interval $[a, b]$, then $f$ is uniform continuous on $[a, b]$.

**Proof:** the proof of this is by contradiction, let's assume that $f$ is continuous on $[a, b]$ but not uniform continuous, this means that there exists some $\varepsilon > 0$ such that for every $\delta > 0$ there exist $x, y \in [a, b]$ such that $|x - y| < \delta$ & $|f(x) - f(y)| \ge \varepsilon$.

Now we will create a sequence using $\delta = 1, \frac{1}{2}, \frac{1}{3}, \dots$
$$
\begin{align}
\implies \ \delta_1 = 1\ \implies \ \exists, x_1, y_1 \text{ such that } |x_1 - y_1| < 1\ \ &\ \ |f(x_1) - f(y_1)| \ge \varepsilon
\end{align}
$$
$$
\begin{align}
\delta_2 = \frac{1}{2}\ \implies \ \exists, x_2, y_2 \implies  |x_2 - y_2| < \frac{1}{2}\ \ &\ \ |f(x_2) - f(y_2)| \ge \varepsilon.
\end{align}
$$
Hence, we have two infinite sequences $x_{n}$ and $y_{n}$, using Bolzano-Weierstrass Theorem, we have a subsequence $x_{n_{k}}$ that converge to a value $c \in [a,b]$, we claim that the corresponding subsequence $y_{n_{k}}$ also converge to the same $c$.
$$
\text{As } k \to \infty \implies n_{k} \implies \infty \implies |x_{n_{k}} -y_{n_{k}}| < \frac{1}{n_{k}} \to 0
$$
$$
\implies x_{n_{k}} = y_{n_{k}} = c
$$
$$
\implies \lim_{ n_{k} \to \infty } |f(x_{n_{k}}) - f(y_{n_{k}})| = |f(c) - f(c)| = 0
$$
But, we have $|f(x_{n_k}) - f(y_{n_k})| \ge \varepsilon \implies  \varepsilon = 0$ which is a contradiction. Hence, we have that for every $\varepsilon > 0$ there exists $\delta > 0$ such that $\forall, x, y \in [a, b]$, if $|x - y| < \delta \implies  |f(x) - f(y)| < \varepsilon$.

Hence $f$ is uniformly continuous on the interval $[a, b]$.

>[!note]
> Geometrically what uniform continuity means is that if we make a rectangle of width $2\delta$ and height $2\varepsilon$, then if we move it over the curve with center of the rectangle on the curve, then at no point will the graph enter and leave from the top or bottom.
> ![](Pasted%20image%2020260925172603.png)
> A function which is not uniform continuous will eventually become steep enough to escape from top or bottom no matter how small we make the width of rectangle.
> 
> For example consider the function $\sin\left(\dfrac{1}{x}\right)$, in the interval $(0, 1)$, no matter how small we choose $\delta$, we will find that in the interval $(0, \delta)$ the function takes its max and min value infinite times & hence all $\varepsilon \in (0, 1)$ won't work.

### Integrability of Piece-wise Continuous Functions

As we have seen that definite integral is nothing but area under the curve of a continuous function. Hence, if a function is not continuous, but rather piece-wise continuous, then it is still integrable, we can integrate each cont. piece and add them to get the final answer.

### Functions with No Riemann Integral

While some discontinuous functions are integrable, others are not. The function
$$
f(x) = \begin{cases} 1, & x \text{ is rational} \\ 0, & x \text{ is irrational} \end{cases} \qquad D(f) = [0, 1]
$$
is not integrable as any partition that we make will have sub-intervals and each sub-interval will have both irrational and rational both.
$$
\begin{align}
\implies \ m_k = 0\ \ &\ \ M_k = 1
\end{align}
$$
$$
\implies \ U(f, P) = \sum_{k=1}^{n} M_k \Delta x_k = 1\cdot\sum_{k=1}^{n}\Delta x_k = 1\cdot(1 - 0) = 1.
$$
$$
\implies \ L(f, P) = \sum_{k=1}^{n} m_k \Delta x_k = 0
$$
$$
\implies \ U(f, P) \neq L(f, P)\ \text{ no matter how small we make } \lVert P \rVert.
$$

### Constant Functions

Theorem 1 says nothing about how to calculate definite integral, except for a few special cases like the constant function $f(x) = c$. The Riemann sum is
$$
\implies \ S_P = \sum_{k=1}^{n} f(c_k)\Delta x_k = c\cdot\sum_{k=1}^{n}\Delta x_k = c\cdot(b - a)
$$
$$
\implies \ \int_a^b f(x) dx = \int_a^b c\cdot dx = c\cdot(b - a)
$$
### The Area Under the Graph of a Non-Negative Function

The definite integral normally gives signed area under the curve, but if the function is non-negative, then we get true area under the curve.

>[!info] Definition
> Let $f(x)$ be a continuous function on $[a, b]$ with $f(x) \ge 0$ then the area of the region b/w the graph of $f$ and the $x$-axis is
> $$
> A = \int_a^b f(x) dx
> $$

>[!note]
> For a graph which is not non-negative we can get area under the curve by splitting it at points where it changes sign and then adding the results, this is $\displaystyle\int_a^b |f(x)| dx$

**Example:** Using area to evaluate definite integral
$$
\int_a^b x dx,\qquad 0 < a < b
$$
**Sol:**
$$
A = \int_a^b x dx = \frac{1}{2}(b - a)\cdot(b - a) + a\cdot(b - a)
$$
$$
\implies \ \int_a^b x dx = \left[\frac{b - a}{2} + a\right]\cdot(b - a)
$$
$$
\implies \ \boxed{\int_a^b x dx = \frac{b^2}{2} - \frac{a^2}{2}}
$$
![](Pasted%20image%2020260925173520.png)
**Example:** Using definite integral to find area of region b/w the parabola $y = x^2$ and $x$-axis on the interval $[0, b]$.
![](Pasted%20image%2020260925174637.png)
**Sol:** let us divide (partition) the interval into $n$ equal sub-intervals
$$
\implies P = \{ 0, \frac{b}{n}, \frac{2b}{n}, \dots, \frac{nb}{n} \}
$$
$$
\implies \ x_k = \frac{kb}{n}\ \text{ and }\ \Delta x_k = \frac{b}{n},
$$
$$
\implies \ \text{Also, we will choose } c_k = x_k = \frac{kb}{n}\ \implies \ f(c_k) = \left(\frac{kb}{n}\right)^2
$$
$$
\implies \ S_P = \sum_{k=1}^{n} f(c_k)\Delta x_k = \sum_{k=1}^{n}\left(\frac{kb}{n}\right)^2\cdot\frac{b}{n} = \frac{b^3}{n^3}\sum_{k=1}^{n}k^2
$$
$$
\implies \ S_P = \frac{b^3}{n^3}\cdot\frac{n\cdot(n+1)(2n+1)}{6} = \frac{b^3}{n^3}\cdot\left(\frac{2n^3 + n^2 + 2n^2 + n}{6}\right)
$$
$$
\implies \ S_P = \frac{b^3}{n^3}\cdot\left(\frac{2n^3 + 3n^2 + n}{6}\right)
$$
Now, as $\displaystyle\lim_{\lVert P \rVert \to 0}$, we have $n \to \infty$
$$
\implies \ \lim_{\lVert P \rVert \to 0} S_P = \lim_{n \to \infty}\frac{b^3}{n^3}\cdot\left(\frac{2n^3 + 3n^2 + n}{6}\right) = \lim_{n \to \infty}\frac{b^3}{6}\left(2 + \frac{3}{n} + \frac{1}{n^2}\right)
$$
$$
\implies \ \lim_{\lVert P \rVert \to 0} S_P = \frac{b^3}{6}\cdot 2 = \frac{b^3}{3}
$$
Hence, area under the curve is $\dfrac{b^3}{3}$.

>[!note] Relation b/w Definite Integral and Anti-Derivatives
> From the previous two examples we see that there is a relation b/w the resulting function and integrand.
> 
> $\displaystyle\int_a^b x dx = \frac{b^2}{2} - \frac{a^2}{2}$, result is of the form $\dfrac{x^2}{2}$ which is anti-derivative of $x$.
> 
> Similarly $\displaystyle\int_0^b x^2 dx = \frac{b^3}{3}$, result is of the form $\dfrac{x^3}{3}$ which is anti-derivative of $x^2$.

# 4.6 Properties, Area and the Mean Value Theorem

## Properties of Definite Integral

1. **Zero:** $\displaystyle\int_a^a f(x) dx = 0$ _(A definition)_
2. **Order of Integration:** $\displaystyle\int_a^b f(x) dx = -\int_b^a f(x) dx$ _(This is a definition)_
##### 3. Constant Multiple Rule: $\displaystyle\int_a^b k f(x) dx = k\int_a^b f(x) dx$
**Proof:** Let $I = \displaystyle\int_a^b f(x) dx$, for this property to work $f$ should be integrable from $[a, b]$. The property says that if $f$ is integrable on $[a, b]$, then so is $k\cdot f(x)$ and $\displaystyle\int_a^b k\cdot f(x) dx = k\cdot I$.

For every $\varepsilon > 0$, there must exist a $\delta > 0$ such that for all partitions with $\lVert P \rVert < \delta$, we have
$$
\left|S_P - kI\right| < \varepsilon,\qquad \text{where } S_P = \sum_{k=1}^{n} k\cdot f(c_k)\cdot\Delta x_k
$$
$$
\implies \ |k|\cdot\left|\sum_{k=1}^{n} f(c_k)\Delta x_k - I\right| < \varepsilon\ \implies \ \left|\sum_{k=1}^{n} f(c_k)\cdot\Delta x_k - I\right| < \frac{\varepsilon}{|k|}
$$
Since $f$ is integrable we can find $\delta > 0$ for which, every partition with $\lVert P \rVert < \delta$, we will get $\left|S_P' - I\right| < \dfrac{\varepsilon}{|k|}$. Hence the same $\delta$ will also give $|S_P - kI| < \varepsilon$.
$$
\displaystyle\int_a^b k\cdot f(x) dx = kI = k\cdot\int_a^b f(x) dx
$$
**Proof 2:** Since $f$ is integrable on $[a,b]$, we have,
$$
\begin{align}
\lim_{ \lvert P \rvert  \to 0 } \sum_{k=1}^{n} f(c_{k}) \Delta x_{k} & = I \\
\implies \lim_{ \lvert P \rvert  \to 0 } \sum_{k=1}^{n} k\cdot f(c_{k}) \Delta x_{k} & = k \cdot \lim_{ \lvert P \rvert  \to 0 } \sum_{k=1}^{n} f(c_{k}) \Delta x_{k} = kI
\end{align}
$$
##### 4. Sums & Differences: $\displaystyle\int_a^b \left[f(x) \pm g(x)\right]dx = \int_a^b f(x) dx \pm \int_a^b g(x) dx$.
**Sol:** This property only works when both the terms in the RHS is defined, this property says that if $f$ and $g$ are integrable in $[a, b]$, then so is $f \pm g$.

Let $I_1 = \displaystyle\int_a^b f(x) dx$, $\quad I_2 = \displaystyle\int_a^b g(x) dx$.

We claim that for every $\varepsilon > 0$, there exists $\delta > 0$ such that for all partitions with $\lVert P \rVert < \delta$, we have
$$
\left|\sum_{k=1}^{n}\left[f(c_k) \pm g(c_k)\right]\Delta x_k - \left[I_1 \pm I_2\right]\right| < \varepsilon
$$
$$
\implies \ \left|\sum_{k=1}^{n}\left[f(c_k) \pm g(c_k)\right]\Delta x_k - \left[I_1 \pm I_2\right]\right| \le \left|S_P - I_1\right| + \left|S_P' - I_2\right|
$$
where $S_P = \displaystyle\sum_{k=1}^{n} f(c_k)\Delta x_k$, & $S_P' = \displaystyle\sum_{k=1}^{n} g(c_k)\Delta x_k$

Now, since both $f$ & $g$ are integrable, we can find $\delta_1$ & $\delta_2$ such that for all $P$ with $\lVert P \rVert < \min(\delta_1, \delta_2)$ we have
$$
\lVert P \rVert < \delta_1\ \implies \ \left|S_P - I_1\right| < \frac{\varepsilon}{2},
$$
$$
\lVert P \rVert < \delta_2\ \implies \ \left|S_P' - I_2\right| < \frac{\varepsilon}{2}
$$
Hence for $\delta = \min(\delta_1, \delta_2)$ we get that
$$
\left|S_P - I_1\right| + \left|S_P' - I_2\right| < \frac{\varepsilon}{2} + \frac{\varepsilon}{2} = \varepsilon
$$
$$
\implies \ \left|\sum_{k=1}^{n}\left[f(c_k) \pm g(c_k)\right]\Delta x_k - \left(I_1 \pm I_2\right)\right| < \varepsilon
$$
$$
\implies \ \text{Hence,}\quad \int_a^b f(x) \pm g(x) dx = \int_a^b f(x) dx \pm \int_a^b g(x) dx
$$
**Proof 2:** Since, both $f$ and $g$ are integrable on $[a,b]$, then we have,
$$
\lim_{ \lvert P \rvert \to 0 } \sum_{k=1}^{n} [f(c_{k}) \pm g(c_{k})]\Delta x_{k} = \lim_{ \lvert P \rvert  \to 0 } \sum_{k=1}^{n} f(c_{k}) \Delta x_{k} \pm \lim_{ \lvert P \rvert  \to 0 } \sum_{k=1}^{n}g(c_{k})\Delta x_{k} = \int_{a}^{b}f(x)dx \pm \int_{a}^{b} g(x)dx
$$
>[!note]
>Using property 3 & 4 and mathematical induction one can prove that any linear combination of integrable functions is also integrable and
>$$
>\int_a^b \left[c_1 f_1 + c_2 f_2 + \dots + c_n f_n\right]dx = c_1\int_a^b f_1 + c_2\int_a^b f_2 + \dots + c_n\int_a^b f_n
>$$
##### 5. Additivity: $\displaystyle\int_a^b f(x) dx + \int_b^c f(x) dx = \int_a^c f(x) dx$
**Proof:** Let $P_{1}$ be the partition of $[a,b]$ and $P_{2}$ be partition of $[b,c]$, then $P = P_{1} \cup P_{2}$ is a partition of $[a,c]$. Let $S_{P_{1}}$ and $S_{P_{2}}$ be Riemann sums of $f$ on $P_{1}$ and $P_{2}$ respectively, then $S_{P} = S_{P_{1}} + S_{P_{2}}$ is a Riemann sum of $f$ on $P$. Now, if we apply the limit we get,
$$
\begin{align}
\lim_{ \lvert P \rvert  \to 0 } S_{P} & = \lim_{ \lvert P_{1} \rvert  \to 0 } S_{P_{1}} + \lim_{ \lvert P_{2} \rvert  \to 0 } S_{P_{2}} \\[2mm]
\implies \int_{a}^{c} f(x)dx & = \int_{a}^{b}f(x)dx + \int_{b}^{c}f(x)dx
\end{align}
$$
>[!note]
> This property makes perfect sense geometrically, which means area under the curve from $[a, c]$ will be sum of area under the curve from $[a, b]$ & $[b, c]$.
> 
> ![](Pasted%20image%2020260925190752.png)

##### 6.Max-Min Inequality
**Statement:** If $\max f$ and $\min f$ are the max and min values of $f$ on $[a, b]$, then
$$
\min f\cdot(b - a) \le \int_a^b f(x) dx \le \max f\cdot(b - a)
$$
**Proof:** We already know that $L(f, P) \le S_P \le U(f, P)$, where $S_P = \displaystyle\sum_{k=1}^{n} f(c_k)\Delta x_k$.
$$
\begin{align}
L(f, P) = \displaystyle\sum_{k=1}^{n} m_k\Delta x_k  & \ge \sum_{k=1}^{n}\min f\cdot\Delta x_k = \min f\cdot(b - a) \\[2mm]
\implies \ \min f\cdot(b - a) & \le L(f, P)
\end{align}
$$
Similarly, we get $U(f, P) \le \max f\cdot(b - a)$, which combined following inequality
$$
\min f\cdot(b - a) \le S_P \le \max f\cdot(b - a)
$$
Applying the limit $\lVert P \rVert \to 0 \implies  S_P = I = \displaystyle\int_a^b f(x) dx$
$$
\implies \ \min f\cdot(b - a) \le \int_a^b f(x) dx \le \max f\cdot(b - a)
$$
##### 7. Domination: If $f(x) \ge g(x)$ on $[a, b] \implies  \displaystyle\int_a^b f(x) dx \ge \int_a^b g(x) dx$
**Proof:** If $f(x) \ge g(x)$, then $S_P \ge S_P'$, where
$$
\begin{align}
S_P = \sum_{k=1}^{n} f(c_k)\Delta x_k\ \geq \ S_P' = \sum_{k=1}^{n} g(c_k)\Delta x_k
\end{align}
$$
If we apply the limit then inequality still holds.
$$
\implies \ \lim_{\lVert P \rVert \to 0} S_P \ge \lim_{\lVert P \rVert \to 0} S_P'\ \implies \ \int_a^b f(x) dx \ge \int_a^b g(x) dx.
$$
>[!note]
>Special Case: If $f(x) \ge 0$ on $[a, b]$, $\implies  \displaystyle\int_a^b f(x) dx \ge 0$.

## Integration and Total Area

As mentioned earlier that definite integral of $f$ on $[a, b]$ is the signed total area, this means it is sum of area above $x$-axis − sum of area below $x$-axis.

$$
\implies \ \int_a^b f(x) dx = A_1 + A_3 - A_2

## Average Value of Continuous Function

We know that the average value of $n$ numbers $a_1, \dots, a_n$ is given by $\dfrac{\sum a_i}{n}$. But how to find average value of a continuous function on the interval $[a, b]$.

We start by dividing the interval into $n$ equal sub-intervals, then we take a point from each sub-interval $c_1, c_2, \dots, c_n$. Then calculate the average of these as.
$$
\text{average-of-sample} = \frac{f(c_1) + \dots + f(c_n)}{n}
$$
$$
= \frac{1}{n}\sum f(c_k) = \frac{1}{b - a}\sum f(c_k)\Delta x_k\qquad \text{where } \Delta x_k = \frac{b - a}{n}
$$
$$
\implies \ \text{Average of Sample} = \frac{1}{b - a}\cdot\text{Riemann Sum.}
$$
As the number of samples reach infinite the size of sub-intervals go to zero, hence we have
$$
\lim_{n \to \infty}\text{Avg-Sample} = \lim_{\lVert P \rVert \to 0}\frac{1}{b - a}\sum f(c_k)\Delta x_k
$$
$$
\implies \ \text{Avg-Function} = \frac{1}{b - a}\int_a^b f(x) dx
$$
>[!info] Definition
> If $f$ is an integrable function on $[a, b]$, its average (mean) value on $[a, b]$ is
> $$
> \text{av}(f) = \frac{1}{b - a}\int_a^b f(x) dx
> $$

### The Mean Value Theorem for Definite Integrals

>[!abstract] Theorem 2
> If $f$ is continuous on $[a, b]$, then at some point $c$ in $[a, b]$,
> $$
> f(c) = \frac{1}{b - a}\int_a^b f(x) dx
> $$
> that is the average value of the function is realised at some point in the interval.

**Proof:** the property we proved in previous section will come handy in this proof.
$$
\implies \ \min f\cdot(b - a) \le \int_a^b f(x) dx \le \max f\cdot(b - a)
$$
$$
\implies \ \min f \le \frac{1}{b - a}\int_a^b f(x) dx \le \max f
$$
Now since $f$ is continuous, then using the Intermediate value theorem, we know at some point $c$ we will have the function take the intermediate value $\dfrac{1}{b - a}\displaystyle\int_a^b f(x) dx$.

>[!note]
> As a consequence of this theorem $\displaystyle\int_a^b f(x) dx = 0$ will only happen if $f(x) = 0$ at some point $c$ in $[a, b]$ (assuming $a \ne b$). Hence $f(x)$ has a root in $[a, b]$.

**Example:** Find the average value of $f(x) = 1 - \sqrt{1 - x^2}$ on $[-1, 1]$.

**Sol:** We don't need to integrate, then we will find the area geometrically and then divide by length of interval. The graph of $f(x)$ is a semi-circle as shown in the figure.
![](Pasted%20image%2020260925193303.png)
$$
\text{Area} = 2 \times 1 - \frac{1}{2}\pi\cdot 1^2 = \frac{4 - \pi}{2}

# 4.7 The Fundamental Theorem

## The Fundamental Theorem of Calculus (Part 1)

>[!abstract] Theorem 3
> If $f$ is continuous on $[a, b]$, then $F(x) = \displaystyle\int_a^x f(t) dt$ has a derivative at every point of $[a, b]$ and
> $$
> \frac{dF}{dx} = \frac{d}{dx}\int_a^x f(t) dt = f(x),\qquad a \le x \le b
> $$

**Proof:** For the proof we will apply the definition of derivative along with the properties of definite integral that we have learned.
$$
\frac{d}{dx}F = \lim_{h \to 0}\frac{F(x + h) - F(x)}{h} = \lim_{h \to 0}\frac{\displaystyle\int_a^{x+h} f(t) dt - \int_a^x f(t) dt}{h}
$$
$$
= \lim_{h \to 0}\frac{1}{h}\int_x^{x+h} f(t) dt
$$
Now, the mean value theorem says that the function $f$ which is continuous on $[x, x + h]$ will take its average value at some point $c$ in this interval.
$$
\implies \ \frac{1}{h}\int_x^{x+h} f(t) dt = f(c),\qquad \text{for some } c \in [x, x + h]
$$
$$
\implies \ \lim_{h \to 0}\frac{1}{h}\int_x^{x+h} f(t) dt = \lim_{h \to 0} f(c)
$$
Now, as $h \to 0 \implies  x + h \to x \implies  c \in [x, x + h] \to x$ & hence we have,
$$
\lim_{h \to 0} f(c) = \lim_{c \to x} f(c) = f(x)\qquad [\because f \text{ is cont. at } x]
$$
$$
\implies \ \frac{dF}{dx} = f(x)
$$
>[!note] Note About $h$
> All above calculations were done assuming $h > 0$, but if $h < 0$ then we get:
> $$
> \lim_{h \to 0^-}\frac{\displaystyle\int_a^{x+h} f(t) dt - \int_a^x f(t) dt}{h} = \lim_{h \to 0^-}\frac{\displaystyle\int_a^{x+h} f + \int_{x+h}^x f - \int_{x+h}^x f - \int_a^x f}{h}
> $$
> $$
> \implies \ \lim_{h \to 0^-}\frac{-\displaystyle\int_{x+h}^x f}{h} = \lim_{h \to 0}\frac{-1}{h}\int_{x+h}^x f(t) dt = \lim_{h \to 0^-} f(c) = f(x)
> $$
> Notice that $\dfrac{-1}{h}\displaystyle\int_{x+h}^x f(t) dt$ is the average value of $f$ in $[x + h, x]$.

>[!note] A Note About the Fundamental Theorem (Part 1)
> *What if we defined $F(x) = \displaystyle\int_b^x f(t) dt$, where $f$ is continuous on $[a, b]$ and $x \in [a, b]$. Do we still get $\dfrac{dF}{dx} = f(x)$ ?*
> The difference quotient in this case will be,
> $$
> \begin{align}
> \frac{F(x + h) - F(x)}{h} & = \frac{\displaystyle\int_b^{x+h} f(t) dt - \int_b^x f(t) dt}{h} \\
>  & = \frac{-\displaystyle\int_{x+h}^b f(t) dt + \int_x^b f(t) dt}{h} \\
>  & = \frac{1}{h}\int_x^{x+h} f(t) dt\qquad [\text{assuming } h \to 0^+] \\
> \implies \ \lim_{h \to 0}\frac{F(x + h) - F(x)}{h} &  = \lim_{h \to 0}\frac{1}{h}\int_x^{x+h} f(t) dt = \lim_{c \to x} f(c) = f(x)
> \end{align}
> $$
> Hence in this case also $\dfrac{dF}{dx} = f(x)$.

Hence, in general $F = \displaystyle\int_a^x f(t) dt$ will always work regardless of the relative position of $a$ and $x$, as long as $f$ is continuous in $[x, a]$ or $[a, x]$, $F$ will be its anti-derivative.

### Geometric Interpretation:

Derivative of $F$ at $x$ gives the rate at which the area b/w $f$ and $x$-axis is changing in the interval $[a, x]$.
![](Pasted%20image%2020260925194450.png)
If we think about the approx change in the area if we move from $x$ to $x + dx$, we see that we are adding a rectangle of height $f(x)$ and width $dx$
$$
\implies \ \Delta F \approx f(x) dx
$$
We also know that $\Delta F \approx F'(x) dx$
$$
\implies \ F'(x) dx = f(x) dx\ \implies \ \boxed{F'(x) = f(x)}
$$
What is remarkable is if $f$ is negative at $x$, then so is $f(x) dx$ and we are actually subtracting area at rate $f(x)$.

>[!note]
>1. This theorem says that the differential equation $\dfrac{dF}{dx} = f$ always has a solution if $f$ is continuous.
>
>2. Every continuous function $f$ is a derivative of some other function i.e. it always has an anti-derivative.
>
>3. This theorem also says that integration [and differentiation] are inverses of each other.

## The Fundamental Theorem of Calculus (Part 2)

>[!abstract] Theorem 4
> If $f$ is continuous at every point of $[a, b]$ and $F$ is any anti-derivative of $f$ on $[a, b]$, then
> $$
> \int_a^b f(x) dx = F(b) - F(a)
> $$

**Proof:** To prove this theorem we use the fact that functions with same derivatives in $[a, b]$ differ by a constant. We already know that $G(x) = \displaystyle\int_a^x f(t) dt$ is an anti-derivative of $f$, hence any other anti-derivative $F$ of $f$, we have
$$
\implies \ F(x) = G(x) + C
$$
$$
\implies \ F(b) - F(a) = G(b) + C - G(a) - C = G(b) - G(a)
$$
$$
\implies \ F(b) - F(a) = \int_a^b f(t) dt - \int_a^a f(t) dt = \int_a^b f(t) dt - 0
$$
$$
\implies \ \int_a^b f(t) dt = F(b) - F(a)
$$

$$

## 4.8 Substitution in Definite Integral

There are two ways to evaluate definite integral by substitution. One is to use the method we learned in indefinite integrals to find an antiderivative and then use fundamental theorem 4.

Other method is that we substitute the new function and update the two limits, below example makes the method clear.

**Example:** Evaluate $\displaystyle\int_{-1}^{1} 3x^2\sqrt{x^3 + 1} dx$

**Sol.** **Method 1:**
$$
\int 3x^2\sqrt{x^3 + 1} dx = \int \sqrt{u} du,\qquad u = x^3 + 1 \implies  du = 3x^2 dx
$$
$$
\implies \ \frac{u^{3/2}}{3/2}\ \implies \ \int_{-1}^{1} 3x^2\sqrt{x^3 + 1} dx = \frac{(x^3 + 1)^{3/2}}{3/2}\Bigg|_{-1}^{1}
$$
$$
= \frac{2^{3/2}}{3/2} - 0 = \frac{2}{3}\cdot 2\sqrt{2} = \frac{4\sqrt{2}}{3}
$$
**Method 2:**
$$
\int_{-1}^{1} 3x^2\sqrt{x^3 + 1} dx = \int_0^2 \sqrt{u} du,\qquad \text{where } u = x^3 + 1 \implies  du = 3x^2 dx
$$
when $x = 1 \implies  u = 2$, & $x = -1 \implies  u = 0$
$$
= \frac{u^{3/2}}{3/2}\Bigg|_0^2 = \frac{4\sqrt{2}}{3}
$$
Hence, we get the same answer both ways.

>[!note]
> In other words, both the methods are good, in the first one we use substitution, then evaluate the integral, then in the next we substitute back the original function and evaluate with original limits.
> 
> In the other method, we substitute function and update the integration limits accordingly and evaluate.
> 
> The second method feels shorter, but some problems favour method 1, hence knowledge of both is important.

= -\int_a^{-a} h(-u) du = \int_{-a}^{a} h(-u) du
$$
**Case 1:** $h$ is odd
$$
\implies \ I = \int_{-a}^{a} h(x) dx = \int_{-a}^{a} h(-u) du = -\int_{-a}^{a} h(u) du = -I
$$
$$
\implies \ I = -I \implies  I = 0 \implies  \boxed{\int_{-a}^{a} h(x) dx = 0}
$$
**Case 2:** $h$ is even.
$$
\implies \ \int_{-a}^{0} h(x) dx = \int_a^0 h(-u)(-du),\qquad \text{where } u = -x \implies  du = -dx
$$
at $x = -a \implies  u = a$, at $x = 0 \implies  u = 0$
$$
= -\int_a^0 h(-u) du = \int_0^a h(u) du
$$
$$
\implies \ \int_{-a}^{a} h(x) dx = \int_{-a}^{0} h(x) dx + \int_0^a h(x) dx = 2\int_0^a h(x) dx
$$
$$
\implies \ \boxed{\int_{-a}^{a} h(x) dx = \begin{cases} 0, & h \text{ is odd} \\[4pt] 2\displaystyle\int_0^a h(x) dx, & h \text{ is even} \end{cases}}
$$

##### Exercise 33
If $f$ is a continuous function, find the value of the integral
$$
I = \int_0^a \frac{f(x) dx}{f(x) + f(a - x)}
$$
**Sol:** $u = a - x \implies  du = -dx$, at $x = 0 \implies  u = a$ & $x = a \implies  u = 0$

\implies \ I = \int_a^0 \frac{f(a - u)(-du)}{f(a - u) + f(u)} = \int_0^a \frac{f(a - u)}{f(u) + f(a - u)} du

$$
$$
\implies \ I = a - I \implies  I = \frac{a}{2}
$$

## 4.9 Numerical Integration

We know now the ideal way to evaluate $\displaystyle\int_a^b f(x) dx$ which is to find an anti-derivative and then $F(b) - F(a)$.

But sometimes finding anti-derivative is very hard and still others, like anti-derivatives of $\dfrac{\sin x}{x}$ and $\sqrt{1 + x^4}$ have no elementary formula.

It has been proven that $\dfrac{\sin x}{x}$, $\sqrt{1 + x^4}$ will have no elementary formula.

Whenever we cannot evaluate a definite integral we turn to numerical methods to approximate the value to desired level or error tolerance.

The idea is that we divide the interval $[a, b]$ using some partition and then use polynomial of some degree that approximates the function within that sub-interval, we then add results of each per sub-interval.

There are two ways to improve accuracy,

1. Use better polynomial for each sub-interval, generally higher degree gives better accuracy.
2. Use a finer partition, the finer the better.

### The Trapezoidal Rule

Consider a function $f(x)$, we approx its integral $\displaystyle\int_a^b f(x) dx$ using equal length partition and polynomials of degree 1 i.e. straight line.

The polynomial is the straight line joining $f(x_k)$ & $f(x_{k-1})$ for $k$-th interval.

If we divide interval $[a, b]$ into $n$ sub-intervals, then $h = \dfrac{b - a}{n}$, & $x_k = a + kh$, & $y_k = f(x_k)$
![](Pasted%20image%2020260925213515.png)
The area of $k$-th trapezium is $\dfrac{1}{2}(y_{k-1} + y_k),h$
$$
\implies \ \text{Total Area} = \frac{h}{2}\left[(y_0 + y_1) + (y_1 + y_2) + \dots + (y_{n-1} + y_n)\right]
$$
$$
\implies \ T = \frac{h}{2}\left(y_0 + 2y_1 + 2y_2 + \dots + 2y_{n-1} + y_n\right)
$$
### The Error Estimate for Trapezoidal Rule:

If $f''$ is continuous and $M$ is any upper bound for the values of $|f''|$ on $[a, b]$, then
$$
|E_T| \le \frac{b - a}{12}h^2 M\ ,\qquad E_T = \int_a^b f(x) dx - T
$$
This result comes from advanced calculus.

The result says that to reduce the max error we can either find a tighter upper bound $M$ (or) make $h = \dfrac{b - a}{n}$ smaller.

In theory since $f''$ is cont. $\implies  |f''|$ is cont. which means there is an exact $M$ which exists and $= |f''|_{\max}$, but is not easy to find and we may have to settle for some other $M'$ which is $> M$.

**Example:** Find an upper bound for the error incurred in estimating $\displaystyle\int_0^{\pi} x\sin x dx$ with trapezoidal rule with $n = 10$ steps.

**Sol:** $f'' = 2\cos x - x\sin x$

**Good Upper Bound**
$$
|f''| = |2\cos x - x\sin x| \le |2\cos x| + |x\sin x|
$$
$$
\le |2\cdot 1| + |x\cdot 1| \le |2| + |x| \le |2| + \pi = 2 + \pi
$$
$$
\implies \ M = 2 + \pi
$$
**Exact Upper Bound:**

To find exact $M$, we need to find max and min values of $f''$ in $[0, \pi]$,
$$
f''(0) = 2,\qquad f''(\pi) = -2
$$
$$
\frac{d}{dx}\left(f''(x)\right) = -2\sin x - (\sin x + x\cos x) = -3\sin x - x\cos x = 0
$$
$$
\implies \ \tan x = \frac{x}{3}
$$
solving this is not easy, so we will settle with $M = 2 + \pi$
$$
\implies \ E_T \le \frac{\pi - 0}{12}\cdot\left(\frac{\pi - 0}{10}\right)^2\cdot(2 + \pi) = \frac{\pi^3(2 + \pi)}{1200} < 0.133
$$
$$
\implies \ E_T < 0.133
$$
If we choose $n = 100$, we get $E_T < 0.00133$.

### Simpson's Rule

This method uses polynomials of degree 2 to approximate the definite integral.

The idea is that we divide interval $[a, b]$ into even number of sub-intervals ($n \to$ even). Then we club the adjacent intervals i.e. $(1, 2), (3, 4), \dots, (n-1, n)$ and find the approx for each pair and add the results.

To approximate area of $k$-th pair, it contains sub-intervals $[x_{2k-2}, x_{2k-1}]$ & $[x_{2k-1}, x_{2k}]$, what we will do to approximate the area is we will find a parabola $Ax^2 + Bx + C$ that has values at $x = -h, 0, h$ same as $f(x_{2k-2}), f(x_{2k-1}), f(x_{2k})$


For example consider 1st pair i.e. $[x_0, x_1], [x_1, x_2]$, if we look at the graph
![](Pasted%20image%2020260925213649.png)
Let $g(x) = Ax^2 + Bx + C$, be any parabola such that
$$
g(-h) = f(x_0) = y_0,\qquad g(0) = f(x_1) = y_1,\qquad g(h) = f(x_2) = y_2
$$
$$
\implies \ g(-h) = Ah^2 - Bh + C = y_0
$$
$$
g(0) = C = y_1
$$
$$
g(h) = Ah^2 + Bh + C = y_2
$$
Area under $g(x)$ in $[-h, h]$ is
$$
= \int_{-h}^{h}\left(Ax^2 + Bx + C\right)dx
$$
$$
= \frac{Ax^3}{3} + \frac{Bx^2}{2} + Cx\Bigg|_{-h}^{h} = \frac{Ah^3}{3} + \frac{Bh^2}{2} + Ch + \frac{Ah^3}{3} - \frac{Bh^2}{2} + Ch
$$
$$
= \frac{h}{3}\left(2Ah^2 + 6C\right) = \frac{h}{3}\left(y_0 + 4y_1 + y_2\right)
$$
$$
\implies \ \text{Area (approx)} = \frac{h}{3}\left(y_0 + 4y_1 + y_2\right)
$$

What is remarkable about this is that it is regardless of the values of $A, B, C$, it only depends on $g(-h), g(0), g(h)$, which fixes what $A, B, C$ can be but we don't need to know them.

Now, to get the sum of all pairs we add them and get total approx area as
$$
S = \frac{h}{3}\left(y_0 + 4y_1 + 2y_2 + \dots + 4y_{n-1} + y_n\right)
$$
Again here $h = \dfrac{b - a}{n}$, $\ x_k = a + kh$, $\ y_k = f(x_k)$.

### Error Estimate for Simpson's Rule

If $f^{(4)}$ is continuous and $M$ is any upper bound for the values of $|f^{(4)}|$ on $[a, b]$, then
$$
|E_S| \le \frac{b - a}{180},h^4 M,\qquad E_S = \int_a^b f(x) dx - S
$$
### Which rule is better?

The answer lies in the error control formulas
$$
\begin{align}
|E_T| \le \frac{b - a}{12}\cdot h^2\cdot M,\qquad &\qquad |E_S| \le \frac{b - a}{180}\cdot h^4\cdot M
\end{align}
$$
If $h < 1$, then $h^4$ will be much smaller than $h^2$, but if $h > 1$ (rare), then $h^4 > h^2$.

Also the factor $\dfrac{b - a}{180}$ is 15 times smaller than $\dfrac{b - a}{12}$.


Hence, Simpson's Rule in general gives more accurate result.

But we still use trapezoidal rule as sometimes it gives much better and simpler formula & is also the basis of Romberg integration which [is a] high precision machine method.

**Example:** A town has a swamp 5 ft deep and shaped as shown, find the volume of the swamp, as that will give the amount of dirt we need to fill this up.
![](Pasted%20image%2020260925213815.png)
**Sol:** We will estimate the area of swamp and multiply with height to get approx volume.
$$
S = \frac{h}{3}\left(y_0 + 4y_1 + 2y_2 + 4y_3 + 2y_4 + 4y_5 + 2y_6 + 4y_7 + y_8\right)
$$
$$
S = \frac{h}{3}\left(146 + 4\cdot 122 + 2\cdot 76 + 4\cdot 54 + 2\cdot 40 + 4\cdot 30 + 2\cdot 30 + 4\cdot 25 + 13\right)
$$
$$
S = 8100
$$
$$
\implies \ \text{The volume} \approx 8100\cdot 5 = 40{,}500\ \text{ft}^3
$$
### Round-off Errors:

Although decreasing the step-size $h$ reduces the error in both the methods in theory, it may fail in practice.

This is due to computational limit of how precise we can store real numbers. If $h$ is very small we need to round up the results of calculations and those might end up increasing the overall error.

### Polynomials of Low Degree:

In trapezoidal rule the magnitude of error $= 0$ if $f''(x) = 0$ i.e. if $f$ is a straight line which is understandable.

What is surprising is that when using Simpson's rule, if $f^{(4)} = 0$, then also we will have $|E_S| = 0$. This means that all polynomials with degree $< 4$ give exact result with Simpson's method even if we use only 2 sub-intervals.

Consider $\displaystyle\int_0^2 x^3 dx = \frac{x^4}{4}\Bigg|_0^2 = 4 - 0 = 4$

Using Simpson's method with $n = 2 \implies  y_0 = 0^3 = 0,\ y_1 = 1^3 = 1$

$y_2 = 2^3 = 8$ & $h = \dfrac{2 - 0}{2} = 1 \implies  S = \dfrac{1}{3}\left(0 + 4\cdot 1 + 8\right) = \dfrac{12}{3} = 4$
$$
\implies \ \boxed{S = \int_0^2 x^3 dx}
$$

### Bounded Piecewise Continuous Functions

### Leibniz's Rule

If $f$ is continuous on $[a, b]$ and $u(x)$ & $v(x)$ are differentiable functions of $x$ whose values lie in $[a, b]$, then
$$
\frac{d}{dx}\int_{u(x)}^{v(x)} f(t) dt = f(v(x)),\frac{dv}{dx} - f(u(x)),\frac{du}{dx}
$$
**Proof:** Let $F$ be an anti-derivative of $f$
$$
\implies \ \int_a^b f(x) dx = F(b) - F(a).
$$
Now, using the additivity of limits of integrals we can write,
$$
\int_{u(x)}^{v(x)} f(t) dt = \int_a^{v(x)} f(t) dt - \int_a^{u(x)} f(t) dt
$$
$$
= F(v(x)) - F(a) - F(u(x)) + F(a)
$$
$$
= F(v(x)) - F(u(x))
$$
$$
\implies \ \frac{d}{dx}\left[\int_{u(x)}^{v(x)} f(t) dt\right] = F'(v(x)),v'(x) - F'(u(x)),u'(x)
$$
$$
\implies \ \frac{d}{dx}\int_{u(x)}^{v(x)} f(t) dt = f(v(x)),\frac{dv}{dx} - f(u(x)),\frac{du}{dx}
$$

### Geometric Interpretation of Leibniz's Rule

Let $A(x) = \displaystyle\int_{u(x)}^{v(x)} f(t) dt$, $\ A(x)$ is the area of the curve $f(t)$ b/w $t = u(x)$ & $t = v(x)$.
![](Pasted%20image%2020260925214147.png)
$\dfrac{dA}{dx}$ is the rate of change of this area w.r.t $x$. Clearly it increases at rate the right limit increases multiplied by its current value
$$
\implies \ \frac{d}{dx}F(v(x)) = f(v(x))\cdot v'(x)
$$
Similarly, area decreases at rate the left end changes times its current value.
$$
\implies \ \frac{dA}{dx} = f(v(x)),v'(x) - f(u(x)),u'(x).
$$
**Example:** Find $\dfrac{d}{dx}\displaystyle\int_{\sin x}^{x^2}(1 + t) dt$

**Sol:**
$$
\frac{d}{dx}\int_{\sin x}^{x^2}(1 + t) dt = \left(1 + x^2\right)\cdot 2x - (1 + \sin x)\cdot\cos x
$$
$$
= 2x^3 + 2x - \cos x - \cos x\cdot\sin x
$$
**Example:** Find the value of $x$ that maximizes the value of
$$

$$

**Sol:** the function $t(5 - t)$ is cont. $\forall, t \in \mathbb{R}$.

The integral $\displaystyle\int_x^{x+3} t(5 - t) dt$ is differentiable for all $x$
$$
\implies \ \frac{d}{dx}\left(\int_x^{x+3} t(5 - t) dt\right) = (x + 3)\left(5 - (x + 3)\right)\cdot 1 - x(5 - x)\cdot 1
$$
$$
= (x + 3)(2 - x) - x(5 - x)
$$
$$
= 2x + 6 - 3x - x^2 - 5x + x^2
$$
$$
= 6 - 6x
$$
$$
\implies \ \frac{dI}{dx} = 0 \implies  x = 1,\quad \text{only one critical point.}
$$
$$
\frac{d^2I}{dx^2} = -6 < 0,\quad \text{hence we get max at } x = 1
$$
$$
\implies \ I_{\max} = I(1) = \int_1^4 t(5 - t) dt = \left[\frac{5t^2}{2} - \frac{t^3}{3}\right]_1^4
$$
$$
= \left[40 - \frac{64}{3}\right] - \left[\frac{5}{2} - \frac{1}{3}\right]
$$
$$
= \frac{56}{3} - \frac{13}{6} = \frac{112 - 13}{6} = \frac{99}{6} = \frac{33}{2}
$$
$$
\implies \ I_{\max} = \frac{33}{2}
$$

### Approximating Finite Sums with Integrals

We know that integral is the limit of Riemann sums, but this property can be used in reverse to approximate the sum using integral.

**Example:** Estimate the sum $\sqrt{1} + \sqrt{2} + \dots + \sqrt{n}$ using integral.

**Sol:**
$$
\lim_{n \to \infty}\sqrt{\frac{1}{n}}\cdot\frac{1}{n} + \sqrt{\frac{2}{n}}\cdot\frac{1}{n} + \dots + \sqrt{\frac{n}{n}}\cdot\frac{1}{n} = \int_0^1 \sqrt{x} dx
$$
$$
\implies \ \lim_{n \to \infty}\frac{\sqrt{1} + \sqrt{2} + \dots + \sqrt{n}}{n^{3/2}} = \int_0^1 \sqrt{x} dx
$$
$$
\implies \ S_n = \sqrt{1} + \sqrt{2} + \dots + \sqrt{n} \approx n^{3/2}\int_0^1 \sqrt{x} dx = \frac{2}{3}\cdot n^{3/2}
$$
$$
\implies \ \boxed{\sqrt{1} + \sqrt{2} + \dots + \sqrt{n} \approx \frac{2}{3},n^{3/2}}
$$
**Note:** many finite sums can be modelled as integrals using the following rule.
$$
\lim_{n \to \infty}\frac{1}{n}\left[f\left(\frac{1}{n}\right) + f\left(\frac{2}{n}\right) + \dots + f\left(\frac{n}{n}\right)\right] = \int_0^1 f(x) dx
$$
**Example:** Evaluate **(a)** $1^5 + 2^5 + \dots + n^5$, $\quad$ **(b)** $2 + 4 + 6 + \dots + 2n$

**Sol:** **(a)**
$$
\lim_{n \to \infty}\frac{1}{n}\left[\left(\frac{1}{n}\right)^5 + \left(\frac{2}{n}\right)^5 + \dots + \left(\frac{n}{n}\right)^5\right] = \int_0^1 x^5 dx
$$
$$
\implies \ 1^5 + 2^5 + \dots + n^5 \approx \frac{n^6}{6}
$$
**(b)**
$$
\lim_{n \to \infty}\frac{1}{n}\left[\frac{2}{n} + \frac{4}{n} + \dots + \frac{2n}{n}\right] = \int_0^1 2x dx
$$
$$
\implies \ S_n = 2 + 4 + \dots + 2n \approx n^2
$$
This is what we expect from direct formula too i.e.
$$
S_n = 2 + 4 + \dots + 2n = 2(1 + 2 + \dots + n) = 2\cdot\frac{n(n + 1)}{2} = n(n + 1)
$$
at $n \to \infty$, $\ n(n + 1) \approx n^2$

**Example:** Evaluate $\displaystyle\lim_{n \to \infty}\frac{1}{n}\left[\sin\frac{\pi}{n} + \sin\frac{2\pi}{n} + \dots + \sin\frac{n\pi}{n}\right]$

**Sol:**
$$
\lim_{n \to \infty}\frac{1}{n}\left[\sin\frac{\pi}{n} + \sin\frac{2\pi}{n} + \dots + \sin\frac{n\pi}{n}\right] = \int_0^1 \sin\pi x dx
$$
$$
= \frac{-\cos\pi x}{\pi}\Bigg|_0^1 = \left[\frac{-(-1)}{\pi}\right] - \left[-\frac{1}{\pi}\right] = \frac{2}{\pi}
$$
**Example:** Evaluate **(a)** $\displaystyle\lim_{n \to \infty}\frac{1}{n^{17}}\left(1^{15} + 2^{15} + \dots + n^{15}\right)$

$\qquad\qquad\qquad$ **(b)** $\displaystyle\lim_{n \to \infty}\frac{1}{n^{15}}\left(1^{15} + 2^{15} + \dots + n^{15}\right)$

**Sol:** **(a)**
$$
\lim_{n \to \infty}\frac{1}{n^{17}}\left(1^{15} + \dots + n^{15}\right) = \lim_{n \to \infty}\frac{1}{n}\cdot\frac{1}{n}\left[\left(\frac{1}{n}\right)^{15} + \dots + \left(\frac{n}{n}\right)^{15}\right]
$$
$$
= \lim_{n \to \infty}\frac{1}{n}\cdot\lim_{n \to \infty}\frac{1}{n}\left[\left(\frac{1}{n}\right)^{15} + \dots + \left(\frac{n}{n}\right)^{15}\right] = \left(\lim_{n \to \infty}\frac{1}{n}\right)\int_0^1 x^{15} dx
$$
$$
= \lim_{n \to \infty}\frac{1}{n}\cdot\frac{1}{16} = 0
$$
**(b)**
$$
\lim_{n \to \infty}\frac{1}{n^{15}}\left[1^{15} + \dots + n^{15}\right] = \lim_{n \to \infty} n\cdot\lim_{n \to \infty}\frac{1}{n}\left[\frac{1^{15}}{n^{15}} + \dots + \frac{n^{15}}{n^{15}}\right]
$$
$$
\implies \ \lim_{n \to \infty} n\cdot\int_0^1 x^{15} dx = \lim_{n \to \infty}\frac{n}{16} = \infty
$$
