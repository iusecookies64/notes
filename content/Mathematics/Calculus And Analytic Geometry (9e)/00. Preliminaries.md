# Real Numbers and the Real Line

Much of calculus is built upon the foundational properties of the real number system. Real numbers can be represented analytically as decimals and geometrically as points along an infinite, continuous line known as the **real line** ($\mathbb{R}$).

## 1. Decimal Representation and the Real Line

Every real number can be expressed in decimal form:

- **Terminating decimals:**
    $$
    -\frac{3}{4} = -0.75000\dots = -0.75
    $$
 - **Repeating decimals:**
	$$
	\frac{1}{3} = 0.33333\dots = 0.\overline{3}
	$$
- **Nonterminating, nonrepeating decimals:**
	$$
	\sqrt{2} = 1.41421\dots
	$$
The real numbers are mapped in a one-to-one correspondence with points on a horizontal line called the **real line**, denoted by the symbol $\mathbb{R}$.

## 2. Subsets of the Real Numbers

The real number system $\mathbb{R}$ contains several distinguished nested subsets:

1. **Natural Numbers ($\mathbb{N}$):** The counting numbers
	$$
	\mathbb{N} = \{1, 2, 3, 4, \dots\}
	$$
2. **Integers ($\mathbb{Z}$):** The natural numbers, their negatives, and zero
	$$
	\mathbb{Z} = \{\dots, -3, -2, -1, 0, 1, 2, 3, \dots\}
	$$
3. **Rational Numbers ($\mathbb{Q}$):** Numbers expressible as the quotient of two integers:
	$$
	\mathbb{Q} = \left\{ \frac{m}{n} \;\middle\vert{}\; m, n \in \mathbb{Z},\, n \neq 0 \right\}
	$$
    - _Examples:_ $\frac{1}{39},\, \frac{4}{13},\, \frac{200}{1},\, 57 = \frac{57}{1}$.
        
    - Rational numbers have decimal expansions that either:
          
        - **Terminate:** e.g., $\frac{3}{4} = 0.75$
            
        - **Repeat:** e.g., $\frac{23}{11} = 2.090909\dots = 2.\overline{09}$ (the bar denotes the repeating block of digits).
            
4. **Irrational Numbers:** Real numbers that cannot be expressed as a ratio of integers ($\mathbb{R} \setminus \mathbb{Q}$). Their decimal expansions are nonterminating and nonrepeating.
      
    - _Examples:_ $\pi,\, \sqrt{2},\, \sqrt{5},\, \log_{10} 3$.

## 3. Properties of the Real Number System

The properties governing $\mathbb{R}$ fall into three foundational categories:

### A. Algebraic Properties

The real numbers form a field under standard addition and multiplication. They can be added, subtracted, multiplied, and divided (with division by $0$ strictly undefined) under the standard laws of arithmetic (associativity, commutativity, distributivity, and existence of identities and inverses).

### B. Order Properties

For any real numbers $a$, $b$, and $c$, the following order rules apply:

1. **Addition Rule:**
$$
a < b \implies a + c < b + c
$$
2. **Subtraction Rule:**
$$
a < b \implies a - c < b - c
$$
3. **Positive Multiplication Rule:**
$$
a < b \quad \text{and} \quad c > 0 \implies ac < bc
$$
4. **Negative Multiplication Rule:** Multiplying by a negative number reverses the inequality:
	$$
	a < b \quad \text{and} \quad c < 0 \implies bc < ac \quad (\text{or } ac > bc)
	$$
    _Special Case ($c = -1$):_
	$$
	a < b \implies -b < -a
	$$
5. **Reciprocal Positivity:**
$$
a > 0 \implies \frac{1}{a} > 0
$$
6. **Reciprocal Rule for Same-Sign Numbers:** If $a$ and $b$ are both positive or both negative, taking reciprocals reverses the inequality:
	$$
	a < b \implies \frac{1}{b} < \frac{1}{a}
	$$

### C. The Completeness Property

The rational numbers $\mathbb{Q}$ satisfy all algebraic and order properties of $\mathbb{R}$, but they lack **completeness**. For instance, there is no rational number $x$ such that $x^2 = 2$; there is a "gap" or "hole" in the rational line where $\sqrt{2}$ should be.

> The **Completeness Property** guarantees that the real line $\mathbb{R}$ has no "holes" or "gaps." Every nonempty set of real numbers that is bounded above possesses a least upper bound (supremum) in $\mathbb{R}$.

## 4. Intervals

An **interval** is a subset of the real line that contains at least two numbers and contains all real numbers lying between any two of its elements.

- **Finite Intervals:** Represent bounded line segments on the real line.
    
- **Infinite Intervals:** Represent unbounded rays or the entire real line.
    
- **Boundary Points vs. Interior Points:** The endpoints of an interval are its _boundary points_. All points inside the interval that are not boundary points are _interior points_.
    - **Closed Interval:** Contains both boundary points.
        
    - **Open Interval:** Contains neither boundary point.
        
    - **Half-Open Interval:** Contains exactly one boundary point.

### Table 1: Types of Intervals

| **Notation**        | **Set Description**                       | **Type**        | **Classification** |
| ------------------- | ----------------------------------------- | --------------- | ------------------ |
| $(a, b)$            | $\{x \in \mathbb{R} \mid a < x < b\}$     | Open            | Finite             |
| $[a, b]$            | $\{x \in \mathbb{R} \mid a \le x \le b\}$ | Closed          | Finite             |
| $[a, b)$            | $\{x \in \mathbb{R} \mid a \le x < b\}$   | Half-open       | Finite             |
| $(a, b]$            | $\{x \in \mathbb{R} \mid a < x \le b\}$   | Half-open       | Finite             |
| $(a, \infty)$       | $\{x \in \mathbb{R} \mid x > a\}$         | Open ray        | Infinite           |
| $[a, \infty)$       | $\{x \in \mathbb{R} \mid x \ge a\}$       | Closed ray      | Infinite           |
| $(-\infty, b)$      | $\{x \in \mathbb{R} \mid x < b\}$         | Open ray        | Infinite           |
| $(-\infty, b]$      | $\{x \in \mathbb{R} \mid x \le b\}$       | Closed ray      | Infinite           |
| $(-\infty, \infty)$ | $\mathbb{R}$ (all real numbers)           | Open and Closed | Infinite           |

### Set Operations: Union ($\cup$) and Intersection ($\cap$)

- **Union ($A \cup B$):** The set of elements belonging to either $A$, $B$, or both:
$$
x \in A \cup B \iff x \in A \quad \text{or} \quad x \in B
$$
- **Intersection ($A \cap B$):** The set of elements belonging to both $A$ and $B$:
$$
x \in A \cap B \iff x \in A \quad \text{and} \quad x \in B
$$
    - _Example:_ $[1, 3) \cap [2, 4] = [2, 3)$.

## 5. Solving Linear and Fractional Inequalities

Solving an inequality means determining the set of all real numbers satisfying the inequality, typically expressed as an interval or union of intervals.

### Example 1: Basic Inequalities

1. Solve $2x - 1 < x + 3$:
	$$
	\begin{align}
	2x - 1 &< x + 3 \\
	2x &< x + 4 && \text{(Add } 1 \text{ to both sides)} \\
	x &< 4 && \text{(Subtract } x \text{ from both sides)}
	\end{align}
	$$ 
	The solution set is the open interval $(-\infty, 4)$.
    
2. Solve $-\frac{x}{3} < 2x + 1$:
    $$
    \begin{align}
    
    -\frac{x}{3} &< 2x + 1 \\
    
    -x &< 6x + 3 && \text{(Multiply both sides by } 3\text{)} \\
    
    0 &< 7x + 3 && \text{(Add } x \text{ to both sides)} \\
    
    -3 &< 7x && \text{(Subtract } 3 \text{ from both sides)} \\
    
    -\frac{3}{7} &< x && \text{(Divide by } 7\text{)}
    
    \end{align}
    $$
    The solution set is the open interval $\left(-\frac{3}{7}, \infty\right)$.
    
1. Solve $\frac{6}{x - 1} \ge 5$:
    $$
    \begin{align}
    
    \frac{6}{x - 1} &\ge 5
    
    \end{align}
    $$
    The fraction can only be $\ge 5$ if the denominator is strictly positive; if $x < 1$, the denominator is negative, making the fraction negative, which cannot be $\ge 5$. Furthermore, $x \neq 1$ because division by zero is undefined. Thus, $x > 1$.
    
    Multiplying by $(x - 1) > 0$ preserves the inequality:
    $$
    \begin{align}
    
    6 &\ge 5(x - 1) \\
    
    6 &\ge 5x - 5 \\
    
    11 &\ge 5x \\
    
    x &\le \frac{11}{5}
    
    \end{align}
    $$
    Combining $x > 1$ with $x \le \frac{11}{5}$ gives the half-open interval $\left(1, \frac{11}{5}\right]$.

## 6. Absolute Value

The **absolute value** (or magnitude) of a real number $x$, denoted $\vert{}x\vert{}$, is defined piecewise:
$$
\vert{}x\vert{} = \begin{cases} x, & \text{if } x \ge 0 \\ -x, & \text{if } x < 0 \end{cases}
$$

### Key Properties

- $\vert{}x\vert{} \ge 0$ for every real number $x$.
    
- $\vert{}x\vert{} = 0 \iff x = 0$.
    
- $\vert{}x\vert{} = \sqrt{x^2}$.

> **Important Warning:**
> $$
> \sqrt{a^2} = |a|
> $$
> Do not write $\sqrt{a^2} = a$ unless it is already known that $a \ge 0$.

### Geometric Interpretation

Geometrically, $\vert{}x\vert{}$ is the distance between $x$ and the origin $0$. More generally, the distance between any two numbers $x$ and $y$ on the real line is given by:
$$
\text{Distance}(x, y) = \vert{}x - y\vert{} = \vert{}y - x\vert{}
$$
![](Pasted%20image%2020260920184933.png)

### Algebraic Properties of Absolute Values

1. **Negation:**
	$$
	\vert{}-a\vert{} = \vert{}a\vert{}
	$$
2. **Product Rule:**
	$$
	\vert{}ab\vert{} = \vert{}a\vert{}\vert{}b\vert{}
	$$
3. **Quotient Rule:**
	$$
	\left\vert{}\frac{a}{b}\right\vert{} = \frac{\vert{}a\vert{}}{\vert{}b\vert{}} \quad (b \neq 0)
	$$
4. **The Triangle Inequality:**
	$$
	\vert{}a + b\vert{} \le \vert{}a\vert{} + \vert{}b\vert{}
	$$
    - Equality holds if and only if $a$ and $b$ have the same sign (or at least one is zero).
        
    - Strict inequality holds if $a$ and $b$ have opposite signs.

### Example 2: Verifying the Triangle Inequality

- Opposite signs:
	$$
	\vert{}-3 + 5\vert{} = \vert{}2\vert{} = 2 < \vert{}-3\vert{} + \vert{}5\vert{} = 3 + 5 = 8
	$$
- Same signs (positive):
	$$
	\vert{}3 + 5\vert{} = \vert{}8\vert{} = 8 = \vert{}3\vert{} + \vert{}5\vert{}
	$$
- Same signs (negative):
	$$
	\vert{}-3 - 5\vert{} = \vert{}-8\vert{} = 8 = \vert{}-3\vert{} + \vert{}-5\vert{} = 3 + 5 = 8
	$$

### Example 3: Absolute Value Equations

Solve $\vert{}2x - 3\vert{} = 7$:
$$
\begin{align}

2x - 3 &= 7 & \text{or} & & 2x - 3 &= -7 \\

2x &= 10 & & & 2x &= -4 \\

x &= 5 & & & x &= -2

\end{align}
$$
The solutions are $x = 5$ and $x = -2$.

## 7. Inequalities Involving Absolute Values

For any positive constant $D > 0$:
$$
\begin{align}
\vert{}a\vert{} < D &  \iff -D < a < D \\
\vert{}a\vert{} \le D  & \iff -D \le a \le D \\
\vert{}a\vert{} > D  & \iff a > D \quad \text{or} \quad a < -D \\
\vert{}a\vert{} \ge D  & \iff a \ge D \quad \text{or} \quad a \le -D
\end{align}
$$
### Example 4: Open Bounded Absolute Value Inequality

Solve $\vert{}x - 5\vert{} < 9$:
$$
\begin{align}
-9 &< x - 5 < 9 \\
-9 + 5 &< x < 9 + 5 && \text{(Add } 5 \text{ across all components)} \\
-4 &< x < 14
\end{align}
$$
The solution set is the open interval $(-4, 14)$.

![](Pasted%20image%2020260920185255.png)

### Example 5: Variable in the Denominator

Solve $\left\vert{}5 - \frac{2}{x}\right\vert{} < 1$:
$$
\begin{align}
-1 &< 5 - \frac{2}{x} < 1 \\
-6 &< -\frac{2}{x} < -4 && \text{(Subtract } 5\text{)} \\
3 &> \frac{1}{x} > 2 && \text{(Multiply by } -\tfrac{1}{2}\text{; reverses inequalities)} \\
2 &< \frac{1}{x} < 3 \\
\frac{1}{2} &> x > \frac{1}{3} && \text{(Take reciprocals of positive terms; reverses inequalities)} \\
\frac{1}{3} &< x < \frac{1}{2}
\end{align}
$$
The solution set is the open interval $\left(\frac{1}{3}, \frac{1}{2}\right)$.
### Example 6: Comparison of $\le$ and $\ge$

1. Solve $\vert{}2x - 3\vert{} \le 1$:
   $$ 
    \begin{align}
    
    -1 &\le 2x - 3 \le 1 \\
    
    2 &\le 2x \le 4 && \text{(Add } 3\text{)} \\
    
    1 &\le x \le 2 && \text{(Divide by } 2\text{)}
    
    \end{align}
    $$
    The solution set is the closed interval $[1, 2]$.
    
2. Solve $\vert{}2x - 3\vert{} \ge 1$:
    $$
    \begin{align}
    
    2x - 3 &\ge 1 & \text{or} & & 2x - 3 &\le -1 \\
    
    2x &\ge 4 & & & 2x &\le 2 \\
    
    x &\ge 2 & & & x &\le 1
    
    \end{align}
    $$
    The solution set is the unbounded union $(-\infty, 1] \cup [2, \infty)$.

# Coordinates, Lines, and Increments

## 1. Cartesian Coordinates in the Plane

The position of any point in a two-dimensional plane is uniquely determined with respect to two mutually perpendicular real lines intersecting at their zero points. These lines are designated as the **coordinate axes**:

- **$x$-axis:** The horizontal line, with real numbers increasing to the right.
    
- **$y$-axis:** The vertical line, with real numbers increasing upward.
    
- **Origin ($O$):** The point of intersection $(0, 0)$ where both $x = 0$ and $y = 0$.

For any point $P$ in the plane, perpendicular lines dropped to the $x$-axis and $y$-axis intersect at real numbers $a$ and $b$, respectively. The ordered pair $(a, b)$ constitutes the **coordinate pair** of $P$:

- $a$ is the **$x$-coordinate** (abscissa).
    
- $b$ is the **$y$-coordinate** (ordinate).

The coordinate axes divide the plane into four infinite regions called **quadrants**, numbered counterclockwise:

### Table 1: Signs of Coordinates in the Quadrants

| **Quadrant**     | **x-Coordinate**   | **y-Coordinate**   | **Sign Pattern (x,y)** |
| ---------------- | ------------------ | ------------------ | ---------------------- |
| **Quadrant I**   | Positive ($x > 0$) | Positive ($y > 0$) | $(+, +)$               |
| **Quadrant II**  | Negative ($x < 0$) | Positive ($y > 0$) | $(-, +)$               |
| **Quadrant III** | Negative ($x < 0$) | Negative ($y < 0$) | $(-, -)$               |
| **Quadrant IV**  | Positive ($x > 0$) | Negative ($y < 0$) | $(+, -)$               |

Points lying on the axes do not belong to any quadrant:

- Every point on the $x$-axis has coordinates of the form $(x, 0)$.
    
- Every point on the $y$-axis has coordinates of the form $(0, y)$.

## 2. Scales and Aspect Ratio

When graphing mathematical and physical relationships, the choice of axis scaling dictates geometric fidelity:

- **Equal Scales (Aspect Ratio = 1):** Essential for geometric and trigonometric analyses where variables do not represent mismatched physical units. Preserves distance proportions, segment lengths, congruence of angles, and circular geometries.
    
- **Unequal Scales:** Applied when plotting distinct physical quantities (e.g., time in seconds versus force in pounds).
    
- **Display Distortion:** Screen displays or computer graphing software with an aspect ratio unequal to $1$ distort geometric properties: circles render as ellipses, squares render as rectangles, and perpendicular angles appear acute or obtuse.

## 3. Increments and the Distance Formula

### Coordinate Increments

When a particle moves from a starting point $P_1(x_1, y_1)$ to an ending point $P_2(x_2, y_2)$, the net changes in its coordinates are defined as **increments**:
$$
\Delta x = x_2 - x_1 \quad (\text{the run})
$$
$$
\Delta y = y_2 - y_1 \quad (\text{the rise})
$$
Increments may be positive, negative, or zero depending on the direction of displacement.

### The Distance Formula

Applying the Pythagorean theorem to the right triangle formed by the points $P_1(x_1, y_1)$, $P_2(x_2, y_2)$, and the vertex $C(x_2, y_1)$:

$$
\begin{align}
d^2 &= (\Delta x)^2 + (\Delta y)^2 \\
d &= \sqrt{(\Delta x)^2 + (\Delta y)^2} = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
\end{align}
$$
  
> $$
> d(P_1, P_2) = \sqrt{(x_2 - x_1)^2 + (y_2 - y_1)^2}
> $$

- **Distance from the Origin:** The distance from $O(0, 0)$ to any point $P(x, y)$ simplifies to:
$$
d = \sqrt{x^2 + y^2}
$$

## 4. Graphs of Equations and Inequalities

The **graph** of an equation or inequality in $x$ and $y$ consists of the set of all points $P(x, y)$ whose coordinates satisfy the given relation:

- **Circle Centered at the Origin:** For a constant radius $a > 0$, the set of all points at distance $a$ from $(0, 0)$ satisfies:
	$$
	x^2 + y^2 = a^2
	$$
- **Unit Circle:** The circle of radius $1$ centered at the origin:
	$$
	x^2 + y^2 = 1
	$$
- **Circular Disk (Region):** The set of all points lying on or inside the circle of radius $a$:
	$$
	x^2 + y^2 \le a^2
	$$
- **Standard Parabola:** The locus of points satisfying the quadratic relation:
	$$
	y = x^2
	$$

## 5. Straight Lines and Slope

Any two distinct points $P_1(x_1, y_1)$ and $P_2(x_2, y_2)$ in the coordinate plane uniquely define a straight line.

### Definition of Slope

For any nonvertical line, the ratio of the vertical change ($\Delta y$) to the horizontal change ($\Delta x$) is invariant across any two chosen points due to the properties of similar right triangles:
$$
m = \frac{\text{rise}}{\text{run}} = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1} \quad (x_1 \neq x_2)
$$

### Properties of Slope

1. **Positive Slope ($m > 0$):** The line rises from left to right.
    
2. **Negative Slope ($m < 0$):** The line falls from left to right.
    
3. **Zero Slope ($m = 0$):** The line is completely horizontal ($\Delta y = 0$).
    
4. **Undefined Slope:** For vertical lines, $\Delta x = 0$, making the ratio $\frac{\Delta y}{\Delta x}$ undefined.
    
5. **Magnitude ($\vert{}m\vert{}$):** Measures steepness; larger values of $\vert{}m\vert{}$ indicate steeper lines.

![](Pasted%20image%2020260920190210.png)

## 6. Angle of Inclination

The steepness and direction of a line crossing the $x$-axis can be defined trigonometrically by its **angle of inclination** ($\phi$):

- $\phi$ is the smallest angle measured counterclockwise from the positive direction of the $x$-axis to the line.
    
- The range of inclination is restricted to:
	$$
	0^\circ \le \phi < 180^\circ \quad (\text{or } 0 \le \phi < \pi)
	$$
- **Horizontal Line:** $\phi = 0^\circ$.
    
- **Vertical Line:** $\phi = 90^\circ$ ($\frac{\pi}{2}\text{ rad}$).

### Relation Between Slope and Inclination

From the right triangle formed by the increments $\Delta x$ and $\Delta y$:
$$
m = \tan \phi \quad (\text{for } \phi \neq 90^\circ)
$$

![](Pasted%20image%2020260920190324.png)

## 7. Parallel and Perpendicular Lines

Let $L_1$ and $L_2$ be two nonvertical lines with slopes $m_1$ and $m_2$ and inclinations $\phi_1$ and $\phi_2$, respectively:

### Parallel Lines

Lines that are parallel share identical directions and angles of inclination:
$$
\phi_1 = \phi_2 \iff m_1 = m_2
$$

### Perpendicular Lines

If two nonvertical lines $L_1$ and $L_2$ are perpendicular ($L_1 \perp L_2$), their angles of inclination differ by $90^\circ$ ($\phi_2 = \phi_1 + 90^\circ$):
$$
\begin{align}
m_2 &= \tan(\phi_1 + 90^\circ) \\
&= -\cot \phi_1 \\
&= -\frac{1}{\tan \phi_1} \\
&= -\frac{1}{m_1}
\end{align}
$$
Thus, the slopes are negative reciprocals of each other:
$$
m_1 m_2 = -1 \iff m_2 = -\frac{1}{m_1}
$$

## 8. Equations of Straight Lines

### Table 2: Standard Forms of Linear Equations

| **Equation Form**        | **Formula**            | **Description & Characteristics**                                                    |
| ------------------------ | ---------------------- | ------------------------------------------------------------------------------------ |
| **Vertical Line**        | $x = a$                | Undefined slope; crosses the $x$-axis at $(a, 0)$.                                   |
| **Horizontal Line**      | $y = b$                | Slope $m = 0$; crosses the $y$-axis at $(0, b)$.                                     |
| **Point-Slope Form**     | $y - y_1 = m(x - x_1)$ | Line passing through known point $(x_1, y_1)$ with known slope $m$.                  |
| **Slope-Intercept Form** | $y = mx + b$           | Line with slope $m$ and $y$-intercept $b$ at point $(0, b)$.                         |
| **General Linear Form**  | $Ax + By = C$          | $A$ and $B$ not both zero; represents every possible line, including vertical lines. |

### Intercepts

- **$y$-intercept ($b$):** The $y$-coordinate of the point where the line crosses the $y$-axis (evaluated at $x = 0$).
    
- **$x$-intercept ($a$):** The $x$-coordinate of the point where the line crosses the $x$-axis (evaluated at $y = 0$).
    
- **Lines Through the Origin:** A line with $y$-intercept $b = 0$ reduces to the direct proportionality equation:
	$$
	y = mx
	$$

## 9. Applications and the Significance of Slope

- **Linear Trajectories:** Uniform motion without external transverse forces (e.g., free-fall trajectory under one-dimensional gravity, or inertial gliding) follows linear equations.
    
- **Rates of Change:** The fundamental interpretation of slope is the ratio of changes:
	$$
	m = \frac{\Delta y}{\Delta x}
	$$
    This constant rate of change serves as the foundation for the derivative in differential calculus, which generalizes the concept of slope to non-linear curves.

# Functions

Functions serve as the primary mathematical instruments for modeling quantitative relationships and dependencies in the real world.

## 1. Formal Definition of a Function

A function defines a rule of deterministic dependence where the value of a dependent variable is uniquely specified by the value of an independent variable.

> A **function** $f$ from a set $D$ to a set $R$ is a rule that assigns a unique element $f(x) \in R$ to each element $x \in D$.

- **Domain ($D$ or $D(f)$):** The set of all admissible input values.
    
- **Codomain ($R$):** A target set containing all possible outputs.
    
- **Range:** The exact set of all assigned output values:
	$$
	\text{Range}(f) = \{f(x) \in R \mid x \in D\}
	$$
- **Independent Variable:** The input variable (commonly denoted $x$).
    
- **Dependent Variable:** The output variable (commonly denoted $y$), whose value depends on the input:
	$$
	y = f(x)
	$$
Strictly speaking, the symbol $f$ designates the function itself, whereas $f(x)$ designates the value of the function evaluated at the point $x$.

![](Pasted%20image%2020260920191012.png)

## 2. Real-Valued Functions and the Natural Domain Convention

In calculus, functions typically map subsets of real numbers to subsets of real numbers ($f: D \to \mathbb{R}$, where $D \subseteq \mathbb{R}$).

### The Natural Domain Convention

When a function is defined by a formula $y = f(x)$ without an explicitly stated domain, its **natural domain** is assumed to be the largest subset of $\mathbb{R}$ for which the formula yields real values.

A formula's natural domain is constrained by foundational algebraic restrictions:

1. **Division by Zero:** Denominators cannot be zero:
	$$
	y = \frac{A(x)}{B(x)} \implies B(x) \neq 0
	$$
2. **Even Radicands:** Expressions under an even root must be nonnegative:
	$$
	y = \sqrt[2k]{g(x)} \implies g(x) \ge 0 \quad (k \in \mathbb{N})
	$$
Restricting the domain of a formula inherently restricts the corresponding range.

## 3. Graphs of Functions and the Vertical Line Test

The **graph** of a function $f$ consists of all coordinate points $(x, y)$ in the Cartesian plane that satisfy the relationship $y = f(x)$:
$$
\text{Graph}(f) = \left\{ (x, y) \in \mathbb{R}^2 \;\middle\vert{}\; x \in D(f),\, y = f(x) \right\}
$$
### The Vertical Line Test

Because a function assigns exactly one output value $f(x)$ to each input value $x$ in its domain, no input may correspond to multiple outputs.

> A curve in the $xy$-plane represents the graph of a function of $x$ if and only if no vertical line intersects the curve at more than one point.

- If $a \in D(f)$, the vertical line $x = a$ intersects the graph of $f$ at precisely the single point $(a, f(a))$.
    
- If a vertical line crosses a curve at two or more points, the curve does not represent a function $y = f(x)$.

|**Reciprocal**|$y = \frac{1}{x}$|$(-\infty, 0) \cup (0, \infty)$|$(-\infty, 0) \cup (0, \infty)$|Hyperbola asymptotic to both axes|

## 4. Arithmetic Operations on Functions

Functions can be combined algebraically to generate new functions. Let $f$ and $g$ be functions with domains $D(f)$ and $D(g)$, respectively:

### Table of Algebraic Combinations

| **Operation**             | **Notation & Formula**                            | **Effective Domain**                        |
| ------------------------- | ------------------------------------------------- | ------------------------------------------- |
| **Sum**                   | $(f + g)(x) = f(x) + g(x)$                        | $D(f) \cap D(g)$                            |
| **Difference**            | $(f - g)(x) = f(x) - g(x)$                        | $D(f) \cap D(g)$                            |
| **Product**               | $(fg)(x) = f(x) \cdot g(x)$                       | $D(f) \cap D(g)$                            |
| **Scalar Multiplication** | $(cf)(x) = c \cdot f(x)$                          | $D(f) \quad (c \in \mathbb{R})$             |
| **Quotient**              | $\left(\frac{f}{g}\right)(x) = \frac{f(x)}{g(x)}$ | $\{x \in D(f) \cap D(g) \mid g(x) \neq 0\}$ |

## 5. Composite Functions

Function composition combines functions in series, where the output of one function serves as the direct input to another.

> Given two functions $f$ and $g$, the **composite function** $f \circ g$ ("$f$ circle $g$") is defined by:
>$$
>(f \circ g)(x) = f(g(x))
>$$

### Domain of a Composite Function

The domain of $f \circ g$ consists of all numbers $x$ in the domain of $g$ whose evaluated values $g(x)$ lie within the domain of $f$:
$$
D(f \circ g) = \{x \in D(g) \mid g(x) \in D(f)\}
$$
### Core Properties

- **Process Sequence:** In $(f \circ g)(x)$, the interior function $g$ evaluates first; the exterior function $f$ evaluates second.
    
- **Non-Commutativity:** In general, function composition does not commute:
	$$
	(f \circ g)(x) \neq (g \circ f)(x)
	$$
- **Self-Composition:** A function can be composed with itself:
	$$
	(f \circ f)(x) = f(f(x))
	$$

## 6. Symmetry: Even and Odd Functions

A function's algebraic behavior under coordinate negation dictates its geometric symmetry.
### Domain Symmetry Precondition

For a function to be classified as even or odd, its domain $D(f)$ must be symmetric about the origin:
$$
x \in D(f) \iff -x \in D(f)
$$

### Classification and Geometric Symmetry

|**Property**|**Even Function**|**Odd Function**|
|---|---|---|
|**Defining Equation**|$f(-x) = f(x)$|$f(-x) = -f(x)$|
|**Geometric Symmetry**|Symmetric with respect to the **$y$-axis**|Symmetric with respect to the **origin**|
|**Coordinate Locus**|$(x, y) \in \text{Graph} \iff (-x, y) \in \text{Graph}$|$(x, y) \in \text{Graph} \iff (-x, -y) \in \text{Graph}$|
|**Geometric Behavior**|Reflection across the vertical axis produces identical curve|$180^\circ$ rotation about $(0,0)$ produces identical curve|

## 7. Piecewise-Defined and Integer Step Functions

A **piecewise-defined function** uses distinct algebraic formulas on non-overlapping intervals of its domain.

### Absolute Value Function

Defined piecewise by splitting the real domain at the origin:
$$
\vert{}x\vert{} = \begin{cases} x, & \text{if } x \ge 0 \\ -x, & \text{if } x < 0 \end{cases}
$$

### Step and Integer Functions

#### 1. Greatest Integer Function (Integer Floor Function)

Denoted by $\lfloor x \rfloor$ (or $[x]$, $[\![x]\!]$), it assigns to any real number $x$ the greatest integer less than or equal to $x$:
$$
\lfloor x \rfloor = n \iff n \le x < n + 1 \quad (n \in \mathbb{Z})
$$

- **Geometric Characteristic:** The graph forms a step curve that lies strictly on or below the diagonal line $y = x$, providing an integer floor for $x$.

#### 2. Least Integer Function (Integer Ceiling Function)

Denoted by $\lceil x \rceil$, it assigns to any real number $x$ the smallest integer greater than or equal to $x$:
$$
\lceil x \rceil = n \iff n - 1 < x \le n \quad (n \in \mathbb{Z})
$$

- **Geometric Characteristic:** The graph forms a step curve that lies strictly on or above the diagonal line $y = x$, providing an integer ceiling for $x$.
