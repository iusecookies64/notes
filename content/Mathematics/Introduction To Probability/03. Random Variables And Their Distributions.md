## 3.1: Random Variables

In complex probability problems, defining events using set-theoretic notation (unions, intersections, subsets) quickly becomes unwieldy.

**Limitations of pure event notation:**

- Expressing composite quantities (e.g., game duration, difference in wealth) requires long, awkward chains of events.

- Events cannot undergo arithmetic operations (e.g., multiplying an event by a currency exchange rate is undefined).
 
**The Solution:** Define numerical quantities that depend on the outcome of an experiment.

**Example (Gambler's Ruin):** Let $X_k$ be gambler A's wealth after $k$ rounds.

- Wealth of gambler B: $Y_k = N - X_k$ (where $N$ is total wealth)

- Difference in wealth: $X_k - Y_k = 2X_k - N$

- Wealth in euros: $c_k X_k$ (where $c_k$ is the exchange rate)

- Game duration: $R = \min\{n : X_n = 0 \text{ or } Y_n = 0\}$

#### Definition of Random Variable

Given an experiment with sample space $S$, a **random variable (r.v.)** is a function $X$ mapping the sample space $S$ to the real numbers $\mathbb{R}$:
$$X : S \to \mathbb{R}$$
For each outcome $s \in S$, $X$ assigns a deterministic numerical value $X(s)$.
![](Pasted%20image%2020260908093252.png)
- **Notation:** Capital letters ($X, Y, Z$) typically denote random variables.
     
- **Source of Randomness:** The mapping $X(s)$ itself is strictly deterministic. The randomness arises solely from the underlying experiment choosing a sample outcome $s \in S$ according to a probability function $P$.
     
- **Pebble Metaphor:**
    - Outcomes $s_i \in S$ are "pebbles" with masses representing their probabilities $P(s_i)$, summing to $1$.
         
    - An r.v. simply writes a real number label on each pebble.
![](Pasted%20image%2020260908093219.png)
##### Timing & Crystallization

|**Stage**|**Status of X**|**Description**|
|---|---|---|
|**Before the experiment**|Function / Variable|Outcome $s$ is unknown. $X$ has not taken a specific value, but we can compute probabilities of events like $P(X = x)$ or $P(a \le X \le b)$.|
|**After the experiment**|Fixed Real Number|Outcome $s$ is realized, and $X$ "crystallizes" into the static numerical value $X(s)$.|

##### Example: Two Fair Coin Tosses

Experiment: Toss a fair coin twice. Sample space $S = \{HH, HT, TH, TT\}$.

- **Number of Heads ($X$):**
    - $X(HH) = 2, \quad X(HT) = X(TH) = 1, \quad X(TT) = 0$
        
    - Possible values: $\{0, 1, 2\}$
        
- **Number of Tails ($Y$):**
    - $Y = 2 - X$
        
- **Indicator Random Variable ($I$):**
    - An indicator r.v. takes value $1$ if a specific event occurs and $0$ otherwise.
        
    - Let $I$ indicate whether the first toss is Heads:
$$I(HH) = 1, \quad I(HT) = 1, \quad I(TH) = 0, \quad I(TT) = 0$$

**Algebraic Encoding:**

If $S$ is encoded as pairs $(s_1, s_2) \in \{0, 1\}^2$ where $1 = \text{Heads}$ and $0 = \text{Tails}$:
- $X(s_1, s_2) = s_1 + s_2$
     
- $Y(s_1, s_2) = 2 - s_1 - s_2$
     
- $I(s_1, s_2) = s_1$

## 3.2: Distributions and Probability Mass Functions

A random variable (r.v.) can be categorized primarily as either discrete or continuous, though hybrid r.v.s also exist (such as generating a discrete r.v. if a coin lands Heads and a continuous r.v. if Tails).

##### Discrete Random Variables and Support

- **Discrete Random Variable:** A random variable $X$ is discrete if there exists a finite list of values $a_1, a_2, \dots, a_n$ or a countably infinite list $a_1, a_2, \dots$ such that:
 $$P(X = a_j \text{ for some } j) = 1$$
    In other words, $X$ can take only one of these values and not any other outside from this set.
    
- **Support:** The finite or countably infinite set of values $x$ such that $P(X = x) > 0$. In most applications, the support is a set of integers.
     
- **Continuous Random Variable (Contrast):** Can take on any real value in an interval (possibly the entire real line).

##### Distribution and the Probability Mass Function (PMF)

The **distribution** of an r.v. specifies the probabilities of all events associated with it. For a discrete r.v., the most natural way to represent the distribution is via a PMF.

- **Definition:** The probability mass function of a discrete r.v. $X$ is the function $p_X$ given by:
 $$p_X(x) = P(X = x)$$
    
    - $p_X(x) > 0$ if $x$ is in the support of $X$.
         
    - $p_X(x) = 0$ otherwise.
 
>[!Note] **Events vs. Random Variables**
> - The expression $X = x$ is shorthand for the event $\{s \in S : X(s) = x\}$, which is a subset of the sample space $S$.
> - Because $\{X = x\}$ is an event, it is mathematically valid to write $P(X = x)$.
> - It is invalid to write $P(X)$; probability applies to events, not to random variables.

#### Examples of PMFs

**Two Fair Coin Tosses**

Sample space: $S = \{HH, HT, TH, TT\}$.

- $X$ = Number of Heads:
    - $p_X(0) = P(X = 0) = 1/4$ (outcome: $TT$)
         
    - $p_X(1) = P(X = 1) = 1/2$ (outcomes: $HT, TH$)
         
    - $p_X(2) = P(X = 2) = 1/4$ (outcome: $HH$)
         
    - $p_X(x) = 0$ for all other $x$.

- $Y = 2 - X$ = Number of Tails:
     - $P(Y = y) = P(2 - X = y) = P(X = 2 - y) = p_X(2 - y)$
         
    - $p_Y(0) = 1/4$, $p_Y(1) = 1/2$, $p_Y(2) = 1/4$, and $0$ otherwise.

- _Key Takeaway:_ $X$ and $Y$ have identical PMFs ($p_X = p_Y$), but they are distinct random variables (different functions mapping $S \to \mathbb{R}$).

- $I$ = Indicator of First Toss Landing Heads:
     - $p_I(0) = P(I = 0) = 1/2$ (outcomes: $TH, TT$)
         
    - $p_I(1) = P(I = 1) = 1/2$ (outcomes: $HH, HT$)
         
    - $p_I(i) = 0$ for all other $i$.

**Sum of Two Fair 6-Sided Die Rolls**

Let $X$ and $Y$ be the outcomes of two fair 6-sided dice, and $T = X + Y$. The sample space $S = \{(1, 1), (1, 2), \dots, (6, 6)\}$ has 36 equally likely outcomes.

- **Individual Marginal PMFs:** $P(X = j) = 1/6$ for $j \in \{1, 2, \dots, 6\}$ (Discrete Uniform distribution). $Y$ is also Discrete Uniform on $\{1, 2, \dots, 6\}$.

- **Identical Distributions vs. Identical Variables:**
    - $P(X = Y) = 6/36 = 1/6$.
        
    - $7 - X$ and $7 - Y$ also share the same distribution as $X$ (the bottom value of a standard die). However, $7 - X$ is never equal to $X$ in any single roll.

- **PMF of $T$:**
    - $P(T = 2) = P(T = 12) = 1/36$
        
    - $P(T = 3) = P(T = 11) = 2/36$
        
    - $P(T = 4) = P(T = 10) = 3/36$
        
    - $P(T = 5) = P(T = 9) = 4/36$
        
    - $P(T = 6) = P(T = 8) = 5/36$
        
    - $P(T = 7) = 6/36$
        
    - $P(T = t) = 0$ for all other values.

- **Symmetry:** $P(T = t) = P(T = 14 - t)$, because each outcome $\{X = x, Y = y\}$ yielding $T = t$ matches an equally likely outcome $\{X = 7 - x, Y = 7 - y\}$ yielding $T = 14 - t$.

- **Verification:** The support is $\{2, 3, \dots, 12\}$, and $\sum_{t=2}^{12} P(T = t) = 1$.

- $P(X = x)$ is proportional to the count of households with $x$ children (approximated via empirical survey data, e.g., the 2010 General Social Survey).

#### Theorem: Criteria for a Valid PMF

Let $X$ be a discrete r.v. with support $x_1, x_2, \dots$ (distinct values). A function $p_X$ is a valid PMF if and only if it satisfies:

1. **Nonnegative:** $p_X(x) > 0$ if $x = x_j$ for some $j$, and $p_X(x) = 0$ otherwise.
    
2. **Sums to 1:**
$$\sum_{j=1}^{\infty} p_X(x_j) = 1$$

_Proof:_ Nonnegativity follows directly from the axiom that probabilities are nonnegative. Summing to 1 follows because $X$ must take on some value in its support, and the events $\{X = x_j\}$ are pairwise disjoint:
$$\sum_{j=1}^{\infty} P(X = x_j) = P\left(\bigcup_{j=1}^{\infty} \{X = x_j\}\right) = P(X = x_1 \text{ or } X = x_2 \text{ or } \dots) = 1$$

_Converse:_ Any function satisfying these two criteria on a set of distinct values represents the PMF of some valid random variable.

**Calculating Probabilities of Subsets from a PMF**

For any subset of real numbers $B \subseteq \mathbb{R}$:
$$P(X \in B) = \sum_{x \in B} p_X(x)$$

**Example:** For the sum of two dice $T$, we want to find $P(1 \le T \le 4)$. The only support values in $[1, 4]$ are $2, 3, 4$:
$$P(1 \le T \le 4) = P(T = 2) + P(T = 3) + P(T = 4) = \frac{1}{36} + \frac{2}{36} + \frac{3}{36} = \frac{6}{36}$$
Visually, finding $P(X \in B)$ corresponds to summing the heights of the vertical bars at all support points lying within $B$. *Knowing the PMF completely determines the distribution of a discrete r.v.*

## 3.3: Bernoulli and Binomial Distributions

Named distributions represent probability distributions that occur frequently in probability and statistics. The simplest of these models random variables that take on only two possible values: 0 and 1.

### The Bernoulli Distribution

A random variable $X$ has a Bernoulli distribution with parameter $p$ if:
$$P(X = 1) = p \quad \text{and} \quad P(X = 0) = 1 - p$$
where $0 < p < 1$.

**Notation:** $X \sim \text{Bern}(p)$ (read as "$X$ is distributed as Bernoulli with parameter $p$").

**Parameter:** The value $p$ determines the specific distribution from the family of Bernoulli distributions. Specifying the distribution requires both the name ($\text{Bernoulli}$) and the parameter value ($p$).

**Bernoulli Trial (Story):** An experiment that results in either a "success" or a "failure" (mutually exclusive). A Bernoulli random variable acts as the indicator of success:
$$X = \begin{cases} 1 & \text{if success occurs} \\ 0 & \text{if failure occurs} \end{cases}$$
The parameter $p$ is known as the **success probability**.

#### Indicator Random Variables

The indicator random variable of an event $A$, denoted $I_A$ or $I(A)$, equals $1$ if event $A$ occurs and $0$ otherwise. Any event has an associated indicator variable distributed as Bernoulli:
$$I_A \sim \text{Bern}(p) \quad \text{where } p = P(A)$$

### The Binomial Distribution

**Story:** Perform $n$ independent Bernoulli trials, each having the same success probability $p$. Let $X$ represent the total number of successes. The distribution of $X$ is the Binomial distribution.

**Notation:** $X \sim \text{Bin}(n, p)$, where $n$ is a positive integer and $0 < p < 1$.

**Relationship to Bernoulli:** The Bernoulli distribution is a special case of the Binomial distribution with a single trial:

$$\text{Bern}(p) \equiv \text{Bin}(1, p)$$

**Importance of Stories:** Defining distributions by the physical/experimental setup (the "story") rather than purely by formulas aids in pattern recognition across structurally identical problems, simplifies proofs without heavy computation, and shows connections between different distributions.

**Theorem:(Binomial PMF)** If $X \sim \text{Bin}(n, p)$, then the probability mass function of $X$ is:
$$P(X = k) = \binom{n}{k} p^k (1 - p)^{n-k} \quad \text{for } k \in \{0, 1, \dots, n\}$$
and $P(X = k) = 0$ otherwise. The support of the distribution is the set $\{0, 1, \dots, n\}$.

**Proof:** In $n$ independent Bernoulli trials, any specific, ordered sequence containing exactly $k$ successes and $n - k$ failures occurs with probability:
$$p^k (1 - p)^{n-k}$$
There are $\binom{n}{k}$ ways to choose the locations of the $k$ successes among the $n$ trials.

Multiplying the number of distinct sequences by the probability of any one sequence yields $P(X = k) = \binom{n}{k} p^k (1 - p)^{n-k}$.

This is a valid PMF because all terms are nonnegative and their sum across all $k \in \{0, 1, \dots, n\}$ equals $(p + (1 - p))^n = 1^n = 1$ by the Binomial Theorem.

**Properties and Shape of the Binomial PMF**

- **Symmetry vs. Skewness:** When $p = 1/2$, the PMF is symmetric. When $p \neq 1/2$, the PMF is skewed.
	
- **Effect of $p$:** For a fixed $n$, larger values of $p$ shift the probability mass toward larger values of $k$, while smaller values of $p$ shift the mass toward lower values of $k$.
    
- **Sum of Masses:** In any PMF plot, the vertical bars sum to 1.    

![](Pasted%20image%2020260908124432.png)
##### Success/Failure Duality and Symmetry Theorems

**Theorem (Distribution of Failures):**

Let $X \sim \text{Bin}(n, p)$, and let $q = 1 - p$ denote the failure probability. Then:
$$n - X \sim \text{Bin}(n, q)$$
**Story Proof:** If $X$ counts the number of successes in $n$ independent Bernoulli trials, $n - X$ represents the number of failures. By interchanging the labels of "success" and "failure," the number of failures is distributed as $\text{Bin}(n, q)$.

**Algebraic Proof:** Let $Y = n - X$. For $k \in \{0, 1, \dots, n\}$:
$$P(Y = k) = P(X = n - k) = \binom{n}{n - k} p^{n - k} q^k = \binom{n}{k} q^k p^{n - k}$$
which matches the $\text{Bin}(n, q)$ PMF.    

**Corollary (Symmetry for $p = 1/2$):**

If $X \sim \text{Bin}(n, 1/2)$ with $n$ even, the distribution of $X$ is symmetric about $n/2$:
$$P\left(X = \frac{n}{2} + j\right) = P\left(X = \frac{n}{2} - j\right) \quad \text{for all integers } j \ge 0$$
**Proof:** Since $p = 1 - p = 1/2$, $n - X \sim \text{Bin}(n, 1/2)$, meaning $P(X = k) = P(n - X = k) = P(X = n - k)$. Substituting $k = n/2 + j$ yields $n - k = n/2 - j$.


**Example:** (Two Fair Coin Tosses Continues) For an experiment of two fair coin tosses:

- $X$ (number of Heads) $\sim \text{Bin}(2, 1/2)$.
    
- $Y = 2 - X$ (number of Tails) $\sim \text{Bin}(2, 1/2)$.
    
- $I$ (indicator of Heads on the first toss) $\sim \text{Bern}(1/2)$.
    
- Because $p = 1/2$ and $n = 2$ (even), $X$ and $Y$ have the same distribution, both symmetric about $n/2 = 1$.

## 3.4: Hypergeometric Distribution

When drawing $n$ balls from an urn containing $w$ white and $b$ black balls:

- **With replacement:** The number of white balls follows a $\text{Bin}(n, w/(w + b))$ distribution because draws are independent Bernoulli trials.
	
- **Without replacement:** The trials become dependent, and the number of white balls follows a Hypergeometric distribution.

#### Story and Definition

**Story 3.4.1 (Hypergeometric Distribution):** Consider an urn with $w$ white balls and $b$ black balls. We draw $n$ balls out of the urn at random without replacement such that all $\binom{w+b}{n}$ samples are equally likely. Let $X$ be the number of white balls in the sample.

**Notation:** $X \sim \text{HGeom}(w, b, n)$ with parameters:
- $w$: Total number of white items ("successes" in population)
	
- $b$: Total number of black items ("failures" in population)
	
- $n$: Sample size drawn without replacement

![](Pasted%20image%2020260908152647.png)
#### Theorem: Hypergeometric PMF  

If $X \sim \text{HGeom}(w, b, n)$, the probability mass function of $X$ is:
$$P(X = k) = \frac{\binom{w}{k}\binom{b}{n - k}}{\binom{w + b}{n}}$$
for integers $k$ satisfying:
$$0 \le k \le w \quad \text{and} \quad 0 \le n - k \le b$$
and $P(X = k) = 0$ otherwise.

**Proof:** To obtain $P(X = k)$, count the ways to draw exactly $k$ white balls and $n - k$ black balls without regard to order.

- If $k > w$ or $n - k > b$, drawing such a sample is impossible. Otherwise, by the multiplication rule, there are $\binom{w}{k}\binom{b}{n - k}$ favorable samples.
	
- The total number of equally likely samples of size $n$ from $w + b$ balls is $\binom{w + b}{n}$.

By the naive definition of probability, $P(X = k) = \frac{\binom{w}{k}\binom{b}{n - k}}{\binom{w + b}{n}}$.
 
**Validity Check:** The PMF is nonnegative, and by **Vandermonde's identity**, the numerator summed over all possible $k$ equals $\binom{w + b}{n}$, confirming the probabilities sum to 1:
$$\sum_{k} \binom{w}{k}\binom{b}{n - k} = \binom{w + b}{n}$$

**The Two-Tags Interpretation**

The Hypergeometric distribution generalizes beyond physical urns. The fundamental structure relies on classifying a population using **two sets of tags**:

1. **First set of tags:** An intrinsic property of each item (e.g., white vs. black).
    
2. **Second set of tags:** Whether the item is selected (e.g., sampled vs. not sampled).

At least one set of tags must be assigned completely at random. Then $X \sim \text{HGeom}(w, b, n)$ represents the count of **twice-tagged items** (items possessing both target tags).

#### Applied Examples

**Elk Capture-Recapture**

A forest has $N$ total elk. $m$ elk are captured, tagged, and released. Later, $n$ elk are recaptured at random (assuming equal likelihood and that captured elk do not learn to avoid recapture). The number of tagged elk in the recaptured sample follows:
$$X \sim \text{HGeom}(m, N - m, n)$$
**Aces in a Poker Hand**

A five-card hand ($n = 5$) drawn at random from a standard 52-card deck ($w = 4$ aces, $b = 48$ non-aces). The number of aces follows $\text{HGeom}(4, 48, 5)$.

Probability of getting exactly 3 aces:
$$P(X = 3) = \frac{\binom{4}{3}\binom{48}{2}}{\binom{52}{5}} \approx 0.0017$$

Let's see how the two tags interpretation fairs in these examples,

|**Story**|**First Set of Tags (Target)**|**First Set of Tags (Other)**|**Second Set of Tags (Target)**|**Second Set of Tags (Other)**|**Twice-Tagged Variable (X)**|
|---|---|---|---|---|---|
|**Urn**|White|Black|Sampled|Not sampled|White and sampled|
|**Elk**|Tagged ($m$)|Untagged ($N - m$)|Recaptured ($n$)|Not recaptured|Tagged and recaptured|
|**Cards**|Ace ($4$)|Not ace ($48$)|In hand ($5$)|Not in hand|Ace and in hand|

#### Theorem: Parameter Symmetry

The distributions $\text{HGeom}(w, b, n)$ and $\text{HGeom}(n, w + b - n, w)$ are identical:
$$\text{HGeom}(w, b, n) \equiv \text{HGeom}(n, w + b - n, w)$$
**Story Proof:**

- Let $X \sim \text{HGeom}(w, b, n)$ be the number of white balls in a sample of size $n$ (treating white/black as the 1st tag and sampled/unsampled as the 2nd tag).

- Let $Y \sim \text{HGeom}(n, w + b - n, w)$ be the number of sampled balls among the $w$ white balls (treating sampled/unsampled as the 1st tag and white/black as the 2nd tag).

- Both $X$ and $Y$ count the exact same entity: balls that are simultaneously white and sampled. Thus, they follow the same distribution.

**Algebraic Verification:**
$$P(X = k) = \frac{\binom{w}{k}\binom{b}{n - k}}{\binom{w + b}{n}} = \frac{w!\,b!\,n!\,(w + b - n)!}{k!\,(w - k)!\,(n - k)!\,(b - n + k)!\,(w + b)!}$$
$$P(Y = k) = \frac{\binom{n}{k}\binom{w + b - n}{w - k}}{\binom{w + b}{w}} = \frac{n!\,(w + b - n)!\,w!\,b!}{k!\,(n - k)!\,(w - k)!\,(b - n + k)!\,(w + b)!}$$
Both expressions are algebraically identical.

#### Comparison: Binomial vs. Hypergeometric

**Similarities:** Both are discrete distributions with support over integers $\{0, 1, \dots, n\}$ representing the total number of "successes" in $n$ trials.

**Core Difference (Independence):**

- **Binomial:** Sampling is done **with replacement**; trials are independent.
	
- **Hypergeometric:** Sampling is done **without replacement**; trials are **dependent**. (For example, observing a tagged elk on the first draw reduces the probability of getting a tagged elk on the second draw).

## 3.5: Discrete Uniform Distribution

The Discrete Uniform distribution models an experiment where a single number is chosen uniformly at random from a finite set of possibilities, directly embodying the naive definition of probability.

#### Story and Definition

**Story (Discrete Uniform Distribution):** Let $C$ be a finite, nonempty set of numbers. Choose one of these numbers uniformly at random (every value in $C$ is equally likely). Let $X$ be the chosen number.

**Notation:**
$$X \sim \text{DUnif}(C)$$
where the parameter is the set $C$ itself.

#### PMF and Event Probabilities

**Probability Mass Function:** The PMF of discrete uniform distribution directly follows from the naive definition of probability,
$$P(X = x) = \frac{1}{\vert{}C\vert{}} \quad \text{for } x \in C$$
and $P(X = x) = 0$ otherwise (satisfying $\sum_{x \in C} P(X = x) = 1$).

**Subset Probability:** For any subset $A \subseteq C$:
$$P(X \in A) = \frac{\vert{}A\vert{}}{\vert{}C\vert{}}$$
Questions involving a Discrete Uniform distribution directly reduce to counting problems.    

#### Case Study: Random Slips of Paper

Consider a hat containing $100$ slips of paper labeled $1, 2, \dots, 100$ (with no duplicates). Five slips are drawn, one at a time.

**Scenario 1: Sampling With Replacement (Independent Draws)**

- **Count of slips with value $\ge 80$:** Values $\ge 80$ form the set $\{80, 81, \dots, 100\}$, containing $21$ values. The probability of success on any draw is $p = 21/100 = 0.21$. Because draws are independent Bernoulli trials, the total count follows:
$$\text{Bin}(5, 0.21)$$

- **Distribution of the $j$-th draw ($X_j$, for $1 \le j \le 5$):** By symmetry, every slip is equally likely to be selected on any given draw.
$$X_j \sim \text{DUnif}(\{1, 2, \dots, 100\})$$

- **Probability that 100 is drawn at least once:** Using the complement rule and independence of draws:
$$P(X_j = 100 \text{ for at least one } j) = 1 - P(X_1 \ne 100, \dots, X_5 \ne 100)$$
$$= 1 - P(X_1 \ne 100)\cdots P(X_5 \ne 100) = 1 - \left(\frac{99}{100}\right)^5 \approx 0.049$$

**Scenario 2: Sampling Without Replacement (Dependent Draws)**

- **Count of slips with value $\ge 80$:** Tagged/target slips ($w$): $21$ slips with values $\ge 80$. Untagged slips ($b$): $79$ slips with values $< 80$. Sample size ($n$): $5$. The distribution is Hypergeometric:
$$\text{HGeom}(21, 79, 5)$$

- **Distribution of the $j$-th draw ($Y_j$, for $1 \le j \le 5$):** Unconditionally (evaluated prior to observing any draws), the $j$-th draw is equally likely to be any of the $100$ slips:
$$Y_j \sim \text{DUnif}(\{1, 2, \dots, 100\})$$
	_Simultaneous Draw Perspective:_ Imagine five people reaching into the hat at the exact same moment to each draw one slip. Let $Z_j$ be the slip drawn by person $j$. By symmetry, each person draws a uniformly random slip: $Z_j \sim \text{DUnif}(\{1, 2, \dots, 100\})$. While $Y_1, \dots, Y_5$ are dependent, marginally/unconditionally each is Discrete Uniform.

- **Probability that 100 is drawn in the sample:** Because draws are made without replacement, the events $Y_1 = 100, \dots, Y_5 = 100$ are pairwise disjoint:
$$P(Y_j = 100 \text{ for some } j) = P(Y_1 = 100) + \dots + P(Y_5 = 100) = 5 \times \frac{1}{100} = 0.05$$
	_Sanity Check:_ Choosing $5$ slips first and then randomly writing numbers $1$ to $100$ on all slips gives an identical $5/100$ probability that the number $100$ lands on one of the $5$ chosen slips.

**Key Comparison: With vs. Without Replacement**

- **Comparison of Probabilities:**
$$P(\text{draw } 100 \text{ with replacement}) \approx 0.049 < P(\text{draw } 100 \text{ without replacement}) = 0.05$$
    Sampling without replacement eliminates duplicate selections, making it strictly more effective when searching for a specific target. The values remain close because the probability of redrawing the same slip across only 5 draws is small.

- **Generalization:** If $k$ slips are drawn without replacement ($0 \le k \le 100$), the probability of drawing the number $100$ is:
$$\frac{k}{100}$$
    In the extreme case where $k = 100$ (drawing all slips), the probability equals $100/100 = 1$.

## 3.6 Cumulative Distribution Functions

The cumulative distribution function (CDF) is another function that describes the distribution of a random variable. Unlike the probability mass function (PMF), which is defined only for discrete random variables, the CDF is defined for all random variables (discrete, continuous, and hybrid).

**Definition:** The cumulative distribution function (CDF) of a random variable $X$ is the function $F_X$ given by:
$$F_X(x) = P(X \le x)$$
When unambiguous, the subscript is often dropped and written simply as $F(x)$.

#### Converting Between PMF and CDF (Discrete Case)

For discrete random variables, the PMF and CDF contain equivalent information and can be converted back and forth:
![](Pasted%20image%2020260908230750.png)
**PMF to CDF:** Sum the PMF over all support values less than or equal to $x$:
$$F_X(x) = P(X \le x) = \sum_{k \le x} P(X = k)$$
_Example:_ For $X \sim \text{Bin}(4, 1/2)$, evaluating the CDF at $x = 1.5$:
$$P(X \le 1.5) = P(X = 0) + P(X = 1) = \left(\frac{1}{2}\right)^4 + 4\left(\frac{1}{2}\right)^4 = \frac{5}{16}$$
Visually, the CDF value at $x$ equals the sum of the heights of the PMF vertical bars for all values $\le x$.

**CDF to PMF:** The CDF of a discrete r.v. consists of flat horizontal regions connected by vertical jumps:

- **Jump Height:** The height of a jump in the CDF at point $x$ equals $P(X = x)$ (the PMF value at $x$).

- **Flat Regions:** Correspond to values outside the support of $X$, where the PMF is equal to $0$.

#### Theorem: Properties of a Valid CDF

Any valid cumulative distribution function $F$ must satisfy three criteria:

1. **Increasing (Non-decreasing):** If $x_1 \le x_2$, then: $F(x_1) \le F(x_2)$
    
2. **Right-Continuous:** $F$ is continuous except possibly for jump discontinuities. At every point $a$, the function is continuous from the right:
$$F(a) = \lim_{x \to a^+} F(x)$$
    _(In plots, jumps have an open dot at the bottom and a closed dot at the top)._
    
3. **Limits at Negative and Positive Infinity:**
$$\lim_{x \to -\infty} F(x) = 0 \quad \text{and} \quad \lim_{x \to \infty} F(x) = 1$$
    _(The CDF may reach $0$ and $1$ exactly, or approach them asymptotically)._

**Proof for Discrete r.v. with Nonnegative Integer Support $\{0, 1, 2, \dots\}$**

- **Property 1 (Increasing):** The event $\{X \le x_1\}$ is a subset of the event $\{X \le x_2\}$. By the monotonicity of probability:
$$P(X \le x_1) \le P(X \le x_2)$$
	
- **Property 2 (Right-Continuous):** Since $X$ is integer-valued:
$$P(X \le x) = P(X \le \lfloor x \rfloor)$$
    where $\lfloor x \rfloor$ is the floor function (greatest integer $\le x$). For any sufficiently small $b > 0$ such that $a + b < \lfloor a \rfloor + 1$, we have $F(a + b) = F(a)$. Because $F(x)$ remains constant just to the right of $a$:
$$\lim_{x \to a^+} F(x) = \lim_{ h \to 0 } F(a+h) = F(a)$$
    
- **Property 3 (Limits at Infinity):** Since the support contains only nonnegative integers, $F(x) = 0$ for all $x < 0$, giving $\lim_{x \to -\infty} F(x) = 0$. As $x \to \infty$:
$$\lim_{x \to \infty} F(x) = \lim_{x \to \infty} P(X \le \lfloor x \rfloor) = \lim_{x \to \infty} \sum_{n=0}^{\lfloor x \rfloor} P(X = n) = \sum_{n=0}^{\infty} P(X = n) = 1$$
#### Summary: Three Ways to Express a Distribution

1. **PMF (Probability Mass Function):** Specific to discrete random variables. Typically the easiest to work with for discrete distributions since it avoids summation operations required by the CDF.

2. **CDF (Cumulative Distribution Function):** Universal framework defined for all types of random variables. Directly interchangeable with the PMF for discrete variables.

3. **Story:** Specifies the underlying experiment or physical mechanism generating the distribution. Contains the same core mathematical information as the PMF/CDF while enabling intuitive, clean proofs without tedious algebraic calculations.

## 3.7: Functions of Random Variables

Applying a mathematical function $g : \mathbb{R} \to \mathbb{R}$ to a random variable $X$ produces a new random variable, denoted $g(X)$ (such as $X^2$, $e^X$, or $\sin(X)$).

**Example (Basketball Match):** Two teams ($A$ and $B$) play a 7-game series. If games are independent and teams are evenly matched, the number of wins for team $A$ is $X \sim \text{Bin}(7, 1/2)$.

- Let $g(x) = 7 - x \implies g(X) = 7 - X$ is an r.v. representing the wins for team $B$.

- Let $h(x) = 1$ if $x \ge 4$ and $0$ if $x < 4 \implies h(X)$ is an indicator r.v. for team $A$ winning the series.
 
#### Formal Definition and Composition

- **Definition (Function of an r.v.):** For an experiment with sample space $S$, an r.v. $X$, and a function $g : \mathbb{R} \to \mathbb{R}$, $g(X)$ is the random variable that maps outcome $s$ to $g(X(s))$ for all $s \in S$.
    
- **Composition:** $g(X)$ represents the composition of functions $X$ and $g$ ($s \mapsto X(s) \mapsto g(X(s))$)—meaning "first apply $X$, then apply $g$." If $X$ crystallizes to a specific number $x$, then $g(X)$ crystallizes to $g(x)$.

#### Finding the PMF of $Y = g(X)$

**Case 1: $g$ is a One-to-One Function**

If $g$ is one-to-one, each possible value of $X$ maps to a unique value of $Y$. The support of $Y$ consists of all $g(x)$ where $x$ is in the support of $X$, and probabilities transfer directly:
$$P(Y = g(x)) = P(g(X) = g(x)) = P(X = x)$$

| **x**    | **P(X=x)** | **y**    | **P(Y=y)** |
| -------- | ---------- | -------- | ---------- |
| $x_1$    | $p_1$      | $g(x_1)$ | $p_1$      |
| $x_2$    | $p_2$      | $g(x_2)$ | $p_2$      |
| $x_3$    | $p_3$      | $g(x_3)$ | $p_3$      |
| $\vdots$ | $\vdots$   | $\vdots$ | $\vdots$   |

_Strategy:_ To find the PMF of an unfamiliar r.v., attempt to express it as a one-to-one function of an r.v. with a known distribution.

**Example (Random Walk Position):** A particle starts at $0$ and takes $n$ independent steps on a number line, each step moving $+1$ (right) or $-1$ (left) with equal probability $1/2$. Let $Y$ be the position after $n$ steps.

- Let $X$ be the number of steps to the right $\implies X \sim \text{Bin}(n, 1/2)$.

- If $X = j$, the particle moves $j$ steps right and $n - j$ steps left:
$$Y = j - (n - j) = 2X - n$$
- Because $g(x) = 2x - n$ is one-to-one, the support of $Y$ is $\{-n, 2 - n, 4 - n, \dots, n\}$.
 
- For any integer $k \in [-n, n]$ such that $n + k$ is even:
$$P(Y = k) = P\left(X = \frac{n + k}{2}\right) = \binom{n}{\frac{n + k}{2}}\left(\frac{1}{2}\right)^n$$

**Case 2: $g$ is Not One-to-One**

When multiple values of $x$ map to the same value $y$, sum the probabilities of all candidate $x$ values that yield $y$.

**Theorem (PMF of $g(X)$):** Let $X$ be a discrete r.v. and $g : \mathbb{R} \to \mathbb{R}$. The support of $g(X)$ is the set of all $y$ such that $g(x) = y$ for at least one $x$ in the support of $X$, and its PMF is:
$$P(g(X) = y) = \sum_{x : g(x) = y} P(X = x)$$
**Example (Distance from Origin in a Random Walk):** Let $D = \vert{}Y\vert{}$ be the distance from the origin after $n$ steps (with $n$ even). The absolute value function is not one-to-one:
- $D = 0 \iff Y = 0$

- $D = k \iff \{Y = k\} \cup \{Y = -k\}$ for $k \in \{2, 4, \dots, n\}$

- By symmetry, $P(Y = k) = P(Y = -k)$, giving:
$$P(D = 0) = \binom{n}{n/2}\left(\frac{1}{2}\right)^n$$
$$P(D = k) = P(Y = k) + P(Y = -k) = 2\binom{n}{\frac{n + k}{2}}\left(\frac{1}{2}\right)^n \quad \text{for } k \in \{2, 4, \dots, n\}$$

#### Functions of Multiple Random Variables

**Definition (Function of Two r.v.s):** Given an experiment with sample space $S$, if $X$ and $Y$ map $s \in S$ to $X(s)$ and $Y(s)$, then $g(X, Y)$ is the r.v. mapping $s$ to $g(X(s), Y(s))$.

- _Sample Space Assumption:_ $X$ and $Y$ must be defined on the same sample space $S$. If originally defined on separate spaces $S_1$ and $S_2$, redefine them on the product space $S = S_1 \times S_2$.

- **Crystallization:** If $X = x$ and $Y = y$, then $g(X, Y)$ crystallizes to $g(x, y)$ (e.g., $X + Y$ crystallizes to $x + y$, and $\max(X, Y)$ crystallizes to $\max(x, y)$).


**Example: Maximum of Two Fair Die Rolls**

Let $X$ and $Y$ be the outcomes of two fair 6-sided dice ($36$ equally likely outcomes).

| **Outcome (s)** | **X** | **Y** | **max(X,Y)** |
| --------------- | ----- | ----- | ------------ |
| $(1, 2)$        | 1     | 2     | 2            |
| $(1, 6)$        | 1     | 6     | 6            |
| $(2, 5)$        | 2     | 5     | 5            |
| $(3, 1)$        | 3     | 1     | 3            |
| $(4, 3)$        | 4     | 3     | 4            |
| $(5, 4)$        | 5     | 4     | 5            |
| $(6, 6)$        | 6     | 6     | 6            |

Tabulating across all 36 pairs in a $6 \times 6$ grid yields the PMF:
$$
\begin{align}
P(\max(X, Y) = 1) &  = 1/36 \\
P(\max(X, Y) = 2) & = 3/36 \\
P(\max(X, Y) = 3) & = 5/36 \\
P(\max(X, Y) = 4) & = 7/36 \\
P(\max(X, Y) = 5) & = 9/36 \\
P(\max(X, Y) = 6) & = 11/36
\end{align}
$$
_Alternative Calculation (Decomposition):_
$$
\begin{align}
P(\max(X, Y) = 5) & = P(X = 5, Y \le 4) + P(X \le 4, Y = 5) + P(X = 5, Y = 5) \\
 & = 2P(X = 5, Y \le 4) + \frac{1}{36} = 2\left(\frac{4}{36}\right) + \frac{1}{36} = \frac{9}{36}
\end{align}
$$

#### Category Errors and "Sympathetic Magic"

A **category error** is an error resulting from confusing fundamentally different classes of mathematical objects: distributions, random variables, events, and numbers.

**Sympathetic Magic:** The specific category error of confusing a random variable with its distribution.

_"The word is not the thing; the map is not the territory."_ — Alfred Korzybski

The distribution is merely the blueprint or map describing the random variable. Distinct random variables defined on entirely different sample spaces can have identical distributions.

**Two Classical Pitfalls of Sympathetic Magic:**

1. **Multiplying a PMF by a Constant (e.g., attempting to find the PMF of $2X$):**
      
    - _The Error:_ Multiplying the PMF values of $X$ by 2 (which invalidates the PMF because the probabilities would sum to 2).
        
    - _The Correction:_ If $X$ takes values $x_j$ with probability $p_j$, then $2X$ takes values $2x_j$ with probability $p_j$. The transformation represents a **horizontal stretch** of the support, not a vertical stretch of the probabilities. (e.g., support $\{0, 1, 2, 3, 4\}$ becomes $\{0, 2, 4, 6, 8\}$).

![](Pasted%20image%2020260909103337.png)

2. **Assuming Identical Distribution Implies Equality ($P(X = Y) = 1$):**
      
    - Having the same distribution does not imply two random variables are equal, or that they ever equal each other.
        
    - _Toss Example 1:_ In a single fair coin toss, let $X$ indicate Heads and $Y = 1 - X$ indicate Tails. Both $X, Y \sim \text{Bern}(1/2)$, but $P(X = Y) = 0$ (the event $X = Y$ is impossible).
        
    - _Toss Example 2:_ Let $Z$ be the indicator of Heads on an independent second toss. $Z \sim \text{Bern}(1/2)$, but $P(Z = X) = P(\{HH, TT\}) = 1/2 \ne 1$.

## 3.8 Independence of Random Variables

Two random variables $X$ and $Y$ are independent if knowing the value of one provides no information about the value of the other.

#### Definitions of Independence  

**Definition (Two Random Variables):** Random variables $X$ and $Y$ are independent if:
$$P(X \le x, Y \le y) = P(X \le x)P(Y \le y) \quad \text{ for all } x, y \in \mathbb{R}$$
**Discrete Equivalent:** For discrete r.v.s, this is equivalent to:
$$P(X = x, Y = y) = P(X = x)P(Y = y)$$
for all $x$ in the support of $X$ and all $y$ in the support of $Y$.

**Definition (Many Random Variables):** Random variables $X_1, \dots, X_n$ are independent if:
$$P(X_1 \le x_1, \dots, X_n \le x_n) = P(X_1 \le x_1)\dots P(X_n \le x_n) \quad \text{for all } x_1, \dots, x_n \in \mathbb{R}$$
- **Infinite Collection:** An infinite set of r.v.s is independent if every finite subset is independent.

- **Contrast with Event Independence:** Unlike events—which require checking pairwise independence, triplet independence, up to $n$-way independence—r.v. independence requires a single product equation, but that equation must hold across **all** possible combinations of $x_1, \dots, x_n$ (an infinite number of conditions). A failure at even a single point disproves independence.

- **Pairwise vs. Mutual Independence:** Mutual independence implies pairwise independence (letting all other $x_k \to \infty$). However, pairwise independence does **not** imply mutual independence.

**Example: Sum and Difference of Two Dice Rolls**

Let $X$ and $Y$ be the outcomes of two independent rolls of a fair die. The random variables $X + Y$ and $X - Y$ are dependent:
$$P(X + Y = 12, X - Y = 1) = 0 \ne P(X + Y = 12)P(X - Y = 1) = \frac{1}{36} \cdot \frac{5}{36}$$
Knowing the total sum is 12 forces the difference to be 0, so the variables convey information about each other.

**Theorem: Functions of Independent Random Variables**

If $X$ and $Y$ are independent random variables, then any function of $X$ is independent of any function of $Y$ (e.g., $X^2$ is independent of $Y^4$).

#### Independent and Identically Distributed (i.i.d.)

- **Definition:** Random variables are **i.i.d.** if they are mutually independent and share the exact same probability distribution (same PMF or CDF).

**Distinction: Independent ("i.") vs. Identically Distributed ("i.d.")**

Independence and identical distribution are separate, orthogonal concepts:

| **Relationship**                              | **Description**                                                              | **Example**                                                                                                                  |
| --------------------------------------------- | ---------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| **Independent & Identically Distributed**     | Share the same PMF/CDF and provide no information about each other.          | Two independent rolls of a fair die ($X$ and $Y$).                                                                           |
| **Independent & Not Identically Distributed** | Provide no information about each other, but follow different distributions. | Roll of a die ($X$) vs. the closing price of the Dow Jones index next month ($Y$).                                           |
| **Dependent & Identically Distributed**       | Share the same distribution, but convey information about each other.        | Number of Heads ($X$) and Tails ($Y = n - X$) in the same $n$ tosses of a fair coin (both are $\text{Bin}(n, 1/2)$).         |
| **Dependent & Not Identically Distributed**   | Follow different distributions and convey information about each other.      | Indicator of the majority party retaining control of the House ($X$) vs. party favorability ratings prior to election ($Y$). |

#### Binomial Representations and Properties

**Theorem (Sum of i.i.d. Bernoullis):**

If $X \sim \text{Bin}(n, p)$, representing the total successes in $n$ independent Bernoulli trials with parameter $p$:
$$X = X_1 + X_2 + \dots + X_n$$
where $X_i \overset{\text{i.i.d.}}{\sim} \text{Bern}(p)$ ($X_i = 1$ if trial $i$ succeeds, $0$ otherwise).

**Proof:** Each individual r.v. $X_{i}$ tells you whether that trial ended in success or not, then you count how many of the r.v.s are giving $X_{i} = 1$, that exactly what the sum is doing, hence the sum represents the binomial distribution.

**Theorem (Sum of Independent Binomials):**

If $X \sim \text{Bin}(n, p)$ and $Y \sim \text{Bin}(m, p)$ are independent, then:
$$X + Y \sim \text{Bin}(n + m, p)$$
**Proof 1 (Law of Total Probability):** Condition on $X = j$ and apply independence:
$$
\begin{align}
P(X + Y = k) & = \sum_{j=0}^k P(X + Y = k \mid X = j)P(X = j) \\
 & = \sum_{j=0}^k P(Y = k - j)P(X = j) \\
 & = \sum_{j=0}^k \binom{m}{k - j} p^{k - j} q^{m - (k - j)} \binom{n}{j} p^j q^{n - j} \\
 & = p^k q^{n + m - k} \sum_{j=0}^k \binom{m}{k - j}\binom{n}{j}
\end{align}
$$
By Vandermonde's identity, the sum equals $\binom{n + m}{k}$, yielding the $\text{Bin}(n + m, p)$ PMF:
$$\binom{n + m}{k} p^k q^{n + m - k}$$
**Proof 2 (Representation):** Write $X = \sum_{i=1}^n X_i$ and $Y = \sum_{j=1}^m Y_j$, where all $X_i, Y_j$ are i.i.d. $\text{Bern}(p)$. Then $X + Y$ is the sum of $n + m$ i.i.d. $\text{Bern}(p)$ variables, which is $\text{Bin}(n + m, p)$.

**Proof 3 (Story):** $X$ counts successes in $n$ trials and $Y$ counts successes in $m$ independent trials with identical success probability $p$. The sum $X + Y$ is the total successes across all $n + m$ trials, matching the definition of $\text{Bin}(n + m, p)$.    

#### Conditional Independence and Conditional PMFs

**Definition (Conditional Independence):** $X$ and $Y$ are conditionally independent given $Z$ if for all $x, y \in \mathbb{R}$ and all $z$ in the support of $Z$:
$$P(X \le x, Y \le y \mid Z = z) = P(X \le x \mid Z = z) P(Y \le y \mid Z = z)$$
**Discrete Case:**
$$P(X = x, Y = y \mid Z = z) = P(X = x \mid Z = z) P(Y = y \mid Z = z)$$

**Definition (Conditional PMF):** For discrete r.v.s $X$ and $Z$, $P(X = x \mid Z = z)$ viewed as a function of $x$ for a fixed $z$ is the conditional PMF of $X$ given $Z = z$.

#### Independence vs. Conditional Independence

Independence does **not** imply conditional independence, nor does conditional independence imply unconditional independence.

**1. Independence Does Not Imply Conditional Independence**

- **Example (Matching Pennies):** Players A and B toss fair pennies independently. Let $X = 1$ (Heads) or $-1$ (Tails) for A, and $Y = 1$ or $-1$ for B (random signs). Let $Z = XY$ ($1$ if pennies match, $-1$ otherwise). Unconditionally, $X$ and $Y$ are independent. Conditioned on $Z = 1$, we know $X = Y$, making them dependent.
    
- **Example (Two Friends):** Let $X$ indicate Alice calling, $Y$ indicate Bob calling (assumed independent), and $Z$ indicate exactly one calling. Conditioned on $Z = 1$, $Y = 1 - X$, making them completely dependent.

**2. Conditional Independence Does Not Imply Independence**

- **Example (Mystery Opponent):** You play two games against one of two identical twins: an evenly matched twin (win probability $1/2$) or a weaker twin (win probability $3/4$). Let $Z = 1$ indicate the evenly matched twin, and $X, Y$ indicate wins in games 1 and 2.
    - Given $Z = 1$, $X$ and $Y$ are i.i.d. $\text{Bern}(1/2)$.
        
    - Given $Z = 0$, $X$ and $Y$ are i.i.d. $\text{Bern}(3/4)$.
        
    - Thus, $X$ and $Y$ are conditionally independent given $Z$.
        
    - Unconditionally, $X$ and $Y$ are dependent: observing $X = 1$ provides evidence that the opponent is the weaker twin, which raises the probability of winning the second game:
$$P(Y = 1 \mid X = 1) > P(Y = 1)$$

## 3.9: Connections Between Binomial and Hypergeometric Distributions

The Binomial and Hypergeometric distributions are connected in two fundamental ways:

1. **Conditioning:** Conditioning independent Binomial random variables on their sum produces a Hypergeometric distribution.
    
2. **Limit:** Taking the limit of a Hypergeometric distribution as the population size grows to infinity produces a Binomial distribution.

#### From Binomial to Hypergeometric: Conditioning (Fisher's Exact Test)

Consider testing whether two groups have the same probability of an outcome (e.g., disease status in women vs. men):

- Let $X \sim \text{Bin}(n, p_1)$ be the number of diseased women out of $n$.
     
- Let $Y \sim \text{Bin}(m, p_2)$ be the number of diseased men out of $m$.
     
- Assume $X$ and $Y$ are independent.
     
- **Null Hypothesis:** $p_1 = p_2 = p$. Under this hypothesis, $X \sim \text{Bin}(n, p)$, $Y \sim \text{Bin}(m, p)$, and their sum follows $X + Y \sim \text{Bin}(n + m, p)$.

The test conditions on both the row and column sums of the observed $2 \times 2$ contingency table, treating $n$, $m$, and the total observed cases $r = X + Y$ as fixed:

| **Status**     | **Women** | **Men**     | **Total**   |
| -------------- | --------- | ----------- | ----------- |
| **Disease**    | $x$       | $r - x$     | $r$         |
| **No disease** | $n - x$   | $m - r + x$ | $n + m - r$ |
| **Total**      | $n$       | $m$         | $n + m$     |

**Derivation of the Conditional PMF:**

Using Bayes' rule and the independence of $X$ and $Y$:
$$P(X = x \mid X + Y = r) = \frac{P(X + Y = r \mid X = x)P(X = x)}{P(X + Y = r)} = \frac{P(Y = r - x)P(X = x)}{P(X + Y = r)}$$
Substituting the Binomial PMFs under the null hypothesis:
$$P(X = x \mid X + Y = r) = \frac{\binom{m}{r - x} p^{r - x} (1 - p)^{m - r + x} \binom{n}{x} p^x (1 - p)^{n - x}}{\binom{n + m}{r} p^r (1 - p)^{n + m - r}} = \frac{\binom{n}{x}\binom{m}{r - x}}{\binom{n + m}{r}}$$
This is the PMF of an $\text{HGeom}(n, m, r)$ distribution.

**Connection to the Elk Story:** Regard women as tagged elk ($n$) and men as untagged elk ($m$). Under the null hypothesis, the $r$ diseased individuals are equally likely to be any subset of size $r$ from the total population $n + m$. $X$ represents the number of "tagged elk" (women) among the $r$ "recaptured" individuals (diseased), which follows $\text{HGeom}(n, m, r)$.

**Elimination of the Parameter $p$:** The conditional distribution of $X$ given $X + Y = r$ does not depend on the unknown parameter $p$. Once the total number of diseased people $r$ is known, the problem reduces to sampling without replacement from a fixed population of $r$ diseased and $n + m - r$ healthy individuals.

**Theorem: Conditioning Independent Binomials**

If $X \sim \text{Bin}(n, p)$, $Y \sim \text{Bin}(m, p)$, and $X$ is independent of $Y$, then the conditional distribution of $X$ given $X + Y = r$ is:
$$X \mid (X + Y = r) \sim \text{HGeom}(n, m, r)$$

#### From Hypergeometric to Binomial: Limiting Distribution

**Theorem (Binomial as a Limit):**

If $X \sim \text{HGeom}(w, b, n)$ and the total population $N = w + b \to \infty$ while the success ratio $p = w/(w + b)$ remains fixed (with $q = 1 - p = b/(w + b)$), then the PMF of $X$ converges to the $\text{Bin}(n, p)$ PMF:
$$P(X = k) \to \binom{n}{k} p^k q^{n - k}$$
**Proof:** Applying the parameter symmetry of the Hypergeometric distribution ($\text{HGeom}(w, b, n) \equiv \text{HGeom}(n, w + b - n, w)$):
$$P(X = k) = \frac{\binom{w}{k}\binom{b}{n - k}}{\binom{w + b}{n}} = \binom{n}{k} \frac{\binom{w + b - n}{w - k}}{\binom{w + b}{w}}$$
Expanding the combinations into factorials and products:
$$
\begin{align}
 & = \binom{n}{k} \frac{w!\,b!\,(w + b - n)!}{(w - k)!\,(b - n + k)!\,(w + b)!} \\
 & = \binom{n}{k} \frac{[w(w - 1)\dots(w - k + 1)] \cdot [b(b - 1)\dots(b - n + k + 1)]}{(w + b)(w + b - 1)\dots(w + b - n + 1)}
\end{align}
$$
Dividing each term in the numerator and denominator by $N = w + b$:
$$= \binom{n}{k} \frac{\left[p\left(p - \frac{1}{N}\right)\dots\left(p - \frac{k - 1}{N}\right)\right] \cdot \left[q\left(q - \frac{1}{N}\right)\dots\left(q - \frac{n - k - 1}{N}\right)\right]}{1\left(1 - \frac{1}{N}\right)\left(1 - \frac{2}{N}\right)\dots\left(1 - \frac{n - 1}{N}\right)}$$
Taking the limit as $N \to \infty$:

- The denominator approaches $1 \times 1 \times \dots \times 1 = 1$.

- The numerator approaches $p^k \cdot q^{n - k}$.

- The expression converges to $\binom{n}{k} p^k q^{n - k}$, which is the $\text{Bin}(n, p)$ PMF.

**Story Intuition and Practical Approximation**

- **Sampling Mechanisms:** The Binomial distribution models sampling $n$ items **with replacement**, whereas the Hypergeometric distribution models sampling $n$ items **without replacement**.
    
- **Large Population Approximation:** When the population size $N = w + b$ is very large relative to the sample size $n$, removing a few items without replacement causes a negligible change in the composition of the remaining population. Therefore, sampling without replacement behaves essentially like sampling with replacement:
$$\text{HGeom}(w, b, n) \approx \text{Bin}\left(n, \frac{w}{w + b}\right) \quad \text{when } N \gg n$$
- **Connection to the Birthday Problem:** Even though drawing with replacement from a large urn can yield duplicate selections (e.g., drawing $1{,}200$ items out of $1{,}000{,}000$ with replacement yields roughly a $51\%$ chance of at least one duplicate), the Binomial approximation remains accurate because the vast majority of items in the sample are drawn only once.

$$
\begin{align}
P(n-X = k) & = P(X=n-k)  \\
 & = \binom{n}{n-k} \frac{1}{2^{n}} \\
 & = \binom{n}{k} \frac{1}{2^{n}} \\
 & = P(X = k) \\ \\
P(n+1-Y = k) & = P(Y=n+1-k) \\
 & = \binom{n+1}{n+1-k} \frac{1}{2^{n+1}} \\
 & = \binom{n+1}{k} \frac{1}{2^{n+1}} \\
 & = P(Y=k)
\end{align}
$$
In terms of story, we can imagine as $X$ being the number of heads Alice gets and $Y$ is the number of heads Bob gets, then $n-X$ is the number of tails Alice gets and $n+1-Y$ is the number of tails Bob gets. And then by symmetry both of them must have the same distribution.

**(b)** From we know **(a)** we know that $P(X<Y) = P(n-X<n+1-Y)$, we can simplify RHS as follows,
$$
P(n-X<n+1-Y) = P(Y < X+1) = P(Y \leq X) \quad \text{(}\because \text{X and Y are integers)}
$$
We know that $X<Y$ and $Y\leq X$ are complements and they have the same probability, which means that,
$$
P(X<Y) = P(Y\leq X) = \frac{1}{2}
$$
##### Algebraic Solution (Only For Part (a))

**Step 1: Expand the LHS using LOTP on $X$**
$$P(X < Y) = \sum_{k=0}^n P(X = k) P(Y > k)$$
Since $X \sim \operatorname{Bin}\left(n, \frac{1}{2}\right)$ and $Y \sim \operatorname{Bin}\left(n+1, \frac{1}{2}\right)$ are independent:
$$
\begin{align}
P(X = k) & = \binom{n}{k} \left(\frac{1}{2}\right)^n \\
P(Y > k) & = \sum_{j=k+1}^{n+1} \binom{n+1}{j} \left(\frac{1}{2}\right)^{n+1}
\end{align}
$$
Multiplying them together gives:
$$P(X < Y) = \frac{1}{2^{2n+1}} \sum_{k=0}^n \binom{n}{k} \sum_{j=k+1}^{n+1} \binom{n+1}{j}$$
**Step 2: Expand the RHS using LOTP on $X$**

First, rearrange the inequality inside the probability:
$$n - X < n + 1 - Y \iff Y < X + 1 \iff Y \le X$$
_(since $X$ and $Y$ take integer values)_

Now condition on $X = k$ and expanding using LOTP we get the following expression,
$$P(n - X < n + 1 - Y) = \frac{1}{2^{2n+1}} \sum_{k=0}^n \binom{n}{k} \sum_{j=0}^k \binom{n+1}{j}$$
**Step 3: Transform the LHS Sum into the RHS Sum**

Take the double sum in the LHS:
$$\sum_{k=0}^n \binom{n}{k} \sum_{j=k+1}^{n+1} \binom{n+1}{j}$$
Apply a change of variables (re-indexing) using binomial symmetry:

1. **Outer index:** Let $u = n - k$. As $k$ goes from $0$ to $n$, $u$ runs from $n$ down to $0$ (covering the same range $0 \le u \le n$). By symmetry:
$$\binom{n}{k} = \binom{n}{n-u} = \binom{n}{u}$$
2. **Inner index:** Let $v = (n + 1) - j$. When $j = k + 1$, the upper limit for $v$ is:
$$v = (n + 1) - (k + 1) = n - k = u$$
	When $j = n + 1$, the lower limit for $v$ is:
$$v = (n + 1) - (n + 1) = 0$$
	By symmetry:
$$\binom{n+1}{j} = \binom{n+1}{(n+1)-v} = \binom{n+1}{v}$$
Replacing $j$ with $v$, the inner sum becomes:
$$\sum_{j=k+1}^{n+1} \binom{n+1}{j} = \sum_{v=0}^u \binom{n+1}{v}$$
Putting both substitutions together:
$$\sum_{k=0}^n \binom{n}{k} \sum_{j=k+1}^{n+1} \binom{n+1}{j} = \sum_{u=0}^n \binom{n}{u} \sum_{v=0}^u \binom{n+1}{v}$$
Since $u$ and $v$ are dummy variables, renaming $u \to k$ and $v \to j$ gives:
$$\frac{1}{2^{2n+1}} \sum_{k=0}^n \binom{n}{k} \sum_{j=0}^k \binom{n+1}{j}$$
This is identical to the RHS expression, completing the algebraic proof.

>[!Note]
>Another way to look at it is that in RHS, we have $\binom{n}{k}$ being multiplied with first $k+1$ terms i.e. $\sum_{j=0}^{k}\binom{n+1}{j}$. Which means that $\binom{n}{n-k}$ is being multiplied with the sum of first $n-k+1$ terms.
>
>In LHS, $\binom{n}{k}$ is being multiplied with with the last $(n+1) - (k+1) + 1 = n-k+1$ terms, but we know that $\binom{n}{k} = \binom{n}{n-k}$, also the sum of first $n-k+1$ terms is the same as the sum of the last $n-k+1$ terms.
>
>Hence, for every term in RHS, there is a matching term in LHS.
