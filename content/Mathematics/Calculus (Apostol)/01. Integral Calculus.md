## 1.3 Functions Formal Definition and Examples

### Ordered Pair
We have seen that the order of elements in a set does not matter. Sets are unordered, but sometimes we do need order, that is where comes the ordered pair.

$\to$ If we have a pair of objects $a$ and $b$ and we wish to distinguish what comes first and what comes second then we write them in parenthesis as $(a, b)$. We refer to this as an ordered pair.

> [!NOTE]
> Unlike sets where $\{a, b\}$ is equal to $\{b, a\}$ always, for ordered pair we have positional equality.
> $$\implies (a, b) = (c, d) \implies a = c \ \& \ b = d$$

### Defn of Function
Formal defn of function states that "A function $f$ is a set of ordered pairs $(x, y)$ where no two of which have the same first member."

$\implies$ This is basically saying that in a function no inputs can have 2 distinct outputs.

$\implies$ The set of all $x$'s is called the **Domain** of the function.

$\implies$ The set of all $y$'s is called the **range** of the function.

> [!NOTE]
> From defn it is clear that a function can have any object in domain and any type object in the range.
> $\to$ But in calculus we mostly study functions where domain and range are subsets of real numbers.

> [!NOTE]
> If we want to indicate a pair is in the set of a function we have to write it as $(x, y) \in f$.
> $\to$ The same is more commonly written as $y = f(x)$, here $f(x)$ denotes the image of $x$ in function $f$.

### Some Common Functions

(i) **Constant Function:** $y = c$, for some $c \in \mathbb{R}$.

(ii) **Linear Functions:** $y = ax + b$, where $a, b \in \mathbb{R} \ \& \ a \neq 0$.

(iii) **The Power Functions:** $y = x^n$, where $n \in \mathbb{Z}^+$.

(iv) **Polynomial Functions:**
A polynomial of degree $n$ is defined as
$$P(x) = c_0 + c_1 x + \dots + c_n x^n = \sum_{k=0}^n c_k x^k$$
$\implies$ All functions covered so far are special cases of polynomials.

(v) **Circle:** $x^2 + y^2 = r^2$ is the equation of a circle with center as origin and radius as $r$.
$\implies$ Now for a given value of $x$ here we actually have 2 different values of $y$ which violates the defn of a function, hence here we have 2 functions one for bottom half and other for the top half.
$$\implies y = \sqrt{r^2 - x^2} \quad \& \quad y = -\sqrt{r^2 - x^2}$$

$$= x(c_1 + c_2 x + \dots + c_n x^{n-1})$$

$$p(x) = \sum_{k=0}^n c_k (x+a)^k$$
$$= \sum_{k=0}^n c_k \sum_{r=0}^k \binom{k}{r} x^r a^{k-r}$$

## 1.8 Partitions and Step Functions

Given a closed interval $[a, b]$, and we decompose it into $n$ subintervals by inserting $(n-1)$ points $x_1, x_2, \dots, x_{n-1}$. These points are such that they satisfy the conditions
$$a < x_1 < x_2 < \dots < x_{n-1} < b$$
$\implies$ A collection of points satisfying the above condition is called a partition of $[a, b]$.
$$P = \{a, x_1, \dots, x_{n-1}, b\}$$
$\implies$ It is convinient to write $a \ \& \ b$ as $x_0$ and $x_n$, hence the partition is given by
$$P = \{x_0, x_1, \dots, x_n\}$$

> [!NOTE]
> The partition consisting of $n+1$ points consists of $n$ subintervals
> $$[x_0, x_1], [x_1, x_2], \dots, [x_{n-1}, x_n]$$
> $\implies$ The $k$th subinterval is given by $[x_{k-1}, x_k]$ and it is called a closed subinterval.
> $\implies (x_{k-1}, x_k)$ is called the $k$th open subinterval.

### Defn of Step Function
A function $s$ whose domain is $[a, b]$ is called a step function if there is a partition $P = \{x_0, \dots, x_n\}$ of $[a, b]$ such that $s$ is constant on each open subinterval of $P$. That is to say, for each $k = 1, 2, \dots, n$ there is a number $s_k$ such that
$$s(x) = s_k \quad \text{if } x_{k-1} < x < x_k.$$

> [!NOTE]
> Step functions are sometimes called piece wise constant functions.

> [!NOTE]
> At each point of the endpoint $x_{k-1}$ and $x_k$ the function must have some well defined value but not necessarily same as $s_k$.

### Refinement of $P$:
given a partition $P$ we can always add more points in b/w the existing ones and create a new partition $P'$.

$\implies$ Such a partition $P'$ is called refinement of $P$ and is said to be finer than $P$.

> [!NOTE]
> If a step function is constant on all open intervals of $P$, then it is constant on all open intervals of $P'$.

### Sum and Product of Step Functions
New step functions can be formed by adding / multiplying existing step functions.

$\to$ If $s \ \& \ t$ are two step functions both defined in the same range then $[a, b]$. Let $P_1$ and $P_2$ be partitions of $[a, b]$ so that $s$ is constant on every open subinterval of $P_1$ and $t$ is for $P_2$.

$\to$ Then a function $u$ defined as
$$u(x) = s(x) + t(x) \quad \text{if } a \le x \le b$$
is also a step function.

$\to$ To prove this we first define the partition $P$ made by taking all points from $P_1$ and $P_2$.

$\to$ This partition made by union of $P_1$ and $P_2$ is called common refinement of $P_1$ and $P_2$.

$\to$ Now $s$ is constant on every open interval of $P$ and so is $t$.

$\to$ Hence their sum is also constant on every open interval of $P$. Therefore $u$ is constant on every open interval of $P$ making it a step function.

$\to$ Similarly the product $v = s \cdot t$ is also a step function with the same reason.

### Example: Prove the following properties of the greatest integer function $[x]$:
(a) $[x+n] = [x] + n \quad \forall n \in \mathbb{Z}$
(b) $[ -x ] = \begin{cases} -[x], & \text{if } x \in \mathbb{Z} \\ -[x] - 1, & \text{otherwise} \end{cases}$
(c) $[x+y] = [x] + [y] \text{ or } [x] + [y] + 1$
(d) $[2x] = [x] + \left[x + \frac{1}{2}\right]$

**solution:**
**(a)** Let $m = [x+n]$
$$\implies m \le x+n < m+1$$
$$\implies m-n \le x < m-n+1$$
$$\implies [x] = m-n \implies m = [x] + n$$
$$\implies [x+n] = [x] + n$$

**(b)** Let $m = [x]$
$$\implies m \le x < m+1$$
$$\implies -m-1 < -x \le -m < -m+1$$
When $x \in \mathbb{Z}$ we have $m = [x] = x$
$$\implies [-x] = -x = -[x]$$

When $x \notin \mathbb{Z}$ we use the inequality
$$-m-1 < -x \le -m < -m+1$$

> [!WARNING] Mathematical Error in Notes
> The notes write $-m-1 < -x \le -m < -m+1$. Since $x \notin \mathbb{Z}$, $-x$ cannot equal the integer $-m$, so strict inequality $-m-1 < -x < -m$ holds. Furthermore, $-m < -m+1$ is trivially true, but $-m$ is the least integer greater than $-x$, so $[-x] = -m-1 = -[x]-1$.

$\implies$ In this case $-m-1$ is closest integer $\le -x$
$$\implies [-x] = -m - 1 = -[x] - 1$$
$$\implies \text{Hence, } [-x] = \begin{cases} -[x], & x \in \mathbb{Z} \\ -[x]-1, & x \notin \mathbb{Z} \end{cases}$$

**(c)**
$$[x] \le x < [x] + 1$$
$$[y] \le y < [y] + 1$$
$$\implies [x] + [y] \le x+y < [x] + [y] + 2$$
$\implies$ Hence the only two integers that $[x+y]$ be are $[x] + [y]$ or $[x] + [y] + 1$.

**(d)**
$$[2x] = [x] + \left[x + \frac{1}{2}\right]$$
$$[x+x] = [x] + [x] \text{ or } [x] + [x] + 1$$

**Case 1:** $[2x] = 2[x]$
$$[2x] \le 2x < [2x] + 1$$
$$2[x] \le 2x < 2[x] + 1$$
$$\implies [x] \le x < [x] + \frac{1}{2}$$
$$\implies [x] < [x] + \frac{1}{2} \le x + \frac{1}{2} < [x] + 1$$
$$\implies [x] < x + \frac{1}{2} < [x] + 1$$
$$\implies \left[x + \frac{1}{2}\right] = [x]$$
$$\implies [2x] = 2[x] = [x] + \left[x + \frac{1}{2}\right]$$

**Case 2:** $[2x] = 2[x] + 1$
$$[2x] \le 2x < [2x] + 1$$
$$\implies 2[x] + 1 \le 2x < 2[x] + 2$$
$$\implies [x] + \frac{1}{2} \le x < [x] + 1$$
$$\implies [x] + 1 \le x + \frac{1}{2} < [x] + \frac{3}{2}$$
$$\implies [x] + 1 \le x + \frac{1}{2} < ([x] + 1) + 1$$
$$\implies \left[x + \frac{1}{2}\right] = [x] + 1$$
$$\implies [2x] = 2[x] + 1 = [x] + \left[x + \frac{1}{2}\right]$$

$\implies$ Hence we have $[2x] = [x] + \left[x + \frac{1}{2}\right]$ always true.

$$\sum_{n=1}^{b-1} \left[\frac{na}{b}\right] = \sum_{n=1}^{b-1} \left[\frac{(b-n)a}{b}\right]$$
$$= \sum_{n=1}^{b-1} \left[a - \frac{na}{b}\right] = (b-1)a + \sum_{n=1}^{b-1} \left[-\frac{na}{b}\right]$$

Now since $a$ and $b$ are coprimes we have that $\frac{na}{b} \ \forall n = 1, 2, \dots, b-1$ are not integers since $\text{LCM}(a, b) = ab$.

$$\implies \text{Hence } \sum_{n=1}^{b-1} \left[-\frac{na}{b}\right] = \sum_{n=1}^{b-1} \left(-\left[\frac{na}{b}\right] - 1\right)$$
$$= -\sum_{n=1}^{b-1} \left[\frac{na}{b}\right] - (b-1)$$
$$\implies \sum_{n=1}^{b-1} \left[\frac{na}{b}\right] = (b-1)a - \sum_{n=1}^{b-1} \left[\frac{na}{b}\right] - (b-1)$$
$$\implies \sum_{n=1}^{b-1} \left[\frac{na}{b}\right] = \frac{(a-1)(b-1)}{2}$$

## 1.11 The Integral for Step Functions and its Properties.

$\to$ Let $s$ be a step function defined on $[a, b]$ and let $P = \{x_0, x_1, \dots, x_n\}$ be a partition defined on $[a, b]$ such that $s$ is constant on every open subinterval of $P$.

$\to$ Let $s_k$ be the value of $s(x)$ when $x_{k-1} < x < x_k$.

$\to$ Now we are ready to define the integral of $s$ from $a$ to $b$,

### Defn of Integral of Step Function
The integral of $s$ from $a$ to $b$ denoted by the symbol $\int_a^b s(x) dx$ is defined by the following formula.
$$\int_a^b s(x) dx = \sum_{k=1}^n s_k (x_k - x_{k-1})$$

### Note Points:
(i) The values of the function at the subdivision points does not matter. They don't change the areas of rectangles and hence the integral.

(ii) It goes without saying that the integral represents the area of the ordinate set of $s$ in the range $[a, b]$.

(iii) The formula of the integral is independent of the choice of partition as long as $s$ is constant at every open interval in the chosen partition.

Eg. If we create a new partition by adding a new point between $x_0$ and $x_1$, then in the new integral all terms will remain same except for the first one, it will be replaced by the following,
$$s_1 (t - x_0) + s_1 (x_1 - t) = s_1 (x_1 - x_0)$$
$\implies$ Hence, adding $t$ did not change the integral.
$\implies$ This further means that the area of the finer partition $P'$ of $P$ is same as $P$ and hence the integral is same as well.

### Fundamental Properties of Integral of the Step Function

### Theorem 1.2 (Additive Property):
$$\int_a^b (s(x) + t(x)) dx = \int_a^b s(x) dx + \int_a^b t(x) dx.$$

**Proof:**
Assume that $P$ is a partition of $[a, b]$, $P = \{x_0, x_1, \dots, x_n\}$.
$\implies P$ is such that both $s \ \& \ t$ are constant at every open interval of $P$ (we can always find this by combining $P_s$ and $P_t$).
$$\implies \int_a^b (s(x) + t(x)) dx = \sum_{k=1}^n (s_k + t_k)(x_k - x_{k-1})$$
$$= \sum_{k=1}^n s_k (x_k - x_{k-1}) + \sum_{k=1}^n t_k (x_k - x_{k-1})$$
$$= \int_a^b s(x) dx + \int_a^b t(x) dx.$$
$\implies$ Hence Proved.

### Theorem 1.3 (Homogeneous Property):
For every real number $c$, we have
$$\int_a^b c \cdot s(x) dx = c \int_a^b s(x) dx$$

**Proof:**
$c \cdot s(x) = c \cdot s_k$ for $x_{k-1} < x < x_k$
$$\implies \int_a^b c \cdot s(x) dx = \sum_{k=1}^n c \cdot s_k (x_k - x_{k-1})$$
$$= c \sum_{k=1}^n s_k (x_k - x_{k-1}) = c \int_a^b s(x) dx.$$
$\implies$ Hence Proved.

> [!NOTE]
> Theorem 1.2 and 1.3 can be combined into a single one called Linearity Property.

### Theorem 1.4 (Linearity Property)
$$\int_a^b [c \cdot s(x) + d \cdot t(x)] dx = c \int_a^b s(x) dx + d \int_a^b t(x) dx$$

**Proof:**
Proof follows from direct application of theorems 1.2 and 1.3.

### Theorem 1.5 (Comparison Property)
If $s(x) < t(x) \ \forall x \in [a, b]$, then
$$\int_a^b s(x) dx < \int_a^b t(x) dx$$

**Proof:**
Again we consider a common partition in which both of these are constant, then we have $s_k < t_k$ when $x_{k-1} < x < x_k$.
$$\implies \sum_{k=1}^n s_k (x_k - x_{k-1}) < \sum_{k=1}^n t_k (x_k - x_{k-1})$$
$$\implies \int_a^b s(x) dx < \int_a^b t(x) dx.$$
$\implies$ Hence Proved.

### Theorem 1.6 Additivity with Respect to the interval of Integration.
$$\int_a^c s(x) dx + \int_c^b s(x) dx = \int_a^b s(x) dx$$

**Proof:**
$P_1$ be partition on $[a, c]$ with $s$ constant on every open interval of $P_1 \ \& \ P_1 = \{x_0, x_1, \dots, x_n\}$.

$\to$ Similarly, $P_2 = \{t_0, t_1, \dots, t_n\}$ on $[c, b]$ and $s$ constant on every open interval of $P_2$.

$\to$ Now, $P = P_1 \cup P_2 = \{y_0, y_1, \dots, y_m\}$ is a partition of $[a, b]$ and $s$ is constant at every open interval of $P$.
$$\implies \sum_{k=1}^{n_1} s_k (x_k - x_{k-1}) + \sum_{k=1}^{n_2} s_k (t_k - t_{k-1})$$
$$= \sum_{k=1}^n s_k (y_k - y_{k-1})$$
$\implies$ Hence we have that
$$\int_a^c s(x) dx + \int_c^b s(x) dx = \int_a^b s(x) dx.$$

### Theorem 1.7: Invariance under translation.
$$\int_a^b s(x) dx = \int_{a+c}^{b+c} s(x-c) dx, \quad \text{for every real } c.$$

**Proof:**
Now $s$ is step function in $[a, b]$ and $P = \{x_0, x_1, \dots, x_n\}$ be a partition of $[a, b]$ such that $s$ is constant at every open subinterval of $P$.
Now consider the function $t(x) = s(x-c)$, then $t$ is constant in $k$th open subinterval if
$$x_{k-1} < x-c < x_k$$
$$\implies x_{k-1} + c < x < x_k + c$$
$\implies$ Hence, $t$ is a step function at every in the interval $[a+c, b+c]$ and constant at every open interval of partition $P' = \{x_0 + c, \dots, x_n + c\}$
$$\implies \int_{a+c}^{b+c} t(x) dx = \sum_{k=1}^n s_k ((x_k + c) - (x_{k-1} + c))$$
$$= \sum_{k=1}^n s_k (x_k - x_{k-1})$$
$$= \int_a^b s(x) dx$$
$$\implies \int_a^b s(x) dx = \int_{a+c}^{b+c} t(x) dx = \int_{a+c}^{b+c} s(x-c) dx$$
$\implies$ Hence Proved.

### Theorem 1.8: Expansion or Contraction of the interval of Integration
$$\int_{ka}^{kb} s\left(\frac{x}{k}\right) dx = k \int_a^b s(x) dx, \quad \forall k > 0$$

**Proof:**
Again we take $t(x) = s\left(\frac{x}{c}\right)$ and we see that it is constant and takes the value $s_k$ in the interval $x_{k-1} < \frac{x}{c} < x_k$
$$\implies c x_{k-1} < x < c x_k \quad (\because c > 0)$$
$\implies$ Hence, $t$ is a step function in the interval $[ca, cb]$ and constant on every open subinterval of the partition $P' = \{c x_0, c x_1, \dots, c x_n\}$.
$$\implies \int_{ca}^{cb} t(x) dx = \sum_{k=1}^n s_k (c x_k - c x_{k-1})$$
$$= c \sum_{k=1}^n s_k (x_k - x_{k-1})$$
$$= c \int_a^b s(x) dx$$
$\implies$ Hence, Proved.

> [!NOTE] Notation Remark
> The proof interchanges the scaling factor notation between $k$ and $c$.

### Note About the Interval $a \ \& \ b$
So far it was assumed that in the integral $\int_a^b s(x) dx$, '$a$' is less than '$b$', but we can extend the idea of integral to have lower limit greater than upper.

$\implies$ When upper limit > lower limit we go from left to right of the interval and calculate the lengths of open sub-intervals as $(x_k - x_{k-1})$.

$\implies$ But when we put upper limit < lower limit then we are calculating subinterval lengths from right to left, this gives us the lengths as $(x_{k-1} - x_k) = -(x_k - x_{k-1})$
$$\implies \int_a^b s(x) dx = -\int_b^a s(x) dx$$

### Note Points:
(i) In the above formula, if we put $b = a$, we get that
$$\int_a^a s(x) dx = 0.$$

(ii) This helps us to modify the theorem 1.6 to work for any $c$, not necessarily in between $a \ \& \ b$. Theorem 1.6 in this new way is sometimes written as
$$\int_a^c s(x) dx + \int_c^b s(x) dx + \int_b^a s(x) dx = 0$$

(iii) **Reflection Property:** with this new idea we can now chose $k$ to be negative in theorem 1.8.
$\to$ More specifically when $k = -1$, we get
$$\int_a^b s(x) dx = -\int_{-a}^{-b} s(-x) dx = \int_{-b}^{-a} s(-x) dx$$
$\implies$ The above property is called the reflection property. Geometrically it looks like this.

## 1.12 Other Notation for Integrals

$\to$ The first thing is that the symbol '$x$' in the integral is arbitrary and has no effect on the value of the integral; commonly we will see other letters like $t, u, v, z$ etc. also being used.
$$\implies \int_a^b s(x) dx = \int_a^b s(t) dt = \int_a^b s(u) du = \dots$$

$\implies$ Some times the integral is written in short as $\int_a^b s$, $\int_a^b t$, omitting the symbol '$x$' completely further implying their irrelevance.

$\implies$ This makes writing certain formula very simple, e.g.
$$\int_a^b (s+t) = \int_a^b s + \int_a^b t$$

$\to$ But this also makes writing formulas like in theorem 1.7 & 1.8 more difficult.

### Example:
(a) Find the value of the integral
$$\int_0^2 [t^2] dt$$

(b) Prove that
$$\int_0^{n^2} [\sqrt{t}] dt = \frac{n(n-1)(4n+1)}{6},$$
for all positive integers $n$.

**Solution:**
**(a)** From the limits of the integral we see that
$$0 \le t \le 2 \implies 0 \le t^2 \le 4$$
$\implies$ Hence the partition of $[0, 2]$ on which $[t^2]$ is constant at every open interval is
$$P = \{0, 1, \sqrt{2}, \sqrt{3}, 2\}$$
$\implies$ The values that $[t^2]$ takes in these sub intervals are
$\implies s_1 = 0, \ s_2 = 1, \ s_3 = 2, \ s_4 = 3$.
$$\implies \int_0^2 [t^2] dt = \sum_{k=1}^4 s_k (x_k - x_{k-1})$$
$$= 0(1-0) + 1(\sqrt{2}-1) + 2(\sqrt{3}-\sqrt{2}) + 3(2-\sqrt{3})$$
$$= 5 - \sqrt{2} - \sqrt{3}$$
$$\implies \int_0^2 [t^2] dt = 5 - \sqrt{2} - \sqrt{3}$$

**(b)** Given that $0 \le t \le n^2 \implies 0 \le \sqrt{t} \le n$

$\implies$ The break points will be where $\sqrt{t}$ is an integer, hence the partition we choose is
$$P = \{0, 1^2, 2^2, 3^2, \dots, n^2\}$$
$\implies$ The value of $[\sqrt{t}]$ b/w $(k-1)^2 \ \& \ k^2$ is $k-1$.
$$\implies \int_0^{n^2} [\sqrt{t}] dt = \sum_{k=1}^n (k-1)(k^2 - (k-1)^2)$$
$$= \sum_{k=1}^n (k-1)(2k-1) = \sum_{k=1}^n (2k^2 - 3k + 1)$$
$$= 2 \sum k^2 - 3 \sum k + \sum 1$$
$$= \frac{2 \cdot n(n+1)(2n+1)}{6} - \frac{3 \cdot n(n+1)}{2} + n$$
$$= \frac{n(n-1)(4n+1)}{6}$$

### Important Misconception: Signed Area
$\implies$ We mentioned that the integral calculates the area of the step functions. Well that is true if the step function is non-negative.

$\implies$ If we read the defn we see that if $s_k < 0$ then the product that we get $s_k (x_k - x_{k-1})$ is also $< 0$ (assuming $x_k - x_{k-1} > 0$) and that is what is added to the sum.

$\implies$ Hence, what the integral calculates is the signed area, which is -ve when the steps are below the x-axis.

## 1.14 Integral of More General Functions

### Bounded Function
The function $f$ is said to be bounded on the interval $[a, b]$ if there is a number $M > 0$ such that
$$-M \le f(x) \le M, \quad \forall x \in [a, b]$$
$$\implies |f(x)| \le M, \quad \forall x \in [a, b]$$

> [!note]
> First we will define the integral for bounded functions only and then later we will define it for unbounded functions like $\frac{1}{x}$, i.e.,
> $$f(x) = \begin{cases} \frac{1}{x}, & x \ne 0 \\ 0, & \text{if } x = 0 \end{cases}$$
> $\implies f(x)$ is unbounded on any interval $[a, b]$ containing the origin.

### Definition of the Integral of a Bounded Function

Let $f$ be a function defined and bounded on $[a, b]$. Let $s$ and $t$ denote arbitrary step functions in the interval $[a, b]$ such that
$$s(x) \le f(x) \le t(x), \quad \forall x \in [a, b] \tag{1}$$

If there is one and only one number $I$ such that
$$\int_a^b s(x)\,dx \le I \le \int_a^b t(x)\,dx$$
for every pair of step functions $s$ and $t$ satisfying $(1)$, then this number $I$ is called the **integral of $f$ from $a$ to $b$**, and is denoted by $\int_a^b f(x)\,dx$. When such an $I$ exists, the function $f$ is said to be **integrable** on $[a, b]$.

> [!note] Terminology
> 1. The function $f$ is called the **integrand**.
> 2. The numbers $a$ and $b$ are called the **limits of integration**.
> 3. The interval $[a, b]$ is called the **interval of integration**.

## 1.15 Upper and Lower Integrals

$\implies$ Assume that $f$ is bounded on $[a, b]$. If $s$ and $t$ are step functions satisfying $(1)$ in the definition:
$\rightarrow$ We say $s$ is *below* $f$ and $t$ is *above* $f$, and we write
$$s(x) \le f \le t(x)$$

$\implies$ Let $S$ denote the set of all numbers $\int_a^b s(x)\,dx$ obtained as $s$ runs through all step functions below $f$, and let $T$ be the set of all numbers $\int_a^b t(x)\,dx$ obtained as $t$ runs through all the step functions above $f$:
$$S = \left\{ \int_a^b s(x)\,dx \;\middle|\; s \le f \right\}$$
$$T = \left\{ \int_a^b t(x)\,dx \;\middle|\; f \le t \right\}$$

$\implies$ Both the sets are non-empty since $f$ is bounded.

$\implies$ Also earlier we proved that if $s(x) \le f \le t(x) \implies s(x) \le t(x)$ for all $x$, then
$$\int_a^b s(x)\,dx \le \int_a^b t(x)\,dx$$

$\implies$ Hence, the set $S$ has a supremum and the set $T$ has an infimum, and they follow the relation:
$$\int_a^b s(x)\,dx \le \sup S \le \inf T \le \int_a^b t(x)\,dx$$

$\implies$ Now, from the definition of the integral of $f$, it will only exist when
$$\sup S = \inf T = I$$

$\rightarrow$ The number $\sup S$ is called the **lower integral** of $f$ and it is denoted by $\underline{I}(f)$.

$\rightarrow$ The number $\inf T$ is called the **upper integral** of $f$ and is denoted by $\overline{I}(f)$.

---

### Theorem 1.9

> Every function $f$ which is bounded on $[a, b]$ has a lower integral $\underline{I}(f)$ and an upper integral $\overline{I}(f)$ satisfying the inequalities
> $$\int_a^b s(x)\,dx \le \underline{I}(f) \le \overline{I}(f) \le \int_a^b t(x)\,dx$$
> for all step functions $s$ and $t$ with $s \le f \le t$. The function $f$ is integrable on $[a, b]$ if and only if its upper and lower integrals are equal, in which case we have
> $$\int_a^b f(x)\,dx = \underline{I}(f) = \overline{I}(f)$$

#### Proof
We have already proved this previously.

## 1.16 Area of Ordinate Set Expressed As An Integral

### Theorem 1.10

> Let $f$ be a non-negative function, integrable on the interval $[a, b]$, and let $Q$ denote the ordinate set of $f$ over $[a, b]$. Then $Q$ is measurable and its area is equal to the integral $\int_a^b f(x)\,dx$.

#### Proof
Since $f$ is integrable on $[a, b]$, then $I = \int_a^b f(x)\,dx$ is the only number that satisfies
$$\int_a^b s(x)\,dx \le I \le \int_a^b t(x)\,dx$$
for all step functions $s$ & $t$ such that $s(x) \le f(x) \le t(x)$, for all $x \in [a, b]$.

$\implies$ Now, $Q$ is the ordinate set of $f$. Let $S$ and $T$ be 2 step regions such that
$$S \subseteq Q \subseteq T$$

$\implies$ Associated with these step regions are step functions $s$ and $t$. Now we already showed that the area of step regions is its integral:
$$\implies a(S) = \int_a^b s(x)\,dx, \quad a(T) = \int_a^b t(x)\,dx$$

$\implies$ Since $S$ and $T$ are measurable, $Q$ is also measurable and $a(Q)$ satisfies the following inequality:
$$a(S) \le a(Q) \le a(T)$$
$$\implies \int_a^b s(x)\,dx \le a(Q) \le \int_a^b t(x)\,dx$$

Now, since $I$ is the only integer that satisfies $\int_a^b s(x)\,dx \le I \le \int_a^b t(x)\,dx$
$\implies I$ is the only integer satisfying $a(S) \le I \le a(T)$, and hence by the principle of exhaustion we can say that $Q$ is measurable and
$$\boxed{a(Q) = \int_a^b f(x)\,dx}$$

> The word should be **number** (real number), not *integer*, as the integral $I$ is a real number and not restricted to being an integer.

### Theorem 1.11

> Let $f$ be a non-negative function, integrable on an interval $[a, b]$. Then the graph of $f$, that is the set
> $$\{(x, y) \mid a \le x \le y, \, y = f(x)\}$$
> is measurable and has area equal to $0$.

> [!warning] Mathematical Error in Notes
> In the definition of the graph of $f$, the notes write:
> $$\{(x, y) \mid a \le x \le y, \, y = f(x)\}$$
> The condition on $x$ contains an error: it should be $a \le x \le b$, not $a \le x \le y$.

#### Proof
Let $Q$ denote the ordinate set of function $f$:
$$\implies Q = \{(x, y) \mid a \le x \le b, \, 0 \le y \le f(x)\}$$

$\implies$ Now, let $Q'$ be the set of points that remain after all points on the graph of $f$ are removed from $Q$:
$$\implies Q' = \{(x, y) \mid a \le x \le b, \, 0 \le y < f(x)\}$$

$\implies$ The area of $Q'$ is the same as the area of $Q$. This is because the area of $Q$ is the $\sup\{a(S) \mid S \subseteq Q\}$, i.e., supremum of area of sets of all step regions $S$ that are subsets of $Q$.

$\implies$ If we create another set $\{a(S') \mid S' \subseteq Q'\}$, then the supremum of this set is also the same.
$$\implies a(Q) = a(Q') \quad \& \quad Q' \subseteq Q$$

$\implies Q - Q'$ is measurable and we have that
$$a(Q - Q') = a(Q) - a(Q') = 0$$
$\implies$ Hence, proved.

## 1.18 Monotonic and Piecewise Monotonic Functions

$\rightarrow$ A function $f$ is said to be **monotonic** in the interval $[a, b]$ if it is either increasing in $[a, b]$ or decreasing in $[a, b]$.
$\rightarrow$ **Increasing** means $x < y \implies f(x) \le f(y)$
$\rightarrow$ **Strictly Increasing** $\implies x < y \implies f(x) < f(y)$
$\rightarrow$ **Decreasing** $\implies x < y \implies f(x) \ge f(y)$
$\rightarrow$ **Strictly Decreasing** $\implies x < y \implies f(x) > f(y)$

### Piecewise Monotonic
A function $f$ is called **piecewise monotonic** if there exists a partition $P$ on $[a, b]$ such that $f$ is monotonic on each of the open subintervals of $P$.

### Example: The Power Functions
If $p$ is a positive integer, we have the inequality
$$x^p < y^p \quad \text{if } 0 \le x < y$$

## 1.19 Integrability of Bounded Monotonic Function

### Theorem 1.12

> If $f$ is monotonic on the closed interval $[a, b]$, then $f$ is integrable on $[a, b]$.

#### Proof
Given that $f$ is monotonic on $[a, b]$. Let $P$ be a partition on $[a, b]$ having $n$ equal subintervals; then the length of each interval is
$$x_k - x_{k-1} = \frac{b-a}{n} \tag{1}$$

$\implies$ Now we define two step functions $s$ and $t$ such that
$$s(x) = f(x_{k-1}), \quad \text{if } x_{k-1} < x < x_k$$
$$t(x) = f(x_k), \quad \text{if } x_{k-1} < x < x_k$$

$$\implies \int_a^b t - \int_a^b s = \sum_{k=1}^n f(x_k)(x_k - x_{k-1}) - \left( \sum_{k=1}^n f(x_{k-1})(x_k - x_{k-1}) \right)$$
$$= \frac{b-a}{n} \sum_{k=1}^n (f(x_k) - f(x_{k-1}))$$
$$= \frac{(b-a)(f(b) - f(a))}{n}$$
$$= \frac{C}{n}, \quad \text{where } C = (b-a)(f(b) - f(a))$$

Now, we know that
$$\int_a^b s \le \underline{I}(f) \le \int_a^b t$$
$$\int_a^b s \le \overline{I}(f) \le \int_a^b t$$

$$\implies -\int_a^b t \le -\underline{I}(f) \le -\int_a^b s$$
$$\implies -\left(\int_a^b t - \int_a^b s\right) \le \overline{I}(f) - \underline{I}(f) \le \int_a^b t - \int_a^b s$$
$$\implies \boxed{0 \le |\overline{I}(f) - \underline{I}(f)| \le \frac{C}{n}}$$
$$\implies \overline{I}(f) - \underline{I}(f) = 0$$
$$\implies \overline{I}(f) = \underline{I}(f) \implies f \text{ is integrable}$$

$\hookrightarrow$ This is similar to $x \le a \le x + \frac{y}{n}$.
Here, $x = 0$ & $y = C$ and the inequality is true for all $n \in \mathbb{Z}^+$.

> [!note] Notation in Notes
> In this portion of the proof, the notes write the lower and upper integrals as $\underline{I}(x)$ and $\overline{I}(x)$ instead of $\underline{I}(f)$ and $\overline{I}(f)$.

#### Geometric Meaning

$\implies$ As we keep increasing $n$, we can make this arbitrarily small and hence this implies that $\overline{I}(f) - \underline{I}(f)$ must be $0$.

## 1.20 Integral of Bounded Monotonic Function

### Theorem 1.13

> Assume $f$ is increasing on a closed interval $[a, b]$. Let $x_k = a + k \frac{(b-a)}{n}$ for $k = 0, 1, 2, \dots, n$. If $I$ is any number which satisfies the inequalities
> $$\frac{b-a}{n} \sum_{k=0}^{n-1} f(x_k) \le I \le \frac{b-a}{n} \sum_{k=1}^n f(x_k)$$
> for every integer $n \ge 1$, then
> $$I = \int_a^b f(x)\,dx$$

#### Proof
The same set of inequalities were proved to be true for $\int_a^b f(x)$, and given that it is true for $I$ also:
$$\implies \int_a^b s \le I \le \int_a^b t$$
$$\implies \int_a^b s \le \int_a^b f(x)\,dx \le \int_a^b t$$
$$\implies -\left(\int_a^b t - \int_a^b s\right) \le I - \int_a^b f \le \int_a^b t - \int_a^b s$$
$$\implies 0 \le \left| I - \int_a^b f \right| \le \int_a^b t - \int_a^b s = \frac{C}{n}$$
$$\implies I = \int_a^b f(x)\,dx$$
$\implies$ Hence, Proved.

## 1.22 The Basic Properties of The Integral

### 1.16 Linearity with Respect to the Integrand

> If both $f$ and $g$ are integrable on $[a, b]$, so is $c_1 f + c_2 g$ for every pair of constants $c_1$ and $c_2$. Furthermore we have
> $$\int_a^b (c_1 f + c_2 g) = c_1 \int_a^b f + c_2 \int_a^b g$$

> [!note] Generalization by Induction
> By using mathematical induction the linearity property can be generalized as follows:
> If $f_1, f_2, \dots, f_n$ are all integrable on $[a, b]$, then so is $c_1 f_1 + c_2 f_2 + \dots + c_n f_n$ for all real $c_1, c_2, \dots, c_n$, and
> $$\int_a^b \sum_{k=1}^n c_k f_k = \sum_{k=1}^n c_k \int_a^b f_k$$

#### Proof
We will prove this by proving the following two separately:
$$\int (f+g) = \int f + \int g \quad \text{and} \quad \int_a^b cf = c \int_a^b f, \quad \forall c \in \mathbb{R}$$

**(i) Proof of Additivity:**
Let $S_1$ be the set of integrals of all step functions $\le f(x)$ in $[a, b]$:
$$\implies S_1 = \left\{ \int_a^b s_1(x)\,dx \;\middle|\; s_1(x) \le f(x) \right\}$$
$$\implies \underline{I}(f) = \sup S_1$$

Similarly, let $S_2$ be the set for $g(x)$:
$$\implies S_2 = \left\{ \int_a^b s_2(x)\,dx \;\middle|\; s_2(x) \le g(x) \right\}$$
$$\implies \underline{I}(g) = \sup S_2$$

$\implies$ Now consider the set $S_1 + S_2$. Using the additive property of supremum, we get:
$$\sup(S_1 + S_2) = \sup S_1 + \sup S_2$$

$\implies$ Now, consider a step function $s = s_1 + s_2$ where $s_1 \le f$ and $s_2 \le g, \; \forall x \in [a, b]$:
$$\implies s = s_1 + s_2 \le f + g$$
$\implies$ In fact all step functions $\le f+g$ are of this form.
$$\implies \underline{I}(f+g) = \sup\left\{ \int_a^b s \;\middle|\; s \le f+g \right\}$$
$$\implies \underline{I}(f+g) = \sup\left\{ \int_a^b s_1 + s_2 \;\middle|\; s_1 + s_2 \le f+g \right\}$$
$$\implies \underline{I}(f+g) = \sup\left\{ \int_a^b s_1 + \int_a^b s_2, \; s_1 \le f, \, s_2 \le g \right\}$$
$$\implies \underline{I}(f+g) = \sup S_1 + \sup S_2 = \underline{I}(f) + \underline{I}(g)$$

> [!warning] Mathematical Error in Notes
> The notes claim: *"In fact all step functions $\le f+g$ are of this form."* (asserting that any step function $s \le f+g$ can be decomposed directly as $s = s_1 + s_2$ with $s_1 \le f$ and $s_2 \le g$).
> This claim is incorrect in general. While it is always true that $s_1 \le f$ and $s_2 \le g \implies s_1 + s_2 \le f+g$ (which proves the inequality $\underline{I}(f+g) \ge \underline{I}(f) + \underline{I}(g)$), not every step function under $f+g$ splits into components beneath $f$ and $g$ individually.

$\implies$ Similarly we can prove that $\overline{I}(f+g) = \overline{I}(f) + \overline{I}(g)$ by using step functions $t_1 \ge f$ & $t_2 \ge g$.
$$\implies \text{Hence, we have that } \int_a^b (f+g) = \int_a^b f + \int_a^b g$$

**(ii) Proof of Homogeneity:**
Now, for every step function $s \le f$, we have $cs \le cf$ for all $c > 0$.
$\implies$ In fact for every step function $s \le cf$ we have a step function $s_1 = \frac{s}{c}$ which is $\le f$.
$$\implies \underline{I}(cf) = \sup\left\{ \int_a^b cs\,dx, \; s \le f \right\} = c \cdot \sup\left\{ \int_a^b s, \; s \le f \right\}$$
$$\underline{I}(cf) = c \int_a^b f$$

In a similar way we can prove that $\overline{I}(cf) = c \int_a^b f$ by using step functions $t_1 \ge f \implies ct_1 \ge cf$.
$$\implies \underline{I}(cf) = \overline{I}(cf) = c \int_a^b f$$
$$\boxed{\int_a^b cf = c \int_a^b f, \quad \forall c > 0}$$

$\implies$ When $c < 0$, we will do the same thing just that for every $s_1 \le f$ we will get $t = cs_1 \ge cf$ & for every $t_1 \ge f$, we will get $s = ct_1 \le cf$.

$\implies$ When $c = 0$, both the integrals are $0$ and hence we get that:
$$\boxed{\int_a^b cf = c \int_a^b f \quad \forall c \in \mathbb{R}}$$

### Theorem 1.17: Additivity with Respect to the Interval of Integration

> If two of the following three integrals exist, the third one also exists, and we have
> $$\int_a^b f + \int_b^c f = \int_a^c f$$

#### Proof
Let $a < b < c$ for this proof and later we will show that it works for any arrangement of $a, b, c$.
$\implies$ The function $f$ is integrable on $[a, b]$ & $[b, c]$. Let $s_1 \le f$ on $[a, b]$ and $s_2 \le f$ on $[b, c]$.
$$\implies \int_a^b f = \sup\left\{ \int_a^b s_1 \;\middle|\; s_1 \le f \right\}$$
$$\implies \int_b^c f = \sup\left\{ \int_a^b s_2 \;\middle|\; s_2 \le f \right\}$$

> [!warning] Mathematical Error in Notes
> In the equation for $\int_b^c f$, the notes write:
> $$\int_b^c f = \sup\left\{ \int_a^b s_2 \;\middle|\; s_2 \le f \right\}$$
> The limits of integration inside the set are incorrectly written as $\int_a^b s_2$ instead of $\int_b^c s_2$.

$$\implies \int_a^b f + \int_b^c f = \sup\left\{ \int_a^b s_1 + \int_b^c s_2 \;\middle|\; s_1 \le f, \, s_2 \le f \right\}$$

$\implies$ Now, consider step function $s \le f$ on $[a, c]$, we can always divide into two step functions $s_1$ & $s_2$ defined on $[a, b]$ & $[b, c]$ respectively:
$$s = \begin{cases} s_1, & x \in [a, b] \\ s_2, & x \in [b, c] \end{cases}$$

$$\implies \underline{I}(f) = \sup\left\{ \int_a^c s \;\middle|\; s \le f \right\} = \sup\left\{ \int_a^b s + \int_b^c s \;\middle|\; s \le f \right\} = \sup\left\{ \int_a^b s_1 + \int_b^c s_2, \; s_1 \le f, \, s_2 \le f \right\}$$
$$\implies \underline{I}(f) = \int_a^b f + \int_b^c f$$

$\implies$ Similarly, we can prove that
$$\overline{I}(f) = \int_a^b f + \int_b^c f$$
$$\implies \int_a^c f = \int_a^b f + \int_b^c f$$

#### Note: Other Arrangements of $a, b, c$
**(i) $a < c < b$:**
In this case we rewrite the equation as:
$$\int_a^c f - \int_b^c f = \int_a^b f$$
$$\text{But } -\int_b^c f = \int_c^b f$$
$$\rightarrow \int_a^c f + \int_c^b f = \int_a^b f$$
$\implies$ We have proved such an arrangement to be true.

**(ii) $b < a < c$:**
In this case we write the equation as:
$$\int_a^b f + \int_b^c f = \int_a^c f$$
$$\implies -\int_b^a f + \int_b^c f = \int_a^c f$$
$$\implies \int_b^a f + \int_a^c f = \int_b^c f$$

$\implies$ Hence, in similar way all other arrangements of $a, b, c$ can be proved.

### Theorem 1.18: Invariance Under Translation

> If $f$ is integrable on $[a, b]$, then for every real $c$ we have
> $$\int_a^b f(x)\,dx = \int_{a+c}^{b+c} f(x-c)\,dx$$

#### Proof
Let $g(x) = f(x-c)$; this function is defined on $[a+c, b+c]$.
$\implies$ Now, for every step function $s_1(x) \le f(x)$ on $[a, b]$, we have step function $s(x) = s_1(x-c)$ defined on $[a+c, b+c]$.
$$\implies s(x) = s_1(x-c) \le f(x-c) = g(x) \implies s(x) \le g(x)$$

$$\implies \underline{I}(g) = \sup\left\{ \int_{a+c}^{b+c} s(x)\,dx \;\middle|\; s(x) \le g(x) \right\}$$
$$= \sup\left\{ \int_{a+c}^{b+c} s_1(x-c)\,dx \;\middle|\; s(x-c) \le f(x-c) \right\}$$
$$= \sup\left\{ \int_a^b s_1(x)\,dx \;\middle|\; s_1(x) \le f(x) \right\}$$

$\implies$ The last step was the result of
$$\int_{a+c}^{b+c} s_1(x-c) = \int_a^b s_1(x) \quad \text{for step functions.}$$
$\implies$ This we have proved already.
$$\implies \underline{I}(g) = \int_a^b f(x)\,dx$$

$\implies$ Similarly we can prove that
$$\overline{I}(g) = \int_a^b f(x)\,dx$$
$$\implies \boxed{\int_{a+c}^{b+c} f(x-c)\,dx = \int_a^b f(x)\,dx}$$

### Theorem 1.19: Expansion or Contraction of the Interval of Integration

> If $f$ is integrable on $[a, b]$, then for every real $k \ne 0$ we have
> $$\int_a^b f(x)\,dx = \int_{ka}^{kb} f\left(\frac{x}{k}\right) dx$$

> [!warning] Mathematical Error in Notes
> In the theorem statement, the scale factor $\frac{1}{k}$ is missing on the right-hand side. The statement should be:
> $$\int_a^b f(x)\,dx = \frac{1}{k} \int_{ka}^{kb} f\left(\frac{x}{k}\right) dx$$
> (This correct factor is later derived and written in the box on the right column of the notes).

#### Proof (Case $k > 0$)
Assuming $k > 0$, assume $g(x) = f\left(\frac{x}{k}\right)$ is a function defined on $[ka, kb]$.
$\implies$ For every step function $s_1(x) \le f(x)$ we have a step function $s(x) = s_1\left(\frac{x}{k}\right)$ defined on $[ka, kb]$ and
$$s(x) = s_1\left(\frac{x}{k}\right) \le f\left(\frac{x}{k}\right) = g(x) \implies s(x) \le g(x)$$

$\implies$ In fact every step function $s(x) \le g(x)$ can be written in the form of $s_1\left(\frac{x}{k}\right)$.
$$\implies \underline{I}(g) = \sup\left\{ \int_{ka}^{kb} s(x)\,dx \;\middle|\; s(x) \le g(x) \right\}$$
$$= \sup\left\{ \int_{ka}^{kb} s_1\left(\frac{x}{k}\right) dx \;\middle|\; s_1\left(\frac{x}{k}\right) \le f\left(\frac{x}{k}\right) \right\}$$
$$= \sup\left\{ k \int_a^b s_1(x)\,dx \;\middle|\; s_1(x) \le f(x) \right\}$$
$$\implies \underline{I}(g) = k \int_a^b f(x)\,dx$$

$\implies$ Similarly we can prove that
$$\overline{I}(g) = k \int_a^b f(x)\,dx$$
$$\implies \int_{ka}^{kb} f\left(\frac{x}{k}\right) = k \int_a^b f(x)$$
$$\implies \boxed{\int_a^b f(x)\,dx = \frac{1}{k} \int_{ka}^{kb} f\left(\frac{x}{k}\right) dx}$$

#### Case $k < 0$
> [!note]
> The case when $k < 0$ is very similar. In this case $g(x)$ is defined on $[kb, ka]$ and everything goes on similarly:

$$\int_{kb}^{ka} s(x)\,dx = -\int_{ka}^{kb} s\left(\frac{x}{k}\right) dx = -k \int_a^b s(x)\,dx$$
$$\implies \sup\left\{ \int_{kb}^{ka} s\left(\frac{x}{k}\right) dx \right\} = (-k) \sup\left\{ \int_a^b s(x)\,dx \right\}$$
$$\implies \underline{I}(g) = -k \int_a^b f(x)\,dx$$

$\implies$ Similarly, we can show that
$$\overline{I}(g) = -k \int_a^b f(x)\,dx$$
$$\implies \int_{kb}^{ka} f\left(\frac{x}{k}\right) dx = -k \int_a^b f(x)\,dx$$
$$\implies \boxed{\int_a^b f(x)\,dx = \frac{1}{k} \int_{ka}^{kb} f\left(\frac{x}{k}\right) dx}$$

> [!note]
> In both the theorems 1.18 & 1.19 we see that the existence of the integral of one type makes the existence of the other one automatically true.

### Supplementary Notes: Supremum and Infimum Properties with Scalar Multiplication

#### Note: Proof of $\sup cS = c \sup S$ when $c > 0$
**Proof:**
Let $S' = cS = \{cs \mid s \in S\}$.
Let $\sup S = b \implies s \le b, \quad \forall s \in S$
$$\implies cs \le cb, \quad \forall cs \in S'$$
$\implies cb$ is an upper bound of $S'$, hence $\sup S' \le cb$.

$\implies$ If $\sup S' < cb$, then we have:
$$\frac{1}{c} \sup S' < b \quad \& \quad cs \le \sup S'$$
$$\implies s \le \frac{1}{c} \sup S' < b \implies \frac{1}{c} \sup S' \text{ is an upper bound of } S \text{ and } < b\text{, which is a contradiction.}$$
$$\implies \sup S' = cb = c \sup S$$
$$\boxed{\sup cS = c \sup S}$$

#### Note: Proof of $\inf cS = c \sup S$ when $c < 0$
**Proof:**
$S' = cS = \{cs \mid s \in S\}$.
$\implies$ Let $\sup S = b \implies s \le b$.
$$\implies cs \ge cb \implies cb \text{ is a lower bound of } S' \implies \inf S' \ge cb$$

$\implies$ If $\inf S' > cb \implies \frac{1}{c} \inf S' \le b$
$\implies$ Also, $\inf S' \le cs \implies \frac{1}{c} \inf S' \ge s$.
$\implies \frac{1}{c} \inf S'$ is an upper bound of $S$ and $\frac{1}{c} \inf S' < b$, which is a contradiction.

> [!warning] Mathematical Error in Notes
> On the transition between pages 35 and 36, the notes write $\inf S' > cb \implies \frac{1}{c} \inf S' \le b$ before using the strict inequality $\frac{1}{c} \inf S' < b$ for the contradiction. When dividing an inequality by negative $c$, strict inequality is preserved in reverse: $\inf S' > cb \implies \frac{1}{c} \inf S' < b$.

$\implies$ Hence we have:
$$\inf S' = \inf cS = cb = c \sup S$$
$$\boxed{\inf cS = c \sup S}$$

#### Note: Application to Theorem 1.16 when $c < 0$
**Proof:**
If $c < 0$, we have that for every step function $s \le f$ on $[a, b]$, we get a step function $t = cs \ge cf$.
$$\implies \overline{I}(cf) = \inf\left\{ \int_a^b t(x)\,dx \;\middle|\; t \ge cf \right\}$$
$$= \inf\left\{ c \int_a^b s(x)\,dx \;\middle|\; s \le f \right\}$$
$$= c \sup\left\{ \int_a^b s(x)\,dx \;\middle|\; s \le f \right\}$$
$$= c \int_a^b f(x)\,dx$$

$\implies$ Similarly we can prove that
$$\underline{I}(cf) = c \int_a^b f(x)\,dx$$
$$\implies \boxed{\int_a^b cf = c \int_a^b f, \quad \forall c \in \mathbb{R}}$$

### Theorem 1.20 (Comparison Theorem)

> If both $f$ and $g$ are integrable on $[a, b]$ and if $g(x) \le f(x)$ for every $x$ in $[a, b]$, then we have
> $$\int_a^b g(x)\,dx \le \int_a^b f(x)\,dx$$

#### Proof
Consider every step function $s \le g$ in $[a, b]$ and every step function $t \ge f$ in $[a, b]$.
$$\implies s \le g \le f \le t$$
$$\implies s \le t, \quad \forall x \in [a, b]$$
$$\implies \int_a^b s \le \int_a^b t$$
$$\implies \sup\left\{ \int_a^b s \right\} \le \inf\left\{ \int_a^b t \right\}$$
$$\implies \int_a^b g(x)\,dx \le \int_a^b f(x)\,dx$$
$\implies$ Hence proved.

> [!note] Non-negative Functions
> If $f(x) \ge 0, \; \forall x \in [a, b]$, then the above theorem states that
> $$\int_a^b f(x)\,dx \ge 0$$
> $\implies$ The integral of a non-negative function is also non-negative.

## 1.23 Integral of Polynomials

$\rightarrow$ We have established that the value of the integral
$$\int_0^b x^p\,dx = \frac{b^{p+1}}{p+1}$$
for $b > 0$ and $p \ge 0$.

$\rightarrow$ When $b = 0$, then the integral $= 0$.

$\rightarrow$ When $b < 0$, we have that $-b > 0$:
$$\implies \int_0^{-b} x^p\,dx = \frac{(-b)^{p+1}}{p+1}$$

$\implies$ Using Theorem 1.19 we get that:
$$\int_0^{-b} x^p = -\int_0^b (-x)^p\,dx = (-1)^{p+1} \int_0^b x^p\,dx$$
$$\implies (-1)^{p+1} \int_0^b x^p\,dx = \frac{(-b)^{p+1}}{p+1} = \frac{(-1)^{p+1} b^{p+1}}{p+1}$$
$$\implies \boxed{\int_0^b x^p = \frac{b^{p+1}}{p+1}, \quad b < 0}$$
$\implies$ Hence the formula is true for $b < 0$ as well.

### Integral of $\int_a^b x^p\,dx$
We can use Theorem 1.17 to get:
$$\int_a^b x^p\,dx = \int_0^b x^p\,dx - \int_0^a x^p\,dx$$
$$\boxed{\int_a^b x^p\,dx = \frac{b^{p+1} - a^{p+1}}{p+1}}$$
$\implies$ Hence proved.

### Integral of a Polynomial $\sum_{k=0}^n c_k x^k$
$\implies$ Using the theorems and formulas derived so far, we can get the integral of any general polynomial:
$$\int_a^b \left( \sum_{k=0}^n c_k x^k \right) dx = \sum_{k=0}^n c_k \int_a^b x^k = \sum_{k=0}^n c_k \left( \frac{b^{k+1} - a^{k+1}}{k+1} \right)$$
$$\implies \boxed{\int_a^b \sum_{k=0}^n c_k x^k\,dx = \sum_{k=0}^n c_k \left( \frac{b^{k+1} - a^{k+1}}{k+1} \right)}$$

### Example
If $f$ is integrable on $[a, b]$, then derive the following formulae:
(a) $\int_a^b f(x)\,dx = (b-a) \int_0^1 f(a + (b-a)x)\,dx$
(b) $\int_a^b f(Ax + B) = \begin{cases} \frac{1}{A} \int_{Aa+B}^{Ab+B} f(x)\,dx, & A \ne 0 \\ (b-a) f(B), & \text{if } A = 0 \end{cases}$

> [!warning] Mathematical Error in Notes
> 1. In formula (b), the differential $dx$ is omitted from the left-hand integral: $\int_a^b f(Ax + B)$ should be $\int_a^b f(Ax + B)\,dx$.
> 2. For the $A = 0$ case, the handwritten note writes $(b-a) f(b)$ or $(b-a) F(b)$ instead of $(b-a) f(B)$. When $A = 0$, $f(Ax+B) = f(B)$ is constant, so $\int_a^b f(B)\,dx = (b-a) f(B)$.

#### Solution

**(a)**
$$\int_a^b f(x)\,dx = (b-a) \int_a^b f\left( \frac{(b-a)x}{b-a} \right) \frac{dx}{b-a}$$
$$= (b-a) \int_{\frac{a}{b-a} - \frac{a}{b-a}}^{\frac{b}{b-a} - \frac{a}{b-a}} f\left( (b-a)\left(x + \frac{a}{b-a}\right) \right) dx$$
$$= (b-a) \int_0^1 f(a + (b-a)x)\,dx$$
$\implies$ Hence, proved.

**(b)**
$$\int_a^b f(Ax + B)\,dx = \frac{1}{A} \int_{Aa}^{Ab} f\left( A \frac{x}{A} + B \right)$$
$$= \frac{1}{A} \int_{Aa+B}^{Ab+B} f(x + B - B)\,dx$$
$$= \frac{1}{A} \int_{Aa+B}^{Ab+B} f(x)\,dx$$
$\implies$ Hence Proved.

> [!note] Notation for Evaluation
> Sometimes we write:
> $$\left. P(x) \right|_a^b \quad \text{to denote} \quad P(b) - P(a)$$
> where $P(x)$ is the polynomial that we get after integration of some other polynomial.

### Exercise 22
Find a quadratic polynomial $P$ for which:
$$P(0) = 1, \quad \int_0^1 P(x)\,dx = 2, \quad \text{and} \quad \int_0^1 x P(x)\,dx = \frac{1}{2}$$

#### Solution
Let $P(x) = c_2 x^2 + c_1 x + c_0$.

Given $P(0) = 1 \implies c_0 = 1$.

$$\int_0^1 P(x)\,dx = \left. \left( c_2 \frac{x^3}{3} + c_1 \frac{x^2}{2} + x \right) \right|_0^1$$
$$\implies \boxed{\frac{c_2}{3} + \frac{c_1}{2} + 1 = 2}$$

$\implies$ Similarly we are given that:
$$\int_0^1 x P(x)\,dx = \int_0^1 (c_2 x^3 + c_1 x^2 + x)\,dx$$
$$= \left. \left( \frac{c_2 x^4}{4} + \frac{c_1 x^3}{3} + \frac{x^2}{2} \right) \right|_0^1$$
$$\implies \frac{c_2}{4} + \frac{c_1}{3} + \frac{1}{2} = \frac{1}{2}$$
$$\implies \boxed{c_2 = -\frac{4}{3} c_1}$$

Substituting $c_2 = -\frac{4}{3} c_1$ into the first equation:
$$\implies \left(-\frac{4}{3}\right) c_1 \left(\frac{1}{3}\right) + \frac{c_1}{2} = 1$$
$$\implies \frac{-8 c_1 + 9 c_1}{18} = 1$$
$$\implies c_1 = 18$$
$$\implies c_2 = -\frac{4}{3}(18) = -24$$
$$\implies \boxed{P(x) = -24 x^2 + 18 x + 1}$$

### Exercise 23
Let $f$ be a function whose domain contains $-x$ whenever it contains $x$. We say that $f$ is an **even function** whenever $f(-x) = f(x)$, and $f$ is **odd** if $f(-x) = -f(x)$ for all $x$ in domain.

If $f$ is integrable on $[0, b]$, then prove that:
(a) $\int_{-b}^b f(x)\,dx = 2 \int_0^b f(x)\,dx$ if $f$ is even.
(b) $\int_{-b}^b f(x)\,dx = 0$, if $f$ is odd.

#### Solution

**(a) If $f$ is even:**
$$\int_{-b}^b f(x)\,dx = \int_{-b}^0 f(x)\,dx + \int_0^b f(x)\,dx$$
$$= -\int_b^0 f(-x)\,dx + \int_0^b f(x)\,dx$$
$$= \int_0^b f(x)\,dx + \int_0^b f(x)\,dx$$
$$= 2 \int_0^b f(x)\,dx$$

**(b) If $f$ is odd:**
We proceed in similar fashion, but we get:
$$\int_{-b}^b f(x)\,dx = \int_{-b}^0 f(-x)\,dx + \int_0^b f(x)\,dx$$
$$= -\int_0^b f(x)\,dx + \int_0^b f(x)\,dx$$
$$= 0$$

### Exercise 24
Use Theorems 1.18 and 1.19 to derive the formula:

#### Solution
