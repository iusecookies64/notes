# The Method of Exhaustion

$\to$ This was developed by Archimedes (300 BC.) to calculate the area under curve of arbitrary shapes.

$\to$ The method then remained as is for the next 1800 years until the advent of modern number system (Hindu-Arabic) and algebra.

$\to$ Archimedes realised that the area of any arbitrary shape can be found using dividing it into infinitesimally small rectangular strip that exhaust the whole area, the area for each strip can be calculated very easily and the area of whole will then be the sum of area's of these strips.

Eg. Consider graph of $y = x^2$

$\to$ The $x$ coordinates in a base of length $b$ divided into $n$ equal bases are given by

$$x = \frac{kb}{n}, \quad \text{where } k = 0, 1, \dots, n$$

$\to$ The heights of each rectangle in this case is,

$$y = \left(\frac{kb}{n}\right)^2, \quad \text{where } k = 0, 1, \dots, n-1$$

$\to$ Hence, total area of the strips is given by

$$s_n = \frac{b}{n} \left(\frac{b}{n}\right)^2 + \dots + \left(\frac{b}{n}\right) \left(\frac{(n-1)b}{n}\right)^2$$

$$s_n = \frac{b^3}{n^3} \left(1^2 + 2^2 + \dots + (n-1)^2\right)$$

#### Approximation from Above:
In this the rectangles give approximate area which is greater than actual area.

$\to$ The $x$ and $y$ coordinates will remain same, only the range will differ,

$$x = \frac{kb}{n}, \quad \text{where } k = 0, 1, \dots, n$$

$$y = \left(\frac{kb}{n}\right)^2, \quad \text{where } k = 1, \dots, n$$

$\to$ In this case the sum of areas of rectangle is given by

$$S_n = \left(\frac{b}{n}\right)\left(\frac{b}{n}\right)^2 + \dots + \left(\frac{b}{n}\right)\left(\frac{nb}{n}\right)^2$$

$$\Rightarrow S_n = \frac{b^3}{n^3} \left(1^2 + 2^2 + \dots + n^2\right)$$

$\to$ To move ahead we need to use the following result (we will prove this later).

$$1^2 + 2^2 + \dots + n^2 = \frac{n^3}{3} + \frac{n^2}{2} + \frac{n}{6}$$

$$\Rightarrow 1^2 + 2^2 + \dots + (n-1)^2 = \frac{n^3}{3} - \frac{n^2}{2} + \frac{n}{6}$$

$$\Rightarrow 1^2 + 2^2 + \dots + (n-1)^2 = \frac{n^3}{3} - \frac{n}{2}\left(n - \frac{1}{3}\right)$$

$\to$ Now, in our case $n \ge 1$, so we have

$$\frac{n^3}{3} - \frac{n}{2}\left(n - \frac{1}{3}\right) < \frac{n^3}{3}$$

$$\Rightarrow 1^2 + 2^2 + \dots + (n-1)^2 < \frac{n^3}{3}$$

$\to$ Similarly, for $S_n$ we can do the following:

$$1^2 + 2^2 + \dots + n^2 = \frac{n^3}{3} + \frac{n^2}{2} + \frac{n}{6}$$

$$\Rightarrow \frac{n^3}{3} < 1^2 + \dots + n^2$$

$$\Rightarrow 1^2 + 2^2 + \dots + (n-1)^2 < \frac{n^3}{3} < 1^2 + 2^2 + \dots + n^2$$

$\to$ Multiplying the above equation with $\frac{b^3}{n^3}$ we get

$$\Rightarrow s_n < \frac{b^3}{3} < S_n$$

$\to$ So for all values of $n$, the number $\frac{b^3}{3}$ lies b/w $s_n$ & $S_n$, but it may not be the only number.

$\to$ If we prove that $\frac{b^3}{3}$ is the only number between $s_n$ & $S_n$, for all possible $n$, then we can say that this is the area under the curve.

$\to$ Let $A$ be a number b/w $s_n$ & $S_n$, then there are 3 choices for the value of $A$ wrt $\frac{b^3}{3}$:

$$A > \frac{b^3}{3}, \quad A < \frac{b^3}{3}, \quad A = \frac{b^3}{3}$$

$\to$ We have seen that,

$$1^2 + 2^2 + \dots + (n-1)^2 < \frac{n^3}{3}$$

$$\Rightarrow 1^2 + 2^2 + \dots + n^2 < \frac{n^3}{3} + n^2$$

$\to$ Multiplying with $\frac{b^3}{n^3}$ we get,

$$S_n < \frac{b^3}{3} + \frac{b^3}{n}$$

$\to$ Similarly, we have $1^2 + \dots + n^2 > \frac{n^3}{3}$

$$\Rightarrow 1^2 + \dots + (n-1)^2 > \frac{n^3}{3} - n^2$$

$\to$ Multiplying with $\frac{b^3}{n^3}$, we get

$$\frac{b^3}{3} - \frac{b^3}{n} < s_n$$

$\to$ Hence, all $A$'s b/w $s_n$ & $S_n$ must satisfy

$$\frac{b^3}{3} - \frac{b^3}{n} < A < \frac{b^3}{3} + \frac{b^3}{n}$$

$\to$ Now, consider $A > \frac{b^3}{3}$, then we have

$$\Rightarrow A - \frac{b^3}{3} < \frac{b^3}{n}$$

since $A - \frac{b^3}{3} > 0$, we can divide the equation with $A - \frac{b^3}{3}$ & then multiply with $n (\ge 1)$ without changing the inequality, hence we have

$$n < \frac{b^3}{A - b^3/3}$$

$\to$ This means that any $A > \frac{b^3}{3}$ is only valid until the $n$ is according to it above.

$\to$ This means $A > \frac{b^3}{3}$ won't always exist.

$\to$ Similarly, if $A < \frac{b^3}{3}$, then we have

$$\frac{b^3}{3} - A < \frac{b^3}{n}$$

and LHS $> 0$, so we divide & multiply and get:

$$n < \frac{b^3}{b^3/3 - A}$$

$\to$ Hence, this case is also not valid always, hence we get, that $A = \frac{b^3}{3}$ is the only option which is always true.

$$\Rightarrow \text{Hence area of } x^2 \text{ under base } b \text{ is } \frac{b^3}{3}.$$

$\to$ In similar fashion we can find the area under any curve of type $ax^k + c$, we just need to use the following Inequality, (which we will prove later),

$$1^k + 2^k + \dots + (n-1)^k < \frac{n^{k+1}}{k+1} < 1^k + \dots + n^k$$

## 2. Basic Concepts of Set Theory

$\to$ Sets are denoted by capital letters $A, B, C, \dots, X, Y, Z$.

$\to$ The elements of the set are denoted by small case letters $a, b, c, \dots, x, y, z$.

$\to$ **Roster Notation**: In this a set is denoted by curly braces with it's el'e's inside it.
* Eg. $\{2, 4, 6, 8\} \Rightarrow$ set of all positive integers $< 10$.
* Eg. $\{2, 4, 6, \dots\} \Rightarrow$ set of all +ve integers, the "$\dots$" replaces the "and so on" phrase, but we must only use it when the meaning of "and so on" is clear.

$\to$ **Defn of Set**: It is a collection of objects seen as a single entity.

$\to$ It usually helps to imagine a set as a container and the items inside the container as it's elements.

$\to$ Another way to visualize set is as a region on paper with points inside it as elements.

$\to$ **Defn of Equality of Sets**:
Two sets are said to be equal or identical if they consist of exactly the same elements, in which case we write $A = B$.

$\to$ If one set contains an element that the other set doesn't have, then the sets are unequal and we write $A \ne B$.
* Eg. $\{2, 4, 6, 8\}$ and $\{2, 2, 4, 4, 6, 8\}$ are equal sets even though they are not of the same size.

$\to$ This examples means that we do not insist the elements of set to be distinct, also the order in which the are written in roster notation is also not important.
* Eg. $\{2, 4, 6, 8\} = \{2, 6, 8, 4\}$

$\to$ **Defn of Subsets**:
A set $A$ is a subset of another set $B$ when every element in $A$ is also present in $B$. It is denoted by,

$$A \subseteq B$$

$\to$ If $A \subseteq B$ & $B \subseteq A$, then we have $A = B$ and vice versa.

$\to$ If $A$ is subset of $B$ and $A \ne B$, then $A$ is called proper subset & denoted by $A \subset B$.

*Note: Symbolically we write the statement that an element $x$ belongs to a set $S$ by,*

$$x \in S$$

$\to$ If $x$ does not belong to $S$, then it is written as, $x \notin S$.

$\to$ **Sets Described by Defining Property**:
Some sets are composed of elements that all satisfy certain property, they are written (symbolically as) $\{x \mid x \text{ satisfies } P\}$, where $P$ is a condition.
* Eg. $\{x \mid x > 0\} \Rightarrow$ set of all +ve real numbers.

$\to$ *Note: $x$ is just an arbitrary symbol and we can choose any symbol & that doesn't change anything about the set.*

$$\Rightarrow \{x \mid x > 0\} = \{y \mid y > 0\} = \{t \mid t > 0\}$$

**Null Set**: A set that does not have any element is called a null set, it is denoted by $\phi$. Think of this like an empty container.

$\to$ A null set is subset of every set.

*Note: We must distinguish between the element $x$ & the set $\{x\}$ whose only element is $x$.*

$\to$ This is like a hat and a container having only that hat, conceptually they are not the same.

$\to$ Just like $\phi$ & $\{\phi\}$ are not the same, in fact the latter is a container having another empty container.

$\to$ **Class**: To simplify language, the collection of sets is called a Class. This is also a set, but its elements are also sets.

$\to$ **Properties of Set Operation**:

(i) **Commutative law**:

$$A \cup B = B \cup A$$

$$A \cap B = B \cap A$$

**Proof**: Let $x \in A \cup B$, then $x \in A$ (or) $x \in B$ (or) both. In either case we can say $x \in$ at least one of $A$ & $B$, hence $x \in B \cup A$ also.

$$\Rightarrow A \cup B \subseteq B \cup A$$

$\to$ Similarly, we can prove that $B \cup A \subseteq A \cup B$. This proves that $A \cup B = B \cup A$.

$\to$ Similarly, we can prove that

$$A \cap B = B \cap A.$$

*Note: The difference operation of sets is not commutative, in fact the only time $A - B = B - A$, when $A = B$ and the differences are null sets.*

$$\Rightarrow A - B = B - A = \phi.$$

(ii) **Associative law**:

$$A \cup (B \cup C) = (A \cup B) \cup C$$

$$(A \cap B) \cap C = A \cap (B \cap C)$$

**Proof**: Let $X = A \cup (B \cup C)$, $Y = (A \cup B) \cup C$.

$\to$ Let $x \in X$, then $x \in$ at least one of $A$ (or) $B \cup C$. If $x \in A$, then $x \in A \cup B \Rightarrow x \in Y$. If $x \in B \cup C$, then $x \in$ at least one of $B$ and $C$. If $x \in B$, then $x \in A \cup B \Rightarrow x \in Y$, if $x \in C \Rightarrow x \in Y$.

$\to$ Hence, if $x \in X$, then $x \in Y$ always $\Rightarrow X \subseteq Y$.

$\to$ Similarly, we can prove that $Y \subseteq X$, this gives us

$$A \cup (B \cup C) = (A \cup B) \cup C.$$

$\to$ Similarly, we can prove other one.

(iii) **Distributive Law**:

$$A \cup (B \cap C) = (A \cup B) \cap (A \cup C)$$

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C)$$

**Proof**: $X = A \cup (B \cap C)$, $Y = (A \cup B) \cap (A \cup C)$.

$\to$ Let $x \in X$, then $x \in$ at least one of $A$ and $B \cap C$.

$\to$ If $x \in A$, then $x \in A \cup B$ & $x \in A \cup C$, hence $x \in Y$.

$\to$ If $x \in B \cap C$, then $x \in B$ & $x \in C$, hence $x \in A \cup B$ & $x \in A \cup C, \Rightarrow x \in Y$.

$\to$ Hence, for all $x \in X$, $x \in Y$.

$\to$ Similarly, we can prove that

$$A \cap (B \cup C) = (A \cap B) \cup (A \cap C).$$

### de-Moivre's Inclusion - Exclusion Principle

> [!WARNING] Flagged Note Inaccuracy: Attribution of Principle
> The notes title this as "de-Moivre's Inclusion - Exclusion Principle". While Abraham de Moivre used related summation techniques in probability, the general combinatorial Principle of Inclusion-Exclusion (PIE) is historically attributed to Daniel da Silva / J. J. Sylvester.

$\to$ This is the general case of the result

$$|A \cup B| = |A| + |B| - |A \cap B|$$

$\to$ Consider sets (finite) $A_1, A_2, \dots, A_n$, then the count of elements in $\bigcup_{k=1}^n A_k$ is given by,

$$\left|\bigcup_{k=1}^n A_k\right| = \sum_{j=1}^n (-1)^{j+1} \sum_{1 \le i_1 < \dots < i_j \le n} \left|A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_j}\right|$$

$\to$ Expanded the above formula looks like,

$$\left|\bigcup A_k\right| = \sum |A_k| - \sum |A_{i_1} \cap A_{i_2}| + \dots + (-1)^{n-1} |A_1 \cap A_2 \cap \dots \cap A_n|$$

*Note: The number of terms in the expression $\sum_{1 \le i_1 < \dots \le i_j \le n} |A_{i_1} \cap A_{i_2} \cap \dots \cap A_{i_j}|$ are $\binom{n}{j}$.*

**Example**: Number of ways to arrange $n$ envelops (addressed) & $n$ letters such that at least 1 of the letter is in the right envelop.

**sol**: Let $A_i$ be the number of ways such that $i$th letter is in the correct envelop, so we need to find the count of $|A_1 \cup A_2 \dots \cup A_n|$.

$\to$ Using principle of inclusion-exclusion we have,

$$\left|\bigcup A_i\right| = \sum |A_i| - \sum |A_{i_1} \cap A_{i_2}| + \dots + (-1)^{n-1} |A_1 \cap A_2 \dots \cap A_n|$$

$\to$ Here, the value of $|A_{i_1} \cap \dots \cap A_{i_j}|$ is $(n-j)!$ for every possible choice.

$$\Rightarrow \sum |A_{i_1} \cap A_{i_2} \dots A_{i_j}| = \binom{n}{j} \cdot (n-j)! = \frac{n!}{j!}$$

$$\Rightarrow \left|\bigcup_{i=1}^n A_i\right| = n! \sum_{j=1}^n \frac{(-1)^{j+1}}{j!}$$

**Example**: Number of surjective functions from a set of size $n$ to a set of size $m$ ($m \le n$).

**sol**: In this case calculating the counter case is easier and then we subtract it from total cases.

$\to$ Let $A_i$ be the number of func's $f: A \to B$ such that the $j$th element is not mapped, here,

$$A = \{1, 2, \dots, n\} \quad \& \quad B = \{1, 2, \dots, m\}$$

$$= m^n - \sum_{j=1}^m (-1)^{j+1} \binom{m}{j} (m-j)^n$$

## PART-3: Axioms For The Real Number System

$\to$ There are many ways to introduce the real number system.

$\to$ A constructive approach uses the positive integers $(1, 2, \dots)$ as undefined object and then defines 5 basic axioms for these. Then adding 0, -ve integers using these axioms to define the set of Integers.

$\to$ Then we use integers to define rational numbers (construct them).

$\to$ And finally use integers and rationals to construct Irrational numbers.

$\to$ Combining rationals and irrationals give us the real number system.

$\to$ All properties of real numbers must be proved from the basic axioms we defined initially.

$\to$ But here, we will use a non-constructive approach, we will start with the real numbers as undefined objects all present in a set $\mathbb{R}$.

$\to$ Then we define 10 axioms about real numbers which help us prove the remaining properties about them.

$\to$ These 10 axioms are divided into 3 categories namely Field Axioms, Order Axioms, and the Least-Upper-Bound Axiom (also called Axiom of Continuity (or) The Completeness axiom).

### 3.2 The Field Axioms

$\to$ Along with the existence of $\mathbb{R}$, we also assume the existence of two operations on the elements of $\mathbb{R}$,
(i) Addition, $x+y$
(ii) Multiplication, $xy$

$\to$ It is also assumed that the sum of $x$ & $y$ & product of $x$ & $y$ is uniquely determined by $x+y$ & $xy$.

**Axiom 1: Commutative Laws**
$$x + y = y + x \quad \& \quad xy = yx$$

**Axiom 2: Associative Laws**
$$x + (y + z) = (x + y) + z \quad \& \quad x(yz) = (xy)z$$

**Axiom 3: Distributive Laws**
$$x(y + z) = xy + xz$$

**Axiom 4: Existence of Identity elements**
$\to$ There exist two distinct real numbers, which we denote by $1$ & $0$, such that, for every real $x$ we have

$$x + 0 = x \quad \& \quad 1 \cdot x = x$$

**Axiom 5: Existence of Negatives**
$\to$ For every real number $x$, there exists another real number $y$, such that

$$x + y = 0$$

**Axiom 6: Existence of Reciprocals**
$\to$ For every real number $x \ne 0$ there is a real number $y$ such that

$$xy = 1$$

$\to$ Now from the above axioms we will prove different laws of algebra, as theorems.

#### Theorem 1.1: Cancellation law for Addition
If $a + b = a + c$, then $b = c$.

**Proof**: From axiom 5 there is a number $y$ such that

$$a + y = y + a = 0$$

$$\Rightarrow y + (a + b) = (y + a) + b = 0 + b = b$$

$$\Rightarrow y + (a + c) = (y + a) + c = 0 + c = c$$

But, given $a + b = a + c$

$$\Rightarrow y + (a + b) = y + (a + c)$$

$$\Rightarrow b = c$$

*Note: From this theorem we also learn that 0 is unique, because if we have $0$ & $0'$, then, by defn*

$$a + 0 = a + 0' = a$$

$\to$ Using the cancellation law, we have

$$0 = 0'$$

#### Theorem 1.2: Possibility of Subtraction
**St**: Given $a$ & $b$, there exists exactly one $x$, such that

$$a + x = b$$

$\to$ This $x$ is denoted by $b - a$, $0 - a$ is particularly written as $-a$ & is called the negative of $a$.

**Proof**: We know there always exists $y$, such that $a + y = 0$, then $x = y + b$ is such that

$$a + x = a + (y + b) = b$$

$\to$ Hence, $x$ always exists, from theorem 1.1 we see that it is unique

$$\Rightarrow a + x_1 = a + x_2 = b \Rightarrow x_1 = x_2$$

#### Theorem 1.3:
$$b - a = b + (-a)$$

**Proof**:
$$a + (b - a) = b \quad (\text{Th } 1.2)$$

$$a + (b + (-a)) = a + ((-a) + b) \quad (\text{Ax } 1)$$

$$\Rightarrow (a + (-a)) + b = 0 + b = b \quad (\text{Ax } 2 \ \& \ \text{Ax } 4)$$

$$\Rightarrow a + (b - a) = a + (b + (-a))$$

$$\Rightarrow b - a = b + (-a) \quad (\text{Th } 1.1)$$

#### Theorem 1.4:
$$-(-a) = a$$

**Proof**:
$$(-a) + (-(-a)) = 0 \quad (\text{Th } 1.2)$$

$$(-a) + a = 0 \quad (\text{Th } 1.2)$$

$$\Rightarrow a = -(-a)$$

#### Theorem 1.5:
$$a(b - c) = ab - ac$$

**Proof**:
$$a(b - c) = a(b + (-c)) \quad (\text{Th } 1.3)$$

$$= ab + a(-c) \quad (\text{Ax } 3)$$

Now consider, $ac + ab - ac = ac - ac + ab$

$\Rightarrow ac + a(b - c) = ab$

### 3.4 The Order Axioms

$\to$ These axioms help us establish ordering among the real numbers.

$\to$ We assume that there exists a certain subset $\mathbb{R}^+ \subset \mathbb{R}$, called the set of positive numbers, which satisfy the following axioms,

**Axiom 7:** If $x$ and $y \in \mathbb{R}^+$, then $x + y$ and $xy$ also $\in \mathbb{R}^+$.

**Axiom 8:** For every real $x \ne 0$, either $x \in \mathbb{R}^+$ or $-x \in \mathbb{R}^+$, but not both.

**Axiom 9:** Here we define the meaning of the symbols $<, >, \le$, and $\ge$.
* $x < y$ means that $y - x$ is +ve;
* $y > x$ means that $x < y$;
* $x \le y$ means that either $x < y$ or $x = y$;
* $y \ge x$ means that $x \le y$;

$\to$ Thus we have $x > 0$ if $x - 0 = x$ is +ve.

$\to$ If $x < 0$ then we say that $x$ is negative.

$\to$ If $x \ge 0$, then we say that $x$ is non-(-ve).

$\to$ A pair of simultaneous inequalities $x < y$ & $y < z$ can be written as $x < y < z$; similar interpretations are given to each of the following compound inequalities

$$\Rightarrow x \le y < z, \quad x < y \le z, \quad x \le y \le z, \text{ etc.}$$

$\to$ Again we provide the usual rules for calculations in inequalities as theorems.

#### Theorem 1.16: Trichotomy Law
**St**: For arbitrary real numbers $a$ & $b$, exactly one of the three relations $a < b, a > b$ (or) $a = b$ holds.

**Proof**: Consider the number $b - a$, if $b - a = 0$, then we have $a = b$.

$\to$ But if $b - a \ne 0$, then by axiom 8 we have either $b - a \in \mathbb{R}^+$ (or) $-(b - a) \in \mathbb{R}^+$, but not both.

$\to$ If $b - a \in \mathbb{R}^+$, then $b - a > 0 \Rightarrow a < b$.

$\to$ If $-(b - a) \in \mathbb{R}^+$, then $-(b - a) > 0 \Rightarrow a - b > 0 \Rightarrow b < a$.

$\to$ Hence, only one of these is always true

$$a = b \text{ (or) } a < b \text{ (or) } b < a.$$

#### Theorem 1.17: Transitive Law
**St**: If $a < b$ and $b < c$, then $a < c$.

**Proof**: Since $a < b \Rightarrow b - a > 0$, and since $b < c \Rightarrow c - b > 0$, now we have $(b - a)$ & $(c - b)$ both positive, then by Axiom 7 we have:

$$\Rightarrow (b - a) + (c - b) \text{ also } \in \mathbb{R}^+$$

## Concept of Lower Bound & Upper Bound

$\to$ **Upper Bound**: Let $S$ be a set of real numbers, let $B$ be a real number such that,

$$x \le B \quad \forall\ x \in S$$

$\to$ Then the set $S$ is said to be bounded from above and the number $B$ is called an Upper Bound for $S$.

$\to$ If $B$ is upper bound, then all numbers greater than $B$ are also upper bounds.

$\to$ If the upper bound $B$ is also a member of the set, then $B$ is called the largest member (or) the maximum element.

$$\Rightarrow B = \max S$$

*Note: It is possible that a set $S$ has no Upper Bound, they are said to be unbounded above.*

**Examples**:
(a) The set of all real numbers i.e $\mathbb{R}$ is an unbounded set.
(b) Set of all real numbers satisfying the condition $0 \le x < 1$. It has an upper bound of 1, but there is no largest member / max $S$.

*Note: The sets that don't have maximum element, for them we have a concept of least-upper-bound (not only for them).*

$\to$ **Definition of Least Upper Bound**:
A number $B$ is called the least upper bound of a set $S$ if $B$ has the following properties:
(a) $B$ is an upper bound of $S$,
(b) No number $< B$ is an upper bound of $S$.

*Note 1: If the set $S$ has a maximum element, then the maximum element is the least upper bound of $S$.*

*Note 2: If $S$ does not have a maximum element, then still it can have an upper bound, for example we have seen the set of real numbers, such that $0 \le x < 1$.*

## THE LEAST-UPPER-BOUND AXIOM (or) THE COMPLETENESS AXIOM

$\to$ This is the axiom 10, it helps us define Irrational Numbers.

**Axiom 10:**
Every non-empty set $S$ of real number that is bounded above has a supremum. That is there is a real number $B$, such that

$$B = \sup S$$

$\to$ Supremum is another name / word for least-upper-bound.

#### Theorem 1.26: Uniqueness of Supremum

**St**: The least upper bound (or) supremum is unique, i.e there cannot be 2 numbers that are both supremum.

**Proof**: Let, there be two supremum's $A$ & $B$, then $A$ & $B$ are also upper bound for the set $S$.

$\to A$ is a supremum & $B$ is an upper bound, then we have $A \le B$.

$\to$ Similarly, $B$ is supremum also and $A$ is upper bound, then we have that $B \le A$.

$$\Rightarrow A = B$$

$\to$ Hence the supremum is unique.

*Note: The concepts that we have defined for upper bound, max element, supremum can also be applied & developed for lower bound, minimum element, infimum.*

**Lower Bound**: A real number $L$ such that it is $\le$ every element of the set $S$.

$$\Rightarrow L \le x \quad \forall x \in S$$

**Minimum Element**: It is the smallest element of the set ie smallest member of the set,

$$\min S \le x \quad \forall x \in S$$

**Infimum**: It is the greatest-lower-bound of a set that is bounded below.

$\to$ If set has a min element then the infimum is the min element.

$$\Rightarrow \inf S = \min S$$

$\to$ Similarly, if a max element exists then we have

$$\sup S = \max S$$

#### Theorem 1.27

**St**: For every set of real number that is bounded below, there always exists a infimum, i.e a real number that is infimum.

**Proof**: This is really an extension for Axiom 10 for infimum.

$$\Rightarrow -L \ge -x \quad \forall -x \in -S$$

$\to$ Hence, $-\sup(-S)$ will be the infimum of the set $S$.

$$\Rightarrow \inf S = -\sup(-S)$$

$\to$ Hence, infimum always exists for set that is bounded below.

### Fundamental Properties of Supremum and Infimum

$\to$ Below we will discuss three properties relating to supremum and of infimum.

#### Theorem 1.32

Let $h$ be a given positive real number and $S$ be a set of real numbers.

(a) If $S$ has a supremum, then for some $x$ in $S$ we have

$$x > \sup S - h$$

(b) If $S$ has a infimum, then for some $x$ in $S$ we have

$$x < \inf S + h$$

**Proof**:

(a) If no such $x$ exists then $\sup S - h$ is an upper bound smaller than least-upper-bound which is not possible.

(b) Can be prooved similarly to (a).

*Note: This property simply says that we can get arbitrarily close to the supremum (or) infimum.*

$\to$ If $S$ has max/min element then this property is not very useful because we can choose $x$ to be $\max/\min S$ everytime which is the closest possible to $\sup/\inf S$ (in fact they are the same).

$\to$ But when $S$ does not have any max/min, then this means that $S$ contains elements that can get as close as we want to $\sup/\inf S$.

#### Theorem 1.33: Additive Property

**St**: Given non empty subsets $A$ & $B$ of $\mathbb{R}$, let $C$ denote the set

$$C = \{a + b \mid a \in A \text{ and } b \in B\}$$

(a) If each of $A$ & $B$ have a supremum then $C$ also has a supremum and

$$\sup C = \sup A + \sup B$$

(b) If each of $A$ & $B$ both have an infimum then $C$ has an infimum and

$$\inf C = \inf A + \inf B$$

**Proof**: We know that $\sup A \ge a$ & $\sup B \ge b$

$$\Rightarrow a + b \le \sup A + \sup B, \quad \text{hence this is an upper bound.}$$

$$\Rightarrow \sup C \le \sup A + \sup B$$

$\to$ From theorem 1.32 we have the following inequalities to always be true:

$$\Rightarrow a > \sup A - \frac{1}{n} \quad \& \quad b > \sup B - \frac{1}{n}, \quad \forall n \in P$$

$$\Rightarrow a + b > \sup A + \sup B - \frac{2}{n}$$

$$\Rightarrow \sup A + \sup B < a + b + \frac{2}{n}$$

$\to$ But we know that $a + b \le \sup C \Rightarrow a + b + \frac{2}{n} \le \sup C + \frac{2}{n}$

$$\Rightarrow \sup C \le \sup A + \sup B < \sup C + \frac{2}{n}$$

for all positive Integers, then by theorem 1.31 we have:

$$\sup C = \sup A + \sup B$$

$\to$ Similarly, we can proove (b).

#### Theorem 1.34

**St**: Given two non empty sets $S$ & $T$ ($\subseteq \mathbb{R}$) such that

$$s \le t \quad \forall s \in S \text{ \& } t \in T$$

Then $S$ has a supremum & $T$ has an infimum, and they satisfy the inequality

$$\sup S \le \inf T$$

**Proof**: Every element of $T$ is an upper bound to $S$, then $S$ has a supremum by axiom 10.

$\to$ Supremum is less than (or) equal to every upper bound hence we have

$$\sup S \le t \quad \forall t \in T$$

$\to$ The set $T$ has a lower bound & hence will have an infimum by def [theorem 1.27].

$\to$ & Infimum is greater than (or) equal to every lower bound.

$$\Rightarrow \sup S \le \inf T$$

### 3.13 Existence of Square Roots of Non-Negative Real Numbers

$\to$ Square root of a number (real) $x$ which is $\ge 0$ always exists and is denoted by $x^{1/2}$ (or) $\sqrt{x}$ is such that:

$$\Rightarrow x^2 = y^2 \Rightarrow x^2 - y^2 = 0$$

$$\Rightarrow (x - y)(x + y) = 0$$

$$\Rightarrow \text{either } x = y \text{ or } x = -y$$

$\to$ Here the number $y$ is denoted by $x^{1/n}$ or $\sqrt[n]{x}$.

**Case 2: $n$ is even integer**

$\to$ In this case the $n$th root only exists for all $x \ge 0$.

$\to$ Again using principle of least-upper-bound we can proove that if $x \ge 0$ then there always exists a unique positive real number $y$ such that $y^n = x$.

$\to$ In this case $y$ is denoted by $x^{1/n}$ (or) $\sqrt[n]{x}$.

$\to$ The difference in case of $n$ being even is that $(-y)^n = y^n$, hence $-y$ is also $n$th root of $x$ and it is denoted by $-x^{1/n}$ or $-\sqrt[n]{x}$.

**Laws of Exponents**: If $r$ is a rational number given by $\frac{m}{n}$, then $x^r$ is defined as $(x^m)^{1/n}$ i.e $n$th root of $x^m$, whenever it exists.

$\to$ Now we will proove the usual laws about exponents, first we will proove them for the fact when exponent is integer.

$$\Rightarrow \underbrace{x \cdot x \cdots x}_{n \text{ times}} = x^n$$

$$\Rightarrow \frac{1}{\underbrace{x \cdot x \cdots x}_{n \text{ times}}} = x^{-n} \text{ (or) } \frac{1}{x^n}$$

(i) $x^n \cdot x^m = x^{n+m}$

**Sol**:

$$x^n \cdot x^m = \underbrace{(x \cdots x)}_{n} \cdot \underbrace{(x \cdots x)}_{m} = \underbrace{(x \cdots x)}_{n+m} = x^{n+m}$$

$$\Rightarrow x^n \cdot x^m = x^{n+m}$$

(ii) $(x^n)^m = x^{nm}$

**Sol**:

$$(x^n)^m = \underbrace{x^n \cdots x^n}_{m \text{ times}} = \underbrace{\underbrace{(x \cdots x)}_{n \text{ times}} \cdot (x \cdots x) \cdots (x \cdots x)}_{m \text{ times}} = \underbrace{(x \cdots x)}_{nm} = x^{nm}$$

$$\Rightarrow (x^n)^m = x^{nm}$$

(iii) $(xy)^n = x^n y^n$

**Sol**:

$$(xy)^n = \underbrace{(xy) \cdots (xy)}_{n} = \underbrace{(x \cdots x)}_{n} \cdot \underbrace{(y \cdots y)}_{n} = x^n y^n$$

$$\Rightarrow (xy)^n = x^n y^n$$

$\to$ Now we will prove the same laws for rational numbers.

(iv) $x^r \cdot x^s = x^{r+s}$

**Sol**: Let $r = \frac{m}{n}$ & $s = \frac{p}{q}$, $y^n = x^m$ & $z^q = x^p$

$$\Rightarrow (y^n)^q = (x^m)^q \Rightarrow y^{nq} = x^{mq}$$

$$\Rightarrow (z^q)^n = (x^p)^n \Rightarrow z^{nq} = x^{np}$$

$$\Rightarrow y^{nq} z^{nq} = x^{mq} \cdot x^{np}$$

$$\Rightarrow (yz)^{nq} = x^{mq + np}$$

$$\Rightarrow yz = (x^{mq + np})^{1/nq}$$

$$\Rightarrow x^{m/n} x^{p/q} = x^{\frac{mq + np}{nq}}$$

$$\Rightarrow x^r \cdot x^s = x^{r+s}$$

(v) $(x^r)^s = x^{rs}$

**Sol**: Again let $r = \frac{m}{n}$ & $s = \frac{p}{q}$

$$\Rightarrow y = x^r \Rightarrow y^n = x^m$$

$$\text{Also, } y^s = z \text{ (say)}$$

$$\Rightarrow y^p = z^q \Rightarrow y^{np} = z^{nq}$$

$$\Rightarrow x^{mp} = z^{nq} \Rightarrow z = (x^{mp})^{1/nq}$$

$$\Rightarrow z = x^{\frac{mp}{nq}} \Rightarrow (x^r)^s = x^{rs}$$

(vi) $(xy)^r = x^r y^r$

**Sol**: $r = \frac{m}{n} \Rightarrow (xy)^r = z$

$$\Rightarrow ((xy)^m)^{1/n} = (x^m \cdot y^m)^{1/n} = z$$

$$\Rightarrow z^n = x^m y^m$$

$$\text{Now, let } a^n = x^m \Rightarrow a = x^r$$

$$\text{also, let } b^n = y^m \Rightarrow b = y^r$$

$$\Rightarrow z^n = x^m y^m = a^n \cdot b^n$$

$$\Rightarrow z^n = (a \cdot b)^n \Rightarrow z = ab$$

$$\Rightarrow (xy)^r = x^r y^r$$

*Note: In the above it is assumed that $x^r$ and y^r both exist which might not always be the case.*

### (3.15) Representation of Real Numbers by Decimals

A real number of the form

$$a_0 + \frac{a_1}{10} + \frac{a_2}{10^2} + \dots + \frac{a_n}{10^n}, \quad \text{where}$$

$a_0$ is a non-negative integer and all other $a_i$ satisfy the condition $0 \le a_i \le 9$ is usually written as

$$a_0.a_1 a_2 \dots a_n$$

Eg. $1 + \frac{5}{10} = 1.5, \quad \frac{1}{50} = \frac{2}{10^2} = 0.02$.

$\to$ Such real numbers are always rational and can be written in the form of $\frac{a}{10^n}$, where $a \in \mathbb{Z}^+$.

Eg. $1.5 = \frac{15}{10}, \quad 0.02 = \frac{2}{100}$

*Note: Not every rational number can be written in this form, for example the number $\frac{1}{3} \ne \frac{a}{10^n}$.*

Because if $\frac{1}{3} = \frac{a}{10^n} \Rightarrow 3a = 10^n$ which tells us that $10^n$ is a multiple of 3 which is not true, no number in the form of $10^n$ is a multiple of 3.

$\to$ What to do in the case of $\frac{1}{3}$?

$\to$ In this case we can have a decimal approx. of the number $\frac{1}{3}$ to any degree of accuracy that we need.

$\to$ The process to approximate any arbitrary real number $x > 0$ is as follows.

(i) Since $x$ may not be an integer then we can find integers $a_0$ such that

$$a_0 \le x < a_0 + 1$$

$\to$ Then divide segment b/w $a_0$ & $a_0 + 1$ into 10 equal parts. Then each part here will be,

$$a_0 + \frac{0}{10} = a_0, \quad a_0 + \frac{1}{10}, \quad a_0 + \frac{2}{10}, \quad \dots, \quad a_0 + \frac{8}{10}, \quad a_0 + \frac{9}{10}, \quad a_0 + \frac{10}{10} = a_0 + 1$$

$\to$ Let $a_1$ now be the largest integer such that

$$a_0 + \frac{a_1}{10} \le x < a_0 + \frac{a_1 + 1}{10}$$

$\to$ Note that $a_1 < 10$, hence satisfying the condition for decimal i.e $0 \le a_1 \le 9$.

$\to$ Now, we further divide the segment b/w $a_0 + \frac{a_1}{10}$ & $a_0 + \frac{a_1 + 1}{10}$, each division point here will be of the form

$$a_0 + \frac{a_1}{10} + \frac{a_2}{100}, \quad \text{where } 0 \le a_2 \le 10$$

> [!WARNING] Flagged Note Inaccuracy: Decimal Digit Range
> The note writes $0 \le a_2 \le 10$; as a base-10 digit, the upper bound is $a_2 \le 9$.

$\to$ Again we can find an integer $a_2$ such that it is largest satisfying

$$a_0 + \frac{a_1}{10} + \frac{a_2}{10^2} \le x < a_0 + \frac{a_1}{10} + \frac{a_2 + 1}{10^2}$$

$\to$ If after some number of steps the number $x$ coincides with a sub division point then we will have,

$$x = a_0 + \frac{a_1}{10} + \dots + \frac{a_n}{10^n}$$

$\to$ But, if $x$ never coincides with any of the subdivision points then the process continuous indefinitely and it generates an infinite decimal expansion of $x$.

$$x = a_0.a_1 a_2 a_3 \dots$$

*Note: At $n$th stage in the above process, we have $x$ satisfying the inequality*

$$a_0 + \frac{a_1}{10} + \dots + \frac{a_n}{10^n} < x < a_0 + \frac{a_1}{10} + \dots + \frac{a_n + 1}{10}$$

> [!WARNING] Flagged Note Inaccuracy: Denominator Exponent Typo
> In the upper bound of the inequality, the denominator of the last term is written as $10$ instead of $10^n$, i.e. it should be $\frac{a_n + 1}{10^n}$.

$\to$ Here we get two approximations of $x$ one from below and other from above, the difference b/w these approximations is $10^{-n}$.

Eg. For $x = \frac{1}{3}$ the decimal expansion is

$$x = \frac{1}{3} = 0.3333\dots$$

**What about Irrational Numbers?**

$\to$ The decimal expansion of real numbers is also infinite otherwise we can prove it to be rational.

Eg. We can approximate the decimal expansion of $\sqrt{2}$ by trial and error.

$$\to (1.4)^2 < 2 < (1.5)^2 \Rightarrow 1.4 < \sqrt{2} < 1.5$$

$$\to 1.41 < \sqrt{2} < 1.42 \Rightarrow 1.414 < \sqrt{2} < 1.415$$

### Sequence of Nested Intervals

$\to$ When finding the decimal expansion of real numbers at each step we have an interval, the sizes of these intervals are $10^0, 10^{-1}, 10^{-2}, \dots$

$\to$ Each of the interval is contained inside the preceeding and each contain $x$. Such intervals are called sequence of nested intervals.

$\to$ This concept is sometimes used as a basis for contructing irrational numbers from rational numbers.

### Analytical Defn of Decimal Expansion

If $x$ is a given positive Real number, let $a_0$ denote the largest integer $\le x$. Having chosen $a_0$, we let $a_1$ denote the largest integer such that,

$$a_0 + \frac{a_1}{10} \le x$$

More generally, having chosen the integers $a_0, a_1, \dots, a_{n-1}$, let $a_n$ denote the largest integer such that

$$a_0 + \frac{a_1}{10} + \frac{a_2}{10^2} + \dots + \frac{a_n}{10^n} \le x$$

$\to$ Let $S$ denote the set of all numbers

$$a_0 + \frac{a_1}{10} + \dots + \frac{a_n}{10^n}, \quad \text{obtained in this way for } n = 0, 1, 2, \dots$$

Then $S$ is non-empty and bounded from above, hence it will have least-upper-bound.

$\to$ The supremum of $S$ is $x$.

**Proof**: $x$ is an upper bound, then we have $\sup S \le x$.

$\to$ We need to prove that $\sup S < x$ is not possible.

$\to$ Let $\sup S < x \Rightarrow \exists z \in \mathbb{R}$ & $z$ being rational, such that

$$\sup S < z < x$$

$\to$ Now, we can find a decimal expansion of $z$ such that since it is a rational number.

$$\Rightarrow b_0 + \frac{b_1}{10} + \dots + \frac{b_k}{10^k} = z$$

Now, $a_0$ is the largest integer such that $a_0 \le x$, also $a_0 \le \sup S$

$$\Rightarrow b_0 = a_0, \quad \text{otherwise } b_0 \text{ will be the largest integer } \le x, \ (\because b_0 \ge a_0).$$

$\Rightarrow$ Similarly, we can proove that all other $a_i = b_i$ and hence we get that

$$z \in S \Rightarrow z \le \sup S$$

$\Rightarrow$ This is a contradiction to the fact that $\sup S < z < x$.

$\Rightarrow$ Hence, $\sup S = x$ is the only option.

$\to$ The integers $a_0, a_1, a_2, \dots$ so obtained may be used to define the decimal expansion of $x$.

$\to$ From the definition we see that $a_1$ is the largest integer such that

$$a_0 + \frac{a_1}{10} \le x$$

$\to$ We can see that $0 \le a_1 \le 9$, otherwise if $a_1 = 10$ (say), then we have

$$a_0 + \frac{10}{10} \le x \Rightarrow a_0 + 1 \le x$$

$\Rightarrow$ This is contradiction to the fact that $a_0$ is the largest integer $\le x$.

$\to$ Similarly, we can prove that all other $a_i$ are also $0 \le a_i \le 9$.

$\to$ Hence, $a_0.a_1 a_2 \dots$ thus is the decimal expansion of $x$.

Eg. If $x = \frac{1}{8}$, we find $a_0 = 0, a_1 = 1, a_2 = 2, a_3 = 5$ and $a_n = 0$, for all $n \ge 4$.

$$\Rightarrow \frac{1}{8} = 0.12500\dots$$

*Note: If we define the set $S$ using the inequality for a given $n$ as*

$$a_0 + \frac{a_1}{10} + \dots + \frac{a_n}{10^n} < x$$

Then the decimal expansion that we get may be different. For example the decimal expansion in this case for $\frac{1}{8}$ will be

$$\frac{1}{8} = 0.124999\dots$$

$\to$ Both the sets thus defined give a decimal expansion for $\frac{1}{8}$ and $\frac{1}{8}$ is the supremum of both of these sets.

### (4.2) Principle of Mathematical Induction

Let $A(n)$ be an assertion involving an integer $n$. We conclude that $A(n)$ is true for all $n \ge n_1$ if we can perform the following 2 steps:

(i) Prove that $A(n_1)$ is true

(ii) Let $k$ be any arbitrary but fixed integer $\ge n_1$. Assume that $A(k)$ is true and prove that $A(k+1)$ is also true.

*Note: In actual practice $n_1$ is usually chosen to be 1.*

#### Theorem 1.36

Let $S$ be a set of positive integers which has the following property (2):

(i) The number 1 is in the set $S$.

(ii) If an integer $k$ is in the set, then so is $k + 1$.

Then every positive integer is in the set $S$.

**Proof**: The proof is actually really simple, properties (a) and (b) tell us that $S$ is an inductive set.

$\to$ Now, the positive integers are defined to be numbers that are present in every inductive set.

$\to$ Hence we can say that $S$ contains all of the positive integers.

*Note: This basically proves that if we proved the assertion for $n = 1$ and then for $A(k+1)$ given $A(k)$ for some $k \ge 1$, then the assertion is true for all positive integers.*

### (4.3) The Well-Ordering Principle

#### Theorem 1.37

Every non-empty set of positive integers contains a smallest member.

**Proof**: Let $T$ be a non empty set of positive integers, we need to prove that $T$ always has a smallest element.

$\to$ Let $T$ not have a smallest element then this means that 1 is not in $T$ as if 1 is in $T$ then it would be the smallest member.

$\to$ Let $S$ be set of all positive integers $n$ such that $n < t \quad \forall t \in T$.

$\to$ Clearly, $1 \in S$, hence $S$ is not empty. Now let $k$ be some number in $S$ then we know that

$$k \in S \Rightarrow k < t \quad \forall t \in T$$

$\to$ We will prove that $k + 1$ also $\in S$.

If $k + 1 \notin S$, then $\exists t_1 \in T$ such that $t_1 \le k + 1$.

$\to$ Since $T$ has no smallest element $\exists t_2 \in T$ st $t_2 < t_1$.

$$\Rightarrow t_2 < k + 1$$

$$\Rightarrow t_2 \le k$$

$\to$ This is a contradiction to the fact that $k < t \quad \forall t \in T$.

$\to$ Hence, $k + 1 \in S$, this makes $S$ an inductive set, hence it contains all positive integers. Since $T$ is nonempty it contains some $t$ & that $t$ is also present in $S$ leading to contradiction that $t < t$.

$\to$ Therefore, the assumption that there is no smallest element in $T$ is false.

*Note: Why is it called Well Order-ing?*

$\to$ Well ordering comes from two words, well and ordering.

(i) The integers are all well ordered as we can always put two integers in $<$ or $>$ relation, they are never same or uncomparable.

(ii) Well ordered means that they give a starting point ie any set always has a smallest which can be used as a starting point.

*Note: What about Real Numbers?*

$\to$ We have seen already that real numbers are also ordered as we can always compare them and the trichotomy law states that at least one $a < b$, $a > b$ or $a = b$ must be true.

$\to$ But in a set of real numbers we may not always have a starting point which we have proved using supremum & infimum, that we can get as close as we want to supremum/infimum.

Eg. $S = \{s \mid s \in \mathbb{R} \text{ \& } 1 < s\}$

$\to$ The above set has no starting point.

### Proof Using Induction and Well Ordering Principle

$\to$ We can prove the same assertion $A(n)$ using 2 ways, one is using mathematical induction and other using well ordering principle (which comes from induction).

Prove that the following assertion is true for all values of $n$ i.e $\mathbb{Z}^+$:

$$A(n) = \sum_{i=1}^n i^2 = \frac{n^3}{3} + \frac{n^2}{2} + \frac{n}{6}$$

**Method 1**:

The assertion is true for $A(1)$ and we can easily verify that:

$$1^2 = 1 \stackrel{?}{=} \frac{1^3}{3} + \frac{1^2}{2} + \frac{1}{6}$$

Let $A(k)$ be true for some $k \ge 1$, then we have $A(k+1)$ as

$$A(k+1) = A(k) + (k+1)^2$$

$$= \frac{k^3}{3} + \frac{k^2}{2} + \frac{k}{6} + (k+1)^2$$

$$= \frac{k^3}{3} + \frac{k^2}{2} + \frac{k}{6} + k^2 + 2k + 1$$

$$= \frac{2k^3 + 3k^2 + k + 6k^2 + 12k + 6}{6}$$

$$= \frac{2(k^3 + 3k^2 + 3k + 1) + 3(k^2 + 2k + 1) + (k+1)}{6}$$

$$\Rightarrow A(k+1) = \frac{(k+1)^3}{3} + \frac{(k+1)^2}{2} + \frac{k+1}{6}$$

$\Rightarrow$ Hence, the assertion is true for all $n \in \mathbb{Z}^+$.

**Method 2**:

$\Rightarrow$ The assertion is clearly true for $A(1)$.

$\Rightarrow$ Now, we are left with two possibilities either it is true for all $n \in \mathbb{Z}^+$, (or) it is not true for some set of $n \in \mathbb{Z}^+$.

$\Rightarrow$ Let $S$ be the set of all $n$ that have $A(n)$ as false.

$\Rightarrow$ By principle of well ordering we have a smallest $k \in S$ for which $A(k)$ is false $\Rightarrow A(k-1)$ must be true.

$$\Rightarrow A(k-1): 1^2 + 2^2 + \dots + (k-1)^2 = \frac{(k-1)^3}{3} + \frac{(k-1)^2}{2} + \frac{k-1}{6}$$

$\Rightarrow$ Adding $k^2$ on both sides we get

$$1^2 + 2^2 + \dots + k^2 = \frac{(k-1)^3}{3} + \frac{(k-1)^2}{2} + \frac{k-1}{6} + k^2$$

$\Rightarrow$ RHS can be simplified to $\frac{k^3}{3} + \frac{k^2}{2} + \frac{k}{6}$

$\Rightarrow A(k)$ is true, but that is a contradiction, hence $S$ must be empty.

$\Rightarrow A(n)$ is true for all $n \in \mathbb{Z}^+$.

*Note: Both of the methods are referred to as proof by induction.*

### Nested Induction

$\to$ For some proofs we use induction inside induction and that is called Nested Induction. For example consider the following problem.

**Example**: Every product of $n$ consecutive positive integers is divisible by $n!$.

**Proof**: One way to prove this is to use binomial coefficient. Let $x$ be the starting integer, then we need to proove that

$$\frac{x \cdot (x+1) \cdot (x+2) \cdots (x+n-1)}{n!}$$

is an integer. If we multiply and divide by $(x-1)!$ we will get

$$\frac{(x+n-1)!}{(x-1)! \, n!} = \binom{x+n-1}{n}$$

$\Rightarrow \binom{x+n-1}{n}$ is the number of ways to choose $n$ people/items out of $(x+n-1)$. Here $x \ge 1$.

### The Nested Induction Proof

$\to$ The nested induction proof does not rely on the binomial coeff.

$\to$ Let $P(n, k)$ be the product $(k+1)(k+2)\cdots(k+n)$, where $k \ge 0$.

$\to$ The assertion $A(n)$ is that $P(n, k)$ is divisible by $n!$ for all non-negative integers $k$.

**Step 1**: $A(1)$ is always true as $(k+1)$ is always divisible by $1! = 1$.

**Step 2**: Assume that $A(n)$ is true for some $n \ge 1$.

$$\Rightarrow \frac{P(n, k)}{n!} = \frac{(k+1)\cdots(k+n)}{n!} \text{ is an integer always.}$$

**Step 3**: Now we need to prove that $A(n+1)$ is also always true.

$\to$ Here we start another Induction.

$\to$ The assertion is true for $k = 0$ as $P(n+1, 0) = (n+1)!$ and it is divisible by $(n+1)!$.

$\Rightarrow$ Now assume that $A(n+1)$ is true for some $k \ge 0$, that is

$$P(n+1, k) = (k+1)\cdots(k+1+n) \text{ is divisible by } (n+1)!$$

$\Rightarrow$ Now consider $\frac{P(n+1, k+1)}{(n+1)!}$, we

$$\Rightarrow \frac{P(n+1, k+1)}{(n+1)!} = \frac{(k+2)\cdots(k+1+n+1)}{(n+1)!}$$

$\Rightarrow$ If we split the last term $(k+1+n+1)$ and multiply all previous we get 2 sums:

$$= \frac{(k+2)\cdots(k+1+n)(k+1)}{(n+1)!} + \frac{(k+2)\cdots(k+1+n)(n+1)}{(n+1)!}$$

$$= \frac{P(n+1, k)}{(n+1)!} + \frac{P(n, k+1)}{n!}$$

Now from the first induction assumption we know that $\frac{P(n, k+1)}{n!}$ is an integer, and from the second induction assumption we know that $\frac{P(n+1, k)}{(n+1)!}$ is also an integer

$$\Rightarrow \frac{P(n+1, k+1)}{(n+1)!} \text{ is an integer, this}$$

proves that $A(n+1)$ is true for all $k \ge 0$, and that proves that $A(n)$ is true for all $n \ge 1$.

### (4.5) The Summation Notation

$\to$ It is a compact way to write summation where each term of the sum follows some clean pattern.

Eg. $1^2 + 2^2 + \dots + n^2 = \sum_{k=1}^n k^2$

$\Rightarrow$ On the top and bottom of the greek symbol $\sum$ we write the range of the sum ie the values that $k$ will take.

$\to$ $k$ is called the summation index and what symbol we use for it is unimportant.

**Formal Definition**: The formal definition of the symbol $\sum$ and it use to represent can be given by using induction.

$\to$ The definition consists of two parts,

(a) We define

$$\sum_{k=1}^1 a_k = a_1$$

(b) Assuming we have defined $\sum_{k=1}^n a_k$ for some fixed $n \ge 1$, then further we define

$$\sum_{k=1}^{n+1} a_k = \left(\sum_{k=1}^n a_k\right) + a_{n+1}$$

**Note**: This definition by induction is also called the recursive defn.

#### Some Properties of Finite Sums

(a) **Additive Property**:

$$\sum_{k=1}^n (a_k + b_k) = a_1 + b_1 + \dots + a_k + b_k$$

$$= (a_1 + \dots + a_k) + (b_1 + \dots + b_k)$$

$$= \sum_{k=1}^n a_k + \sum_{k=1}^n b_k$$

$$\Rightarrow \sum_{k=1}^n (a_k + b_k) = \sum_{k=1}^n a_k + \sum_{k=1}^n b_k$$

> [!WARNING] Flagged Note Inaccuracy: Index Notation in Expansion
> In the intermediate expanded expressions $a_1 + b_1 + \dots + a_k + b_k$ and $(a_1 + \dots + a_k) + (b_1 + \dots + b_k)$, the summation index variable $k$ is erroneously written at the end of the sum instead of the upper limit $n$.

(b) **Homogeneous Property**:

$$\sum_{k=1}^n (c a_k) = c a_1 + c a_2 + \dots + c a_n$$

$$= c (a_1 + a_2 + \dots + a_n)$$

$$\Rightarrow \sum_{k=1}^n (c a_k) = c \sum_{k=1}^n a_k$$

(c) **Telescoping Property**:

$$\sum_{k=1}^n (a_k - a_{k-1}) = \sum_{k=1}^n a_k + (-1)\sum_{k=1}^n a_{k-1}$$

$$= a_n + \sum_{k=1}^{n-1} a_k + (-1)\left(a_0 + \sum_{k=1}^{n-1} a_k\right)$$

$$= a_n - a_0$$

$$\Rightarrow \sum_{k=1}^n (a_k - a_{k-1}) = a_n - a_0$$

### (4.7) Absolute Values and the $\Delta^{\text{le}}$ Inequality

$\to$ The absolute value of $x$ is a non-negative real number denoted by $|x|$ and defined as follows.

$$|x| = \begin{cases} x & \text{if } x \ge 0 \\ -x & \text{if } x \le 0 \end{cases}$$

$\Rightarrow$ From the definition we can see that $x$ is either equal to $|x|$ (or) $-|x|$, so we can write the following inequality

$$-|x| \le x \le |x|$$

#### Theorem 1.38:
If $a \ge 0$, then $|x| \le a$ if and only if $-a \le x \le a$.

**Proof**: We have to prove this statement both ways.

**Case 1**: When $|x| \le a \Rightarrow -a \le -|x|$

We also know that $-|x| \le x \le |x|$

$$\Rightarrow -a \le -|x| \le x \le |x| \le a$$

$$\Rightarrow -a \le x \le a.$$

**Case 2**: When $-a \le x \le a$, then if $x \ge 0$ we have $x = |x|$, so in that case we have $|x| \le a$.

When $x < 0$, then we have $x = -|x|$

$$\Rightarrow -a \le x \Rightarrow -a \le -|x|$$

$$\Rightarrow |x| \le a \text{ in all cases.}$$

#### Geometrical Meaning

$\to$ On the real number line $|x|$ represents the distance of $x$ from 0.

$\Rightarrow |x| \le a$ means all the real numbers between $-a$ & $a$.

$$= a + x^2 \left(\frac{2b^3 + a}{3b^2}\right) > a$$

$$\Rightarrow c^3 > a \Rightarrow c^3 > x^3 \Rightarrow c > x \quad \forall x \in S.$$

$\Rightarrow c$ is upper bound and this leads to contradiction.

**Case (ii)**: $b^3 < a$

> [!WARNING] Flagged Note Inaccuracy: Notation Slip $b^3 < a^3$
> In the case header and text, the note writes $b^3 < a^3$ and $(b+c)^3 < a^3$ instead of $b^3 < a$ and $(b+c)^3 < a$. The subsequent calculations correctly use $a - b^3$.

$\Rightarrow$ In this case we chose a number $c$ such that $0 < c < b$ & $(b+c)^3 < a$.

$\Rightarrow$ That number turns out to be any $c$ such that

$$0 < c < b \quad \& \quad c < \frac{a - b^3}{7b^2}$$

$$\Rightarrow \text{Now, } (b+c)^3 = b^3 + 3b^2 c + 3b c^2 + c^3$$

$$= b^3 + c(3b^2 + 3bc + c^2)$$

$$< b^3 + c(3b^2 + 3b^2 + b^2)$$

$$= b^3 + c(7b^2)$$

$$< b^3 + a - b^3$$

$$< a$$

$$\Rightarrow (b+c)^3 < a \Rightarrow b+c \in S, \text{ but this is again a contradiction.}$$

$\Rightarrow$ Hence the only option that works is that $b^3 = a$.

**Note**: I have tried to generalize the approach and this can be used for any $n$ now.

(i) Declare a set $S$ and prove that $S$ is bounded from above and not empty. Hence, $\sup S = b$ exists.

(ii) Then prove that $b^3 > a$ is not possible as there exist $0 < c < b$ whose $c^3 > a$.

(iii) Then prove that $b^3 < a$ is also not possible as we can find a number $c$ such that $(b+c)^3 < a$ & $0 < c < b$.

(iv) This leaves us with only one option that $b^3 = a$.
