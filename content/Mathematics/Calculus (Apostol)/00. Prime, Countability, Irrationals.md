$\Rightarrow$ Not only are the factors $p_1, p_2, \dots, p_k$ unique, their powers are unique as well.

### Theorem: There are infinitely many prime numbers.

**Proof**: Fermat's number $F_n = 2^{2^n} + 1$

First we need to prove the following fact that,

$$\prod_{k=0}^{n-1} F_k = F_n - 2, \quad n \ge 1$$

$$\Rightarrow 2^{2^n} + 1 = \frac{2^{2^{n+1}} - 1}{2^{2^n} - 1}$$

$$\Rightarrow \prod_{k=0}^{n-1} F_k = \prod_{k=0}^{n-1} \left(2^{2^k} + 1\right) = \prod_{k=0}^{n-1} \frac{2^{2^{k+1}} - 1}{2^{2^k} - 1}$$

$$= \frac{2^{2^n} - 1}{2^{2^0} - 1} = 2^{2^n} + 1 - 2$$

$$\Rightarrow \prod_{k=0}^{n-1} F_k = F_n - 2$$

$\Rightarrow$ Now, the actual proof starts.

The idea is that we will prove that every 2 fermates numbers are co-primes ie they are relatively prime i.e. their gcd or hcf is 1.

$\to$ Now, since there are infinitely many fermates numbers as there are infinitely many $n$'s, this would mean that there are infinitely many prime numbers.

Consider now the result we just proved, if any $F_k$ and $F_n$ have an common factor $q$, then it means that $q$ also divides $\prod_{k=0}^{n-1} F_k$, this means it must also divide $F_n - 2$, and since it divides $F_n$, this $q$ must also divide 2.

> [!WARNING] Flagged Note Inaccuracy: Index Condition for Fermat Numbers
> In the step stating "$q$ also divides $\prod_{k=0}^{n-1} F_k$", it requires $k < n$ so that $F_k$ is one of the factors in the product $\prod_{k=0}^{n-1} F_k$.

$\Rightarrow$ The only possibilities for $q$ are $q = 1$ or $2$, but $q \ne 2$ as that would make the Fermat's numbers even but they are odd, hence $q = 1$.

$\Rightarrow$ Hence proved.

* **Note**: We can also prove the formula $\prod_{k=0}^{n-1} F_k = F_n - 2$ using mathematical induction.

$$\Rightarrow \prod_{k=0}^{n} F_k = \left(\prod_{k=0}^{n-1} F_k\right) F_n = (F_n - 2) F_n$$

$$\Rightarrow \prod_{k=0}^{n} F_k = F_{n+1} - 2$$

### Decimal Representation

Every rational number can be represented as sum of powers of 10 multiplied by some integer $a_i$ such that $0 \le a_i \le 9$.

$\Rightarrow$ There is a (.) called the decimal that separates (-ve) powers with positive powers

> [!WARNING] Flagged Note Error: Powers Separated by Decimal
> The notes state that the decimal separates negative powers from positive powers. However, the digit immediately preceding the decimal point corresponds to $10^0$ (power $0$, which is non-negative, not positive). It separates non-negative powers ($\ge 0$) from negative powers ($< 0$).

$\to$ E.g. $\frac{25}{2} = 12.5 = 1 \times 10^1 + 2 \times 10^0 + 5 \times 10^{-1}$

$\to$ There are 2 types of decimal expansion that we get for rational numbers:

#### (i) Terminating decimal expansion
This means that number of digits after decimal are finite.

E.g. $\frac{185}{50} = 3.7$

$\Rightarrow$ Every number of this type can be written in the form of $\frac{a}{10^k}$ where $a$ is an integer.

$\Rightarrow$ **How to Identify this type?**
Given a rational number $\frac{p}{q}$ you can tell if it has terminating decimal by checking the prime factors of $q$.
$\Rightarrow$ If they consist of only 2 & 5 then it will have terminating decimal.

> [!WARNING] Flagged Note Error: Condition for Terminating Decimal
> The rule that $q$ has only prime factors 2 and 5 applies only when the fraction $\frac{p}{q}$ is in simplest form ($\gcd(p, q) = 1$). If not reduced (e.g., $\frac{3}{6} = 0.5$), $q$ has a factor of 3, but the decimal terminates.

#### (ii) Non-terminating repeating
$\to$ This is where the decimal expansion repeats infinitely, and we can convert any such decimal back to fraction using an algorithm.

E.g.
$$\frac{1}{3} = 0.333\dots = 0.\bar{3}$$

$$\frac{2}{7} = 0.\overline{285714}$$

#### Converting Non Terminating Repeating Decimal to $\frac{p}{q}$ form
$\Rightarrow$ This is shown in the following example.

E.g. $n = 133.\overline{12} = 133 + 0.\overline{12}$

$$\text{let } x = 0.\overline{12} \Rightarrow 100x = 12.\overline{12}$$

$$\Rightarrow 100x = 12 + 0.\overline{12} = 12 + x$$

$$\Rightarrow x = \frac{12}{99}$$

$$\Rightarrow n = 133 + \frac{12}{99} = \frac{13179}{99}$$

### Countable Set
A set $M$ is countable if its elements can be put in one-to-one correspondance with $\mathbb{N}$.

$$M = \{a_1, a_2, a_3, \dots\}$$
$$\updownarrow \quad \updownarrow \quad \updownarrow$$
$$\mathbb{N} = \{1, 2, 3, \dots\}$$

> [!WARNING] Flagged Note Error: Definition of Countable Set
> The notes define a countable set strictly via a bijection with $\mathbb{N}$, which standardly defines a *countably infinite* (or denumerable) set. In general mathematics, a set is countable if it is finite or countably infinite.

### Cardinality
It refers to the number of elements in a set, measuring its size. It ignores duplicates, counting only distinct elements. For a set $S$ it is denoted by $|S|$ or $n(S)$.

### Hilbert's Hotel

#### (iii) $\mathbb{Z}$ (Set of Integers) is Countable
$\to$ One way to show this is to arrange all integers in the following manner and assign them their position.

$$\begin{array}{ccccccccc}
\Rightarrow & 0 & 1 & -1 & 2 & -2 & 3 & -3 & \dots \\
& 1 & 2 & 3 & 4 & 5 & 6 & 7 & \dots
\end{array}$$

$\to$ The more rigorous way is the following function $f: \mathbb{N} \to \mathbb{Z}$

$$f(n) = \begin{cases} \frac{n}{2}, & \text{when } n \text{ is even} \\ -\frac{n-1}{2}, & \text{when } n \text{ is odd} \end{cases}$$

E.g.
$$f(1) = -(1-1)/2 = 0$$
$$f(2) = 2/2 = 1$$
$$f(3) = -(3-1)/2 = -1$$
$$f(4) = 4/2 = 2$$
$$f(5) = -(5-1)/2 = -2$$

* **Injective**: no two natural numbers must have the same output.
  $\Rightarrow$ If both are even $\Rightarrow \frac{n_1}{2} = \frac{n_2}{2} \Rightarrow n_1 = n_2$
  $\Rightarrow$ If both are odd $\Rightarrow -\frac{n_1-1}{2} = -\frac{n_2-1}{2} \Rightarrow n_1 = n_2$
  $\Rightarrow$ If one is even and other is odd, then we have:
  $$\frac{n_1}{2} = -\frac{n_2-1}{2} \Rightarrow n_1 + n_2 = 1$$
  $\Rightarrow$ But that is contradiction to fact that $n_1, n_2 \in \mathbb{N}$ & 1 is smallest in $\mathbb{N}$.
  $\Rightarrow$ Hence the function is injective

* **Surjective**: Every number in $\mathbb{Z}$ has a number in $\mathbb{N}$ corresponding to it.
  $\to$ For 0 we have 1.
  $\to$ For $z > 0$, we have $n = 2z \Rightarrow \frac{2z}{2} = z$
  $\to$ For $z < 0$, we have $n = 1 - 2z \Rightarrow -\frac{1 - 2z - 1}{2} = \frac{2z}{2} = z$.

$\Rightarrow$ Hence $f$ is surjective, this proves that $f$ is bijection from $\mathbb{N}$ to $\mathbb{Z}$, hence $\mathbb{Z}$ is countable set.

### The Cartesian Product Theorem
This theorem states that the cartesian product of two countable sets is also countable.

**Proof**: Let $A$ and $B$ be any 2 countable sets, this means that we can assign a unique natural number to every element for $A$, same goes for $B$.

$\Rightarrow$ There exists injective functions $f$ and $g$ such that
$$f: A \to \mathbb{N}$$
$$g: B \to \mathbb{N}$$

$\Rightarrow$ Now we can define a mapping $h(a, b)$ from $A \times B \to \mathbb{N}$ which is also injective thereby proving the theorem.

$\Rightarrow$ We define $h(a, b) = 2^{f(a)} 3^{g(b)}$.

$\Rightarrow$ Now $f(a), g(b) \in \mathbb{N} \Rightarrow 2^{f(a)} 3^{g(b)} \in \mathbb{N}$

$\Rightarrow$ Now we will prove that this $h(a, b)$ is injective i.e $h(a_1, b_1) = h(a_2, b_2)$ then we have $a_1 = a_2$ & $b_1 = b_2$.

$$\Rightarrow 2^{f(a_1)} 3^{g(b_1)} = 2^{f(a_2)} 3^{g(b_2)}$$

$\Rightarrow$ Since 2 & 3 are primes we can use the Fundamental Theorem of Arithmetic that every positive integer has a unique prime factorization.

$$\Rightarrow f(a_1) = f(a_2) \quad \& \quad g(b_1) = g(b_2)$$

$\Rightarrow$ But since $f$ & $g$ are injective functions we have $a_1 = a_2$ & $b_1 = b_2$.

$$\Rightarrow A \times B \text{ is also countable set.}$$

### The Rational Root Theorem

**Th**: If $f(x)$ is an $n$th degree polynomial with integer coefficients, then if the rational number $r = \frac{p}{q}$ is a root of this $f(x)$ then $p$ must divide $c_0$ and $q$ divides $c_n$.

$$f(x) = c_n x^n + c_{n-1} x^{n-1} + \dots + c_1 x + c_0$$

**Proof**: The proof is simple, we can write $r = \frac{p}{q}$ such that $p$ and $q$ are co-primes.

$$\Rightarrow f\left(\frac{p}{q}\right) = 0 \Rightarrow c_n \left(\frac{p}{q}\right)^n + \dots + c_1 \left(\frac{p}{q}\right) + c_0 = 0$$

$\Rightarrow$ Getting rid of the denom.

$$\Rightarrow c_n p^n + c_{n-1} p^{n-1} q + \dots + c_1 p q^{n-1} + c_0 q^n = 0$$

$$\Rightarrow c_n p^n = -(c_{n-1} p^{n-1} q + \dots + c_0 q^n) = -q (c_{n-1} p^{n-1} + \dots + c_0 q^{n-1})$$

$\Rightarrow q$ is factor of $c_n p^n$, but since $p$ and $q$ are co-primes hence $c_n$ must have $q$ as factor.

$\Rightarrow$ Similarly, we can prove that $p$ is a factor of $c_0$.

### Method to check that $\sqrt[n]{a}$ is Rational or Irrational

$\to$ Testing whether $\sqrt{2}, \sqrt{3}, \sqrt{6}$ is rational or not is relatively an easy thing to do, but it is not so easy to prove this for any general $\sqrt[n]{a}$ where $a, n \in \mathbb{N}$.

$\to$ The first fact about $\sqrt[n]{a}$ that we prove is that it is either not rational or an Integer.

$\to$ For this we will use the result that we derived in the last page.

$\sqrt[n]{a}$ is a number that is a solution of the polynomial,

$$\because x^n - a = 0$$

$\to$ If $\frac{p}{q}$ is a solution, then $q$ must be a factor of $c_n = 1 \Rightarrow q = 1$.

$\Rightarrow$ Hence if the value of $\sqrt[n]{a}$ is rational then it must be an integer.

$\Rightarrow$ Now, if $\sqrt[n]{a}$ is a rational we have that $p$ must be a factor of $a$.

$\Rightarrow$ We can find all factors of $a$ and then put them 1 by 1 in the polynomial $x^n - a = 0$ and if any of the factor satisfies then $\sqrt[n]{a}$ is rational and equal to that integer.

E.g. $\sqrt[3]{5} \Rightarrow x^3 - 5 = 0$, the factors of 5 are, $1, -1, 5, -5$, we can see that none of these satisfy the equation hence $\sqrt[3]{5}$ is an irrational number.
