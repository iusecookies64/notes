## Module Introduction

This module shifts focus from spatial data (images) to **temporal data**. Time series data consists of observations recorded sequentially over time, where the **order** of data points is the most critical feature.

---

### 1. What Makes Time Series Data Unique?

Unlike tabular data, where each row is often independent, time series data is defined by its dependencies:

* **Temporal Ordering:** The sequence is fixed. Shuffling the rows destroys the meaning of the dataset.
* **Autocorrelation:** A data point is often highly correlated with its own past (e.g., if it is hot today, it is likely to be warm tomorrow).
* **Trend:** A long-term increase or decrease in the data (e.g., a company's stock growing over 10 years).
* **Seasonality:** Repeating patterns at fixed intervals (e.g., increased retail sales every December).
* **Non-Stationarity:** The statistical properties (mean, variance) of the data change over time, making it difficult for models to generalize without processing.
* **Exogenous Variables:** External factors (holidays, economic shifts) that impact the sequence but are not part of the time series itself.

---

### 2. Why Feature Engineering is Essential

Raw time series data is often just a timestamp and a value. Feature engineering is required to:

* Convert the temporal structure into a format machine learning models can process.
* Highlight cyclical patterns that are otherwise "hidden" in the raw numbers.
* Account for "lags" (past events influencing the present).

---

### 3. Common Techniques Preview

The module introduces three foundational categories of features:

| Feature Category | Description | Example |
| --- | --- | --- |
| **Lag Features** | Using values from previous time steps as current features. | Using *yesterday’s* price to predict *today’s*. |
| **Rolling Statistics** | Calculating metrics (mean, std dev) over a sliding window. | A 7-day moving average to smooth out daily noise. |
| **Date/Time Features** | Extracting categorical information from the timestamp. | Identifying if a date is a "Weekend" or a "Holiday." |

---

### 4. Primary Library Tools

Time series manipulation in Python is primarily handled by **Pandas**, which provides built-in methods for shifting and windowing data.

**Key Pandas Methods:**

```python
import pandas as pd

# 1. Lag Features (shifting data)
df['previous_day'] = df['value'].shift(1)

# 2. Rolling Statistics (7-day window)
df['rolling_mean'] = df['value'].rolling(window=7).mean()

# 3. Date Features
df['month'] = df['timestamp'].dt.month
df['is_weekend'] = df['timestamp'].dt.dayofweek > 4

```

## Feature Engineering: Time Series Concepts

Time series feature engineering focuses on making hidden temporal patterns—like cycles, dependencies, and trends—explicit for a machine learning model.

---

### 1. Seasonality & Calendar Features

Seasonality refers to patterns that repeat at fixed intervals (daily, weekly, monthly). By extracting specific date components, we transform a raw timestamp into meaningful categories.

* **Day of Month:** Captures monthly cycles (e.g., paydays affecting retail).
* **Weekday:** Identifies weekly cycles (e.g., traffic drops on weekends).
* **Month:** Accounts for annual trends (e.g., holiday shopping in December).
* **Week Number:** Useful for business reporting or planning cycles.

**Primary Library Methods (Pandas):**

```python
import pandas as pd

# Extracting components from a DatetimeIndex
df['day'] = df.index.day
df['weekday'] = df.index.weekday # 0=Monday, 6=Sunday
df['month'] = df.index.month
df['week_of_year'] = df.index.isocalendar().week
df['is_weekend'] = df.index.weekday >= 5

```

---

### 2. Lag Features (Temporal Memory)

Lag features are past values of the target variable used as predictors for the current time step. They provide the model with "memory," answering: *"What happened  steps ago?"*

* **Lag 1:** Yesterday's value (useful for daily data).
* **Lag 7:** Value from exactly one week ago (captures weekly seasonality).

**Primary Library Methods (Pandas):**

```python
# Shifting the series backward to create lags
df['lag_1'] = df['value'].shift(1)
df['lag_7'] = df['value'].shift(7)

```

> **Note:** Shifting creates `NaN` (null) values at the beginning of the dataset because there is no "past" data available for the very first entries.

---

### 3. Rolling Statistics (Smoothing & Variation)

Rolling statistics summarize data within a sliding window. This helps the model look at recent behavior rather than just a single, potentially noisy data point.

* **Rolling Mean:** Smooths out short-term noise to reveal the underlying trend.
* **Rolling Standard Deviation:** Measures recent volatility or variability.
* **Rolling Slope:** Uses linear regression over a window to determine if the trend is currently moving upward (positive slope) or downward (negative slope).

**Primary Library Methods (Pandas):**

```python
# Calculating statistics over a 7-day sliding window
df['rolling_mean_7'] = df['value'].rolling(window=7).mean()
df['rolling_std_7'] = df['value'].rolling(window=7).std()

```

---

### Summary Table: Time Series Techniques

| Technique | Goal | Practical Benefit |
| --- | --- | --- |
| **Calendar Features** | Capture Seasonality | Helps model "know" it's a holiday or weekend. |
| **Lag Features** | Capture Dependency | Provides the model with historical context. |
| **Rolling Stats** | Smooth Noise | Highlights the local trend and reduces spikes. |
| **Rolling Slope** | Quantify Trend | Tells the model how steeply a value is rising/falling. |

## Feature Engineering: Financial Time Series

In the finance domain, feature engineering transforms raw price data into technical indicators that capture **momentum**, **volatility**, and **trend reversals**. Using a dataset inspired by Yahoo Finance (containing Open, High, Low, Close, and Volume), we can derive sophisticated features for algorithmic trading and forecasting.

---

### 1. Basic Temporal & Statistical Features

As seen in previous sections, we start by building a foundation of lags and rolling statistics:

* **Time-based:** Day, Weekday, Month, and Weekend indicators.
* **Lag Features:** Lags (1, 3, 7 days) to provide the model with "memory."
* **Rolling Statistics:** 7-day mean, standard deviation, and **rolling slope** (trend direction).

---

### 2. Domain-Specific Financial Features

These features are calculated using specific financial formulas to identify market conditions:

#### **A. Moving Average (MA)**

Similar to a rolling mean, a **14-day Moving Average** smooths price data to identify the long-term trend.

* **OpenCV/Pandas Logic:** `df['MA14'] = df['Close'].rolling(window=14).mean()`

#### **B. Relative Strength Index (RSI)**

RSI is a momentum oscillator (0–100) that measures the speed and change of price movements.

* **Overbought (>70):** The price has risen too quickly; a pullback may be coming.
* **Oversold (<30):** The price has fallen sharply; a rebound may be likely.

**Primary Function (Simplified Logic):**

```python
# Conceptual RSI calculation
delta = df['Close'].diff()
gain = (delta.where(delta > 0, 0)).rolling(window=14).mean()
loss = (-delta.where(delta < 0, 0)).rolling(window=14).mean()
rs = gain / loss
df['RSI'] = 100 - (100 / (1 + rs))

```

#### **C. Bollinger Bands**

These visualize volatility and define a "normal" range for price movement.

* **Middle Band:** A 20-day (or 7-day) rolling mean.
* **Upper Band:** Middle Band + (2  Rolling Std Dev).
* **Lower Band:** Middle Band - (2  Rolling Std Dev).

**Primary Function:**

```python
# Calculating volatility bands
rolling_mean = df['Close'].rolling(window=7).mean()
rolling_std = df['Close'].rolling(window=7).std()

df['Upper_Band'] = rolling_mean + (rolling_std * 2)
df['Lower_Band'] = rolling_mean - (rolling_std * 2)

```

---

### 3. Summary of Financial Indicators

| Indicator | Type | Purpose |
| --- | --- | --- |
| **Moving Average** | Trend | Identifies the general direction (Bullish/Bearish). |
| **RSI** | Momentum | Spots potential price reversals (Overbought/Oversold). |
| **Bollinger Bands** | Volatility | Identifies if current price is within "normal" variation. |
| **Rolling Slope** | Trend | Quantifies how steeply the price is rising or falling. |

---

### Visualization Insights

* **Price vs. MA:** When the price crosses above the Moving Average, it often signals an upward trend.
* **RSI Plot:** Watching for the blue line to cross the 70 or 30 thresholds provides "buy/sell" warning signals.
* **Bollinger Width:** Narrow bands indicate low volatility (the "squeeze"), while wide bands indicate high market turbulence.

## Feature Engineering: Medical Time Series (ECG Data)

In the healthcare domain, time-series analysis focuses on physiological signals. A primary example is the **ECG (Electrocardiogram)**, which tracks the electrical activity of the heart. The most critical "feature" extracted from a raw ECG signal is the **RR Interval**.

---

### 1. Understanding RR Intervals

An **RR Interval** is the time between two successive R-peaks (the highest points) on an ECG.

* **Significance:** It measures one complete cardiac cycle.
* **Normal Range:** Between 600 and 1200 milliseconds (rest).
* **Relationship to Heart Rate:**
	* Shorter RR = Faster Heart Rate (Tachycardia).
	* Longer RR = Slower Heart Rate (Bradycardia).



---

### 2. Basic Feature Extraction

Even with daily average RR data, we can apply standard time-series techniques:

* **Time-based:** Day, Weekday, Month (captures cycles related to sleep or activity).
* **Lag Features:** Lags (1, 3, 7 days) to see if past heart rhythms predict current ones.
* **Rolling Statistics:** 7-day mean and standard deviation to identify long-term health trends.
* **Rolling Slope:** To see if a patient's resting heart rate is trending up or down over a week.

---

### 3. Domain-Specific Feature: Heart Rate Variability (HRV)

**HRV** is the variation in time between heartbeats. Unlike heart rate (which is an average), HRV measures the **fluctuation**. It is a key indicator of the autonomic nervous system's health.

* **High HRV:** Indicates a healthy, flexible cardiovascular system (good recovery/low stress).
* **Low HRV:** Indicates stress, fatigue, or potential illness.

#### **RMSSD (Root Mean Square of Successive Differences)**

RMSSD is the most common time-domain measure for HRV. It emphasizes high-frequency variations (the "beat-to-beat" changes).

**The 4-Step RMSSD Calculation:**

1. Calculate the **difference** between successive RR intervals.
2. **Square** those differences.
3. Calculate the **mean** of the squared differences over a window.
4. Take the **square root** of that mean.

**Primary Library Methods (Pandas/NumPy):**

```python
import numpy as np

# 1. Successive differences
diff = df['RR'].diff()

# 2. Square the differences
squared_diff = diff ** 2

# 3. & 4. Rolling mean and Square Root (7-day window)
df['HRV_RMSSD'] = np.sqrt(squared_diff.rolling(window=7).mean())

```

---

### 4. Real-World Application: MIT-BIH Arrhythmia Dataset

In clinical datasets like the **MIT-BIH Arrhythmia Database**, features are much more granular. Instead of daily averages, features are extracted for **every single beat**.

* **Pre-RR:** The interval immediately *before* a specific beat.
* **Post-RR:** The interval immediately *after* a specific beat.
* **Significance:** These features provide the "temporal context" necessary for machine learning models to classify beats into categories like **Normal**, **Supraventricular**, or **Ventricular** ectopic beats.
