## Module Introduction

### Why Text Data is Different

In previous modules, we focused on **structured data** (tabular data) where features like age, income, or price are already numerical or easily categorized. Feature engineering for text is fundamentally different because text is:

* **Unstructured:** There are no fixed columns or predefined lengths.
* **Highly Variable:** The same idea can be expressed in infinite ways.
* **Context-Dependent:** The meaning of a word can change based on the words surrounding it.

### The Core Challenge: The "Meaning" Gap

Machines cannot "read" text; they only understand numbers. The goal of feature engineering here is to convert raw text into **numeric vectors** without losing the underlying meaning, tone, or relationships.

> **Example:** > 1. "I love this movie."
> 2. "This movie is great."
> To a human, these are nearly identical. To a computer, they are just different strings of characters. Feature engineering must bridge this gap so the model recognizes their **semantic similarity**.

---

### Key Concepts in Text Feature Engineering

To transform "messy" text into model-ready features, we use a variety of techniques ranging from simple counts to complex linguistic rules.

#### 1. Classical Approaches (Frequency-Based)

* **Bag of Words (BoW):** A simple method that counts how many times each word appears in a document. It ignores word order but captures the general vocabulary.
* **TF-IDF (Term Frequency-Inverse Document Frequency):** A smarter counting method that gives more importance to unique, "meaningful" words and less importance to common words like "the" or "is."

#### 2. Modern Approaches (Context & Semantics)

* **Word Embeddings:** Mathematical representations where words with similar meanings are placed close together in a multi-dimensional space. This captures deep relationships (e.g., "King" is to "Man" as "Queen" is to "Woman").
* **Part of Speech (POS) Tagging:** Identifying whether a word is a noun, verb, or adjective to help the model understand the grammatical structure of a sentence.

---

### Summary of the Workflow

1. **Raw Text:** Unstructured sentences and paragraphs.
2. **Transformation:** Applying techniques (BoW, TF-IDF, or Embeddings) to turn strings into numbers.
3. **Feature Vectors:** The final numeric representation that a machine learning model can process.

---

## Tokens and Vectors

### The Pre-processing Pipeline

Before text can be turned into features for a machine learning model, it must undergo several "cleaning" steps. This ensures the model focuses on meaningful content rather than "noise."

* **Tokenization:** The process of breaking down a raw sentence into individual units (words, subwords, or characters).
* *Example:* "I love tech" \rightarrow `["I", "love", "tech"]`.


* **Case Normalization:** Converting all characters to lowercase so that "Apple" and "apple" are treated as the same word.
* **Stop Word Removal:** Deleting common words like "the," "is," and "at." These words appear frequently but carry little unique meaning for classification.
* **Stemming/Lemmatization:** Reducing words to their root form (e.g., "running" \rightarrow "run").

---

### Vectorization: Turning Text into Numbers

Machine learning algorithms (like Logistic Regression or Neural Networks) cannot "read"; they require numeric input. **Vectorization** is the process of mapping tokens to numeric vectors.

#### 1. Bag of Words (BoW)

A basic technique that creates a vocabulary of all unique words and simply counts how many times each word appears in a document.

* **Pro:** Simple and fast.
* **Con:** Ignores word order and context.

#### 2. TF-IDF (Term Frequency-Inverse Document Frequency)

A more sophisticated method that weights words based on their importance. It balances two factors:

1. **Term Frequency (TF):** How often a word appears in a specific document. (High frequency = High weight).
2. **Inverse Document Frequency (IDF):** how rare a word is across the *entire collection* (corpus) of documents. (Common words across all docs = Lower weight).

> **The Logic:** In a set of political articles, the word "election" is highly meaningful (high TF-IDF), while the word "said" is likely common everywhere and is penalized (low TF-IDF).

The **Natural Language Toolkit (NLTK)** is a popular Python library used for these tasks. It includes pre-trained models and datasets, such as:

STEP 3: Basic Text Cleaning
```python
# ------------------------------------------------
# 1. Define the text cleaning function
# ------------------------------------------------
# This function takes raw text and:
# - Splits it into tokens (words)
# - Converts everything to lowercase
# - Removes punctuation and stopwords
# - Returns the cleaned sentence as a single string

import nltk
from nltk.tokenize import word_tokenize
from nltk.corpus import stopwords
import string

def clean_text(text):
    tokens = word_tokenize(text)                            # Break sentence into individual words
    tokens = [t.lower() for t in tokens if t.isalpha()]     # Keep only alphabetic words, discard numbers/punctuation
    tokens = [t for t in tokens if t not in stopwords.words('english')]  # Remove stopwords like 'the', 'is', 'and'
    return " ".join(tokens)                                 # Join back into cleaned sentence

# ------------------------------------------------
# 2. Apply the cleaning on a small subset (for speed)
# ------------------------------------------------
# We'll use only 2000 samples from the full 18846 to reduce processing time during the lab
df_small = df.sample(2000, random_state=42).copy()          # Random 2000 documents
df_small['clean_text'] = df_small['text'].apply(clean_text) # Apply the cleaning

# ------------------------------------------------

# ------------------------------------------------
print("Original Text Sample:\n")
print(df_small['text'].iloc[0][:500])  # Show first 500 chars of original
print("\nCleaned Text:\n")
print(df_small['clean_text'].iloc[0])  # Show cleaned version

# ------------------------------------------------
# INTERPRETATION:
# ------------------------------------------------

# - The cleaned version is more focused and ready for feature extraction.
# - This preprocessing improves model accuracy and reduces noise.

# ==============================================
```

STEP 5: TF-IDF Vectorization
```python
# ------------------------------------------------
# TF-IDF vectorizer transforms text into weighted numerical features.
# It reduces the influence of frequent words and boosts rare but important words.
# ------------------------------------------------

from sklearn.feature_extraction.text import TfidfVectorizer

# Initialize vectorizer: keep top 3000 features (by frequency)
tfidf = TfidfVectorizer(max_features=3000)

# Apply TF-IDF to cleaned text to generate a sparse feature matrix
X_tfidf = tfidf.fit_transform(df_small['clean_text'])

# ------------------------------------------------
# Check shape of resulting TF-IDF matrix
# ------------------------------------------------
print("TF-IDF Matrix Shape:", X_tfidf.shape)
# Example output: (2000, 3000) = 2000 documents and 3000 top weighted features

# ------------------------------------------------
# Let's analyze most important features by average TF-IDF value
# ------------------------------------------------

feature_names = tfidf.get_feature_names_out()        # List of all feature terms
tfidf_means = X_tfidf.mean(axis=0).A1                # Compute mean TF-IDF score for each term across all docs
sorted_indices = np.argsort(tfidf_means)[::-1][:10]  # Get indices of top 10 highest TF-IDF features

# Print the top 10 most important features with their TF-IDF scores
print("Top 10 TF-IDF Features (by average importance across docs):")
for idx in sorted_indices:
    print(f"{feature_names[idx]}: {tfidf_means[idx]:.4f}")

# ------------------------------------------------
# INTERPRETATION:
# ------------------------------------------------
# - These words contribute most to document uniqueness.
# - High TF-IDF = rare but significant across the corpus.
# - Unlike raw counts, TF-IDF avoids giving high score to frequent stopwords.
# ==============================================
```

### Understanding Word Vectors

In a modern NLP pipeline, a sentence with n tokens will typically result in n vectors.

* **Vector Definition:** An array of numbers (floats) that represent the semantic properties of a word.
* **High-Dimensional Space:** These numbers represent the word's position in a "meaning space" where similar words are grouped together.

### Summary of the Classification Workflow

1. **Cleaning:** Word tokenization, removing non-alphabetic characters, and filtering out stop words.
2. **Vectorization:** Applying **TF-IDF** to the cleaned text to generate a feature matrix (e.g., 2,000 samples \times 3,000 features).
3. **Modeling:** Training a **Logistic Regression** classifier on the TF-IDF vectors.
4. **Analysis:** Extracting the features with the highest mean TF-IDF scores to see which words were most influential in defining the documents.
