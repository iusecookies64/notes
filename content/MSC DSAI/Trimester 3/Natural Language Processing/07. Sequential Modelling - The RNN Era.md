## 1. Fundamentals of Sequential Modeling

### The Limitations of Classical Architectures

Traditional machine learning and feedforward neural network approaches treat input data as independent, static feature vectors. When applied to language and temporal data, classical representations (such as Bag-of-Words and TF-IDF) encounter two fundamental bottlenecks:

- **Fixed-Dimension Constraint:** A standard feedforward neural network requires a rigid, predetermined number of input neurons. In a Bag-of-Words (BoW) model, the input vector size is strictly bounded to the total vocabulary size $\vert{}V\vert{}$ (e.g., a $10,000$-dimensional vector for a $10,000$-token vocabulary), regardless of whether the text is a three-word phrase or a lengthy article.
    
- **Loss of Temporal Order (Permutation Invariance):** BoW representations aggregate token frequencies while discarding positional context. Consequently, semantically opposite sentences such as _"The dog bit the man"_ and _"The man bit the dog"_ yield identical mathematical vectors because they contain the exact same token set. Similarly, modifiers lose their local dependency (e.g., _"not good"_ is decomposed into isolated tokens rather than a negated sentiment).

|**Architectural Feature**|**Traditional Models (BoW, TF-IDF, Standard MLPs)**|**Sequential Models (RNNs, LSTMs, GRUs)**|
|---|---|---|
|**Input Length**|Fixed dimension; requires zero-padding or vector truncation.|Dynamic; natively ingests variable-length inputs token-by-token.|
|**Order Sensitivity**|Permutation invariant; ignores word positions.|Temporal; preserves syntactic and contextual order.|
|**Context Representation**|Static token frequency counts.|Continuously updated internal state vectors.|

### The Sequential First Principle

Natural language and time-series data are inherently ordered sequences where the semantic value of token $x_t$ depends conditioned on the sequence of preceding tokens $(x_1, x_2, \dots, x_{t-1})$. Sequential modeling treats data as a dynamic stream, carrying forward historical context to interpret current inputs.

## 2. Sequence-to-Sequence (Seq2Seq) Modeling

Sequence-to-Sequence (Seq2Seq) architectures map an input sequence from one domain to an output sequence in another domain, where both sequences can vary arbitrarily in length.

```
Input Sequence: [x_1, x_2, ..., x_T]
       │
       ▼
┌──────────────┐
│   ENCODER    │ ───► [ Context Vector / Final Hidden State ]
└──────────────┘                           │
                                           ▼
                                    ┌──────────────┐
                                    │   DECODER    │ ───► Output Sequence: [y_1, y_2, ..., y_T']
                                    └──────────────┘
```

### The Encoder-Decoder Mechanism

The network is split into two specialized sub-networks:

- **The Encoder:** Ingests the source sequence one token at a time. As it processes each element, it updates its internal state to condense the semantic, syntactic, and factual information of the entire sequence into a single, fixed-size vector called the **context vector** (or final hidden state).
    
- **The Decoder:** Accepts the context vector as its initial hidden state and autoregressively generates the target sequence token-by-token until a termination condition is reached.

### Primary Applications

- **Machine Translation:** Mapping a source sentence (e.g., _"I am fine"_) to a target language (e.g., _"Je vais bien"_).
    
- **Abstractive Text Summarization:** Condensing a long document into a concise summary sequence.
    
- **Speech Recognition:** Transcribing sequential acoustic audio frames into text token sequences.

### The Information Bottleneck

A core theoretical drawback of the basic Seq2Seq architecture is the **information bottleneck**. Forcing an entire sequence of arbitrary length and complexity into a single static vector causes information degradation. As sequence length increases, early contextual cues are overwritten by later tokens before reaching the decoder, leading to context loss (a limitation resolved in advanced models by attention mechanisms).

## 3. Vanilla Recurrent Neural Networks (RNNs)

Unlike standard feedforward networks that map an input directly to an output along a unidirectional path, a Recurrent Neural Network contains a cyclic feedback loop. This feedback loop passes the hidden representation from the previous time step into the current time step, allowing historical context to persist.

```
 Unrolled across time steps:
 
    y_{t-1}                y_t                y_{t+1}
       ▲                    ▲                    ▲
       │                    │                    │
  ┌────┴────┐  W_hh    ┌────┴────┐  W_hh    ┌────┴────┐
  │ h_{t-1} │ ───────► │   h_t   │ ───────► │ h_{t+1} │
  └────┬────┘          └────┬────┘          └────┬────┘
       ▲                    ▲                    ▲
       │ W_xh               │ W_xh               │ W_xh
       │                    │                    │
    x_{t-1}                x_t                x_{t+1}
```

### Mathematical Formulation

At each discrete time step $t$, the network receives the current input vector $x_t$ and the previous hidden state vector $h_{t-1}$. The current hidden state $h_t$ and output $y_t$ are computed as:
$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$
$$y_t = \text{Softmax}(W_{hy} h_t + b_y)$$
Where:

- $x_t \in \mathbb{R}^d$ is the input vector at time step $t$.
    
- $h_{t-1} \in \mathbb{R}^h$ is the hidden state vector holding context from steps $1$ to $t-1$.
    
- $W_{xh} \in \mathbb{R}^{h \times d}$ is the input-to-hidden weight matrix.
    
- $W_{hh} \in \mathbb{R}^{h \times h}$ is the hidden-to-hidden recurrence weight matrix.
    
- $W_{hy} \in \mathbb{R}^{k \times h}$ is the hidden-to-output weight matrix.
    
- $\tanh$ is the non-linear hyperbolic tangent activation function, scaling activations between $[-1, 1]$.

### Weight Sharing Across Time

When unrolled across $T$ time steps, the RNN behaves like a chain of $T$ identical feedforward layers. Crucially, the parameter matrices ($W_{xh}, W_{hh}, W_{hy}$) are **shared across every single time step**. This parameter sharing enforces translation invariance: the model applies the same transformation rules to tokens regardless of their index position within the sequence.

## 4. RNN Topologies and Input-Output Mappings

Depending on the dimensionality and structure of the task, recurrent networks can be configured into four operational topologies:

```
1. Many-to-One        2. One-to-Many        3. Many-to-Many (Seq2Seq)    4. Synced Many-to-Many
   [x][x][x]                 [x]                 [x][x][x]                     [x][x][x]
       │                      │                      │                             │
    [ RNN ]                [ RNN ]                [Enc/Dec]                     [ RNN ]
       │                      │                      │                             │
      [y]                  [y][y][y]              [y][y]                       [y][y][y]
```

- **Many-to-One:** Multiple sequential inputs map to a single categorical output token or scalar.
       
    - _Use Case:_ Sentiment analysis (e.g., processing a sequence of review words to predict a positive/negative label).
         
- **One-to-Many:** A single non-sequential input initializes the recurrent chain to produce an output sequence.
       
    - _Use Case:_ Image captioning (e.g., encoding an image vector to autoregressively decode a descriptive sentence).
         
- **Many-to-Many (Asynchronous / Seq2Seq):** An input sequence is fully ingested before an output sequence of different length is produced.
       
    - _Use Case:_ Machine translation (e.g., converting a 5-word English sentence into a 4-word French sentence).
         
- **Synced Many-to-Many (Synchronous):** For every incoming sequence step, the network immediately emits a corresponding output step ($T_{in} = T_{out}$).
       
    - _Use Case:_ Video frame classification, live subtitling, and sequence tagging.

## 5. The Vanishing and Exploding Gradient Problem

### Backpropagation Through Time (BPTT)

To train an RNN, the loss $L$ is computed at the output and propagated backward across the unrolled sequence to update the shared weight matrices. The gradient of the loss with respect to the initial hidden state $h_1$ requires computing a chain of matrix multiplications across temporal steps:
$$\frac{\partial L}{\partial h_1} = \frac{\partial L}{\partial h_T} \prod_{j=2}^{T} \frac{\partial h_j}{\partial h_{j-1}}$$
Because the hidden state transitions depend on repeated multiplication by the recurrent weight matrix $W_{hh}$, the gradient magnitude scales with $W_{hh}^{T-1}$.

### Vanishing Gradients

- **Mechanism:** If the dominant eigenvalues of $W_{hh}$ (or values within the activation derivatives) are less than $1.0$ (e.g., $0.9$), multiplying them continuously across long time steps results in exponential decay: $0.9^{100} \approx 2.65 \times 10^{-5}$.
    
- **Consequence:** The gradient signal diminishes to zero before reaching early time steps. The weights at early positions fail to update, causing the model to suffer from short-term memory loss (amnesia) and lose long-range contextual dependencies (e.g., forgetting _"I grew up in France..."_ when predicting _"I speak fluent French"_ hundreds of tokens later).

### Exploding Gradients

- **Mechanism:** If the dominant eigenvalues of $W_{hh}$ exceed $1.0$ (e.g., $1.1$), repeated multiplication compounds exponentially: $1.1^{100} \approx 13,780$.
    
- **Consequence:** Gradients diverge to infinity, resulting in numerical overflow (`NaN` errors) and model collapse.
    
- **Remedy:** **Gradient Clipping**, which caps the gradient vector to a predefined threshold whenever its norm exceeds that limit:
$$\text{if } \Vert{}\mathbf{g}\Vert{} > \text{threshold}, \quad \mathbf{g} \leftarrow \mathbf{g} \cdot \frac{\text{threshold}}{\Vert{}\mathbf{g}\Vert{}}$$

## 6. Long Short-Term Memory (LSTM)

To resolve the vanishing gradient problem, Long Short-Term Memory networks introduce an explicit architectural division between **long-term memory** (the Cell State, $C_t$) and **short-term working memory** (the Hidden State, $h_t$).

```
               Cell State Superhighway (Additive C_{t-1} -> C_t)
         C_{t-1} ─────────────────[ X ]──────────────────[ + ]─────────────────► C_t
                                   ▲                       ▲
                                   │ f_t                   │ (i_t * \tilde{C}_t)
                              ┌────┴────┐             ┌────┴────┐
                   ┌─────────►│ \sigma  │             │ \sigma  │ ◄───────┐
                   │          └─────────┘             └─────────┘         │
                   │          Forget Gate              Input Gate         │
                   │                                       │              │
                   │                                  ┌────┴────┐         │
                   │                                  │  \tanh  │         │
                   │                                  └─────────┘         │
                   │                               Candidate State        │
                   │                                                      │
         h_{t-1} ──┴──┬───────────────────────────────────────────────────┼──► h_t
                      │                                                   │
                      │                               ┌─────────┐         │
                      └──────────────────────────────►│ \sigma  │─────────┤
                                                      └─────────┘         │
                                                      Output Gate         │
                                                           │              │
                                                           ▼              │
                                                         [ X ] ◄── \tanh(C_t)
                                                           │
                                                           ▼
                                                          h_t
```

### The Cell State Superhighway

The cell state $C_t$ runs directly down the top of the LSTM cell with minimal linear interactions. Modifications occur via **additive operations** rather than continuous matrix multiplications, providing an uninterrupted pathway for gradients to flow backward through time without decaying exponentially.

### Gate Operations

LSTMs regulate information using three dedicated gates parameterized by sigmoid activations ($\sigma(z) = \frac{1}{1 + e^{-z}}$), which produce values in the range $[0, 1]$ acting as soft switches ($0 = \text{completely block}$, $1 = \text{completely retain}$):

- **1. Forget Gate ($f_t$):** Examines the previous hidden state $h_{t-1}$ and current input $x_t$ to determine what proportion of the existing cell state should be discarded (e.g., dropping a singular subject when a plural noun appears).
$$f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$$
    
- **2. Input Gate ($i_t$ and $\tilde{C}_t$):** Decides what new information to store in the cell state. The sigmoid layer $i_t$ selects which values to update, while a $\tanh$ layer creates candidate state values $\tilde{C}_t$:
$$i_t = \sigma(W_i \cdot [h_{t-1}, x_t] + b_i)$$
$$\tilde{C}_t = \tanh(W_c \cdot [h_{t-1}, x_t] + b_c)$$
    The updated cell state combines the forgotten old memory and the new input:
$$C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$$
    
- **3. Output Gate ($o_t$ and $h_t$):** Determines the next hidden state $h_t$. The gate passes $C_t$ through a $\tanh$ function to scale values between $[-1, 1]$, multiplying it by the output gate activations $o_t$:
$$o_t = \sigma(W_o \cdot [h_{t-1}, x_t] + b_o)$$
$$h_t = o_t \odot \tanh(C_t)$$

## 7. Gated Recurrent Unit (GRU)

The Gated Recurrent Unit (GRU) simplifies the LSTM architecture by merging the separate cell state and hidden state into a single recurrent state vector $h_t$, cutting parameter counts and reducing computational overhead.

```
                 h_{t-1} ───────────[ X ]──────────────────────[ + ]────────► h_t
                                      ▲                          ▲
                                      │ (1 - z_t)                │ (z_t)
                                 ┌────┴────┐                ┌────┴────┐
                      ┌─────────►│ \sigma  │                │  \tanh  │ ◄─── \tilde{h}_t
                      │          └─────────┘                └─────────┘
                      │          Update Gate                     ▲
                      │             (z_t)                        │
                      │                                    [ X ] ◄── r_t (Reset Gate)
                      │                                      │
                      ├──────────────────────────────────────┘
                      │
         [h_{t-1}, x_t]
```

### The Two-Gate Structure

Instead of three gates, the GRU utilizes two functional gates:

- **1. Reset Gate ($r_t$):** Determines how much of the past hidden state to ignore when calculating a new candidate hidden state $\tilde{h}_t$. This allows the network to temporarily drop previous context to evaluate an incoming token independently:
$$r_t = \sigma(W_r \cdot [h_{t-1}, x_t] + b_r)$$
$$\tilde{h}_t = \tanh(W_h \cdot [r_t \odot h_{t-1}, x_t] + b_h)$$
    
- **2. Update Gate ($z_t$):** Simultaneously performs the roles of the LSTM's forget and input gates. It computes a single balance coefficient $z_t \in [0, 1]$ that controls the trade-off between retaining past context and adopting candidate information:
$$z_t = \sigma(W_z \cdot [h_{t-1}, x_t] + b_z)$$
$$h_t = (1 - z_t) \odot h_{t-1} + z_t \odot \tilde{h}_t$$

## 8. Comparative Architecture Summary

|**Dimension**|**Vanilla RNN**|**LSTM**|**GRU**|
|---|---|---|---|
|**State Vectors**|Single state ($h_t$)|Dual state: Cell ($C_t$) & Hidden ($h_t$)|Single state ($h_t$)|
|**Gating Count**|None (Static transitions)|3 Gates (Forget, Input, Output)|2 Gates (Reset, Update)|
|**Long-Term Memory**|Poor (Suffers from vanishing gradients)|High (Additive cell highway prevents decay)|High (Additive gating pathway)|
|**Computational Cost**|Lowest|Highest (Largest parameter count)|Moderate (Faster convergence than LSTM)|
|**Recommended Scope**|Short sequences or simple baseline benchmarks.|Long, complex sequential dependencies and translation.|Moderate-sized datasets, classification, and speed-optimized training.|

A standard operational heuristic is to begin modeling with a **GRU** to achieve faster training iterations. If the task involves extended sequences with intricate nested relationships (such as complex machine translation), transition to an **LSTM** architecture.
