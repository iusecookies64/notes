To setup a laravel project you run following command `composer create-project laravel/laravel path_or_folderName`. Just like how we do initialize an empty react project using `create-react-app` or `vite` this command will also setup a basic laravel project setup.

After the project is setup, you can run the command `php artisan serve` to start the server. Now you can visit the `localhost:8000` URL and should see the following page. Laravel server is up and running.
