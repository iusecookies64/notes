### **Functions**
##### Basic Syntax
Functions are defined with the **`function`** keyword, a name, and curly braces **`{}`** that enclose the function's code. All variable names in PHP must start with a dollar sign **`$`**.


```php
// A simple function with no parameters
function say_hello() {
  echo "Hello, World!";
}

// Calling the function
say_hello();
```
##### Parameters & Arguments
Functions become powerful when you pass data to them using parameters.
###### 1. Positional & Default Arguments
You can define required parameters and optional ones that have a default value. Optional parameters should always come after required ones.

```php
function greet($name, $greeting = "Hello") {
  echo "$greeting, $name!";
}

greet("Alice"); // Outputs: Hello, Alice!
greet("Bob", "Good morning"); // Outputs: Good morning, Bob!
```
###### 2. Type Declarations
PHP 7 introduced **scalar type declarations**, which allow you to specify the expected data type for parameters. This helps create more robust and predictable code. If the wrong type is given, PHP will try to convert it or throw an error.

```php
// This function expects two integers
function add(int $a, int $b) {
  return $a + $b;
}

echo add(5, 10); // Works, outputs: 15
```

Common types include **`int`**, **`float`**, **`string`**, **`bool`**, and **`array`**.
##### Return Values
Functions can send data back to the code that called them using the **`return`** keyword. You can also declare what type of value a function is expected to return.

```php
// This function is declared to return an integer
function multiply(int $a, int $b): int {
  return $a * $b;
}

$product = multiply(7, 3); // $product is now 21
```
##### Variable Scope
Understanding variable scope is crucial.

Variables defined inside a function are **local** to that function and cannot be accessed from the outside. Likewise, variables defined outside a function (in the global scope) are not automatically available inside it.

```php
$tax_rate = 0.20; // Global variable

function calculate_total(float $price): float {
  // To use a global variable, you must explicitly import it.
  
  // Option 1: Use the `global` keyword
  global $tax_rate;
  return $price * (1 + $tax_rate);

  // Option 2: Use the $GLOBALS superglobal array
  // return $price * (1 + $GLOBALS['tax_rate']);
}

echo calculate_total(100); // Outputs: 120
```
##### Variadic Functions
If you need a function to accept an unknown number of arguments, you can use the splat operator **`...`**. The arguments will be passed into the function as an array.

```php
function sum(...$numbers): int {
  $total = 0;
  foreach ($numbers as $num) {
    $total += $num;
  }
  return $total;
}

echo sum(1, 2, 3, 4); // Outputs: 10
```

##### Passing by Reference
By default, PHP passes arguments by value, meaning the function gets a copy. To allow a function to modify the original variable, you must pass it by reference by adding an ampersand **`&`** to the parameter name.

```php
$value = 10;

// The & allows this function to modify the original $value
function double_it(&$num) {
  $num = $num * 2;
}

double_it($value);

echo $value; // Outputs: 20 (the original variable was changed)
```
##### Anonymous Functions (Closures)
You can also create functions without a specified name. These are useful as one-off callbacks. To use a variable from the parent scope inside a closure, you must use the **`use`** keyword.

```php
$numbers = [1, 2, 3, 4];
$multiplier = 3;

// `array_map` applies the anonymous function to every item in the array.
// The `use` keyword makes $multiplier available inside the function.
$multiplied = array_map(function($n) use ($multiplier) {
    return $n * $multiplier;
}, $numbers);

print_r($multiplied); // Outputs: Array ( [0] => 3 [1] => 6 [2] => 9 [3] => 12 )
```

### **`if`, `elseif`, `else` Statement**

This is the most common way to control program flow. It checks a series of conditions and executes the code block for the first condition that evaluates to **`true`**.

- **`if`**: Checks the first condition.
    
- **`elseif`**: If the previous `if` (or `elseif`) was false, this checks a new condition. You can have many `elseif` blocks.
    
- **`else`**: If all preceding conditions were false, this block runs as a fallback.
    

```php
$age = 25;

if ($age >= 65) {
  echo "You are a senior citizen.";
} elseif ($age >= 18) {
  echo "You are an adult."; // This block will run
} else {
  echo "You are a minor.";
}
```

##### Ternary Operator
The ternary operator is a compact shorthand for a simple `if-else` statement. It's great for assigning a value to a variable based on a single condition.

**Syntax:** `(condition) ? value_if_true : value_if_false;`

```php
$is_logged_in = true;

$message = $is_logged_in ? "Welcome back!" : "Please log in.";

echo $message; // Outputs: Welcome back!
```

##### Null Coalescing Operator (`??`)
Introduced in PHP 7, the null coalescing operator is a shortcut for checking if a variable exists and is not **`null`**. It returns the first operand if it exists and is not `null`; otherwise, it returns the second operand.

This is extremely useful for handling form data or API responses where a key might not be set.

```php
// Old way with a ternary operator
$username = isset($_POST['user']) ? $_POST['user'] : 'guest';

// New way with the null coalescing operator
$username = $_POST['user'] ?? 'guest';

echo $username; // If $_POST['user'] is not set, it will output 'guest'
```

##### `switch` Statement
A **`switch`** statement is a clean alternative to a long `if-elseif-else` chain when you are comparing a single variable against many possible values.

- **`case`**: Defines a value to check against.
    
- **`break`**: Exits the `switch` statement. **Crucially, if you forget `break`, execution will "fall through" to the next `case` block.**
    
- **`default`**: An optional block that runs if no other `case` matches.
    

```php
$user_role = 'editor';

switch ($user_role) {
  case 'admin':
    echo "Full access granted.";
    break;
  case 'editor':
    echo "Can write and publish content."; // This block runs
    break;
  case 'subscriber':
    echo "Can only read content.";
    break;
  default:
    echo "Unknown role.";
    break;
}
```

### **Conditional Operators**
##### AND (`&&`)

The **`&&`** operator returns **`true`** only if **both** the left and right conditions are true. If either one is false, the entire expression becomes false.

Think of it as needing multiple things to be true at once.

```php
$age = 25;
$has_license = true;

// Both conditions must be true to rent a car
if ($age >= 25 && $has_license) {
  echo "You can rent a car."; // This will run
}
```

_Note: The word `and` can be used instead of `&&`, but `&&` is more common and has higher precedence (priority) in evaluation._

##### OR (`||`)
The **`||`** operator returns **`true`** if **at least one** of the conditions is true. It only returns false if both conditions are false.

Think of it as having multiple options available.

```php
$is_admin = false;
$is_editor = true;

// Only one of the conditions needs to be true
if ($is_admin || $is_editor) {
  echo "You can publish articles."; // This will run
}
```

_Note: The word `or` can be used instead of `||`, but `||` is more common and has higher precedence._

##### NOT (`!`)
The **`!`** operator is a unary operator that inverts a boolean value. It turns **`true`** into **`false`**, and **`false`** into **`true`**.

It's used to check if something is not true.

```php
$is_logged_in = false;

// Checks if the user is NOT logged in
if (!$is_logged_in) {
  echo "Please log in to continue."; // This will run
}
```

##### Combining Operators
You can combine these operators to build complex logic. Use parentheses `()` to group conditions and ensure they are evaluated in the order you intend.

```php
$account_active = true;
$user_role = 'subscriber';
$is_premium = true;

// Check if an active user is either an admin OR a premium subscriber
if ($account_active && ($user_role == 'admin' || $is_premium)) {
    echo "Welcome to the premium content area!"; // This will run
}
```

In this example, the `||` inside the parentheses is evaluated first.

### **Loops**

##### `for` Loop
A **`for`** loop is ideal when you know exactly how many times you want the code to run. It combines initialization, condition checking, and incrementing into one line.

It has three parts:

1. **Initialization**: Runs once at the very beginning (`$i = 1`).
    
2. **Condition**: Checked _before_ each iteration. If it's true, the loop continues (`$i <= 5`).
    
3. **Increment**: Runs at the _end_ of each iteration (`$i++`).
    

```php
for ($i = 1; $i <= 5; $i++) {
  echo "Iteration number $i\n";
}
```

##### `foreach` Loop
The **`foreach`** loop is the easiest and most reliable way to iterate over every element in an **array**. It's the most commonly used loop for handling arrays.

```php
$colors = ["Red", "Green", "Blue"];

// Loop through and get only the values
foreach ($colors as $color) {
  echo "$color\n";
}

// You can also get both the key (index) and the value
$user = ['name' => 'Alice', 'age' => 30];
foreach ($user as $key => $value) {
  echo "$key: $value\n";
}
```

>[!Note]
>In the `foreach` loop with key values, we will index as keys and respective values if the array also had indexed elements.

##### `while` Loop
A **`while`** loop runs as long as a specified condition is true. The condition is checked _before_ the code block is executed. If the condition is false from the start, the loop will never run.

```php
$count = 1;

while ($count <= 5) {
  echo "The count is $count\n";
  $count++; // Important: Don't forget to increment, or you'll create an infinite loop!
}
```

##### `do-while` Loop
A **`do-while`** loop is similar to a `while` loop, but it checks the condition _after_ the code block has executed. This means the loop is **guaranteed to run at least once**.

```php
$i = 10;

do {
  echo "This will run once, even though the condition is false.\n";
  $i++;
} while ($i < 5);
```

##### `break` and `continue` Keywords
You can control loop execution with these two keywords.

- **`break`**: Immediately terminates the loop entirely.
    
- **`continue`**: Skips the rest of the current iteration and proceeds to the next one.
    

```php
for ($i = 1; $i <= 10; $i++) {
  if ($i % 2 == 0) {
    // Skip all even numbers
    continue;
  }
  
  if ($i == 7) {
    // Exit the loop completely when we find 7
    break;
  }
  
  echo "$i\n"; // Outputs: 1, 3, 5
}
```

### **Object Oriented Programming In PHP**

##### Classes and Objects
- A **class** is a blueprint for creating things. It defines a set of properties (variables) and methods (functions) that the things created from it will have.
    
- An **object** is an instance of a class—a concrete thing created from that blueprint.
    

```php
// Define the blueprint (Class)
class Car {
  // Properties and methods go here
}

// Create actual objects from the blueprint
$myCar = new Car();
$yourCar = new Car();
```

##### Properties, Methods, and `$this`
- **Properties** are variables that belong to a class. They store the state of an object.
    
- **Methods** are functions that belong to a class. They define the behavior of an object.
    
- The **`$this`** keyword is a special variable that refers to the _current object_. You use it inside a method to access the object's own properties and methods.
    

```php
class Car {
  // Property
  public $color = 'red';

  // Method
  public function startEngine() {
    // Use $this to access the object's properties
    echo "Starting the " . $this->color . " car's engine...";
  }
}

$myCar = new Car();
$myCar->color = 'blue'; // Change the property of this specific object
$myCar->startEngine(); // Outputs: Starting the blue car's engine...
```

##### The Constructor
A constructor is a special method named **`__construct()`** that is automatically called when you create a new object. It's used to initialize an object's properties.

```php
class User {
  public $username;

  // This runs automatically when you use `new User(...)`
  public function __construct($name) {
    $this->username = $name;
    echo "User object for '$this->username' was created.";
  }
}

$user1 = new User('Alice'); // Outputs: User object for 'Alice' was created.
```

##### Access Modifiers (Encapsulation)
Access modifiers control where properties and methods can be accessed from. This is a core concept called **encapsulation**.

- **`public`**: Can be accessed from anywhere (outside the class and by child classes). This is the default.
    
- **`protected`**: Can only be accessed within the class itself and by its child classes (see inheritance).
    
- **`private`**: Can _only_ be accessed from within the class that defined it.
    

```php
class BankAccount {
  public $accountHolder;    // Anyone can see this
  private $balance;         // Can only be accessed inside this class

  public function __construct($name, $initialDeposit) {
    $this->accountHolder = $name;
    $this->balance = $initialDeposit;
  }

  public function getBalance() {
    // We provide a public method to safely get the private property
    return $this->balance;
  }
}

$account = new BankAccount('Bob', 100);
echo $account->accountHolder; // Works (public)
// echo $account->balance;      // FATAL ERROR! Cannot access private property
echo $account->getBalance();   // Works, returns 100
```

##### Inheritance
Inheritance allows a class (the **child**) to inherit all the `public` and `protected` properties and methods from another class (the **parent**). This promotes code reuse.

- The child class uses the **`extends`** keyword.
    
- A child class can **override** a parent's method to provide its own implementation.
    
- You can call a parent's method from within a child using **`parent::methodName()`**.
    

```php
// Parent Class
class Animal {
  public function makeSound() {
    echo "Animal makes a sound.";
  }
}

// Child Class
class Dog extends Animal {
  // Override the parent's method
  public function makeSound() {
    echo "Dog barks.";
  }

  public function fetch() {
    echo "Fetching a stick.";
  }
}

$myDog = new Dog();
$myDog->makeSound(); // Outputs: Dog barks.
```

##### Static Properties and Methods
**Static** members belong to the **class itself**, not to any specific object instance. You access them using the class name and the double colon `::` (Scope Resolution Operator). You do not need to create an object to use them.

```php
class MathHelper {
  public static $pi = 3.14159;

  public static function add($a, $b) {
    return $a + $b;
  }
}

// No object needed
echo MathHelper::$pi; // Outputs: 3.14159
echo MathHelper::add(5, 10); // Outputs: 15
```

##### Class Constants
Constants are properties whose value can never be changed. They are defined with the `const` keyword and are also accessed with `::`.

```php
class Config {
  const SITE_URL = 'https://www.example.com';
}

echo Config::SITE_URL; // Outputs: https://www.example.com
```
